Hermes Agent 功能丰富——CLI 助手、Telegram/Discord 机器人、任务自动化、强化学习训练等。本页帮助您根据自身经验水平和目标，确定从哪里开始、阅读哪些内容。

> [!-success] -success
> 从这里开始
> 
> 如果您尚未安装 Hermes Agent，请先阅读 [安装指南](https://hermes-agent.nousresearch.com/docs/zh-Hans/getting-started/installation) ，然后完成 [快速入门](https://hermes-agent.nousresearch.com/docs/zh-Hans/getting-started/quickstart) 。以下内容均假设您已完成安装。

| 水平 | 目标 | 推荐阅读 | 预计时间 |

| **中级** | 搭建消息机器人，使用记忆、cron 任务、技能等高级功能 | [会话](https://hermes-agent.nousresearch.com/docs/zh-Hans/user-guide/sessions) → [消息](https://hermes-agent.nousresearch.com/docs/zh-Hans/user-guide/messaging) → [工具](https://hermes-agent.nousresearch.com/docs/zh-Hans/user-guide/features/tools) → [技能](https://hermes-agent.nousresearch.com/docs/zh-Hans/user-guide/features/skills) → [记忆](https://hermes-agent.nousresearch.com/docs/zh-Hans/user-guide/features/memory) → [Cron](https://hermes-agent.nousresearch.com/docs/zh-Hans/user-guide/features/cron) | 约 2–3 小时 |

## 按使用场景

选择与您目标匹配的场景，每个场景均按推荐顺序链接到相关文档。

### "我想要一个 CLI 编程助手"

将 Hermes Agent 用作交互式终端助手，用于编写、审查和运行代码。

> 提示
> 
> 通过上下文文件将文件直接传入对话。Hermes Agent 可以读取、编辑并运行您项目中的代码。

### "我想自动化任务"

调度周期性任务、运行批处理作业，或将多个 agent 动作串联起来。

1. [快速入门](https://hermes-agent.nousresearch.com/docs/zh-Hans/getting-started/quickstart)
2. [Cron 调度](https://hermes-agent.nousresearch.com/docs/zh-Hans/user-guide/features/cron)
3. [批处理](https://hermes-agent.nousresearch.com/docs/zh-Hans/user-guide/features/batch-processing)

> 提示
> 
> Cron 任务让 Hermes Agent 按计划执行任务——每日摘要、定期检查、自动报告——无需您在场。

## 下一步阅读

根据您当前所处阶段：

- **刚完成安装？** → 前往 [快速入门](https://hermes-agent.nousresearch.com/docs/zh-Hans/getting-started/quickstart) ，运行您的第一次对话。
- **完成了快速入门？** → 阅读 [CLI 用法](https://hermes-agent.nousresearch.com/docs/zh-Hans/user-guide/cli) 和 [配置](https://hermes-agent.nousresearch.com/docs/zh-Hans/user-guide/configuration) ，自定义您的设置。
- **已熟悉基础？** → 探索 [工具](https://hermes-agent.nousresearch.com/docs/zh-Hans/user-guide/features/tools) 、 [技能](https://hermes-agent.nousresearch.com/docs/zh-Hans/user-guide/features/skills) 和 [记忆](https://hermes-agent.nousresearch.com/docs/zh-Hans/user-guide/features/memory) ，释放 agent 的全部能力。
- **为团队部署？** → 阅读 [安全](https://hermes-agent.nousresearch.com/docs/zh-Hans/user-guide/security) 和 [会话](https://hermes-agent.nousresearch.com/docs/zh-Hans/user-guide/sessions) ，了解访问控制与对话管理。
- **准备好开发了？** → 进入 [开发者指南](https://hermes-agent.nousresearch.com/docs/zh-Hans/developer-guide/architecture) ，了解内部机制并开始贡献。
- **想要实际示例？** → 查看 [指南](https://hermes-agent.nousresearch.com/docs/zh-Hans/guides/tips) 部分，获取真实项目案例和技巧。

> [!-success] -success
> 提示
> 
> 您无需阅读所有内容。选择与您目标匹配的路径，按顺序跟随链接，即可快速上手。随时可以回到本页寻找下一步。
