## 速打开 GitHub 上与插件和主题相关的仓库

## 打开 GitHub 插件仓库

> 这其实比听起来要酷多了。
> 
> 该命令面板中包含“BRAT”命令：该命令可用于打开某个插件的 GitHub 仓库。这样，你就能看到所有在 BRAT 系统中注册的测试版插件，以及社区中提供的所有插件。只需从列表中选择某个插件，该插件的 GitHub 仓库就会在你的浏览器中打开。

## 打开一个 GitHub 主题仓库

与“打开 GitHub 插件仓库”命令类似，“打开 GitHub 主题仓库”也会打开社区主题列表中发布的某个主题对应的 GitHub 仓库。
