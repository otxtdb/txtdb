## 记住光标的位置

一个黑曜石插件，能够记住每个笔记的光标位置、滚动位置以及文本选择内容。

## 特点

- 光标位置——返回到您正在编辑的精确行和列
- 滚动位置——恢复您在当前文档中滚动到的位置。
- 文本选择功能——在重新打开笔记时，会保留已选择的文本。
- 编辑和预览模式——适用于编辑视图和阅读视图
- 持久存储——职位信息被保存为 JSON 文件（路径可配置），并且即使在应用重新启动的情况下也能保持有效。
- 智能恢复功能——在打开指向特定部分的链接时，避免不必要的滚动操作（ `#header` 链接）
- 可配置的默认设置——可以选择在不存在保存的持仓时执行什么操作：返回到起始位置、结束位置、在脚注之前执行操作，或者什么都不做。
- 修剪——可以选择性地删除已删除文件的记录，或者根据存储时间顺序删除旧记录，或者限制存储的位置总数。

## 它是如何运作的

每次你移动光标或在笔记中滚动时，插件都会记录下当前的状态。当你再次回到同一个音符处时（即使在关闭并重新打开 Obsidian 软件之后），系统也能恢复你之前的定位和操作状态。这样就能轻松地在各个音符之间切换了——无需再手动滚动寻找目标位置了。

## 安装

### 来自黑曜石社区插件

1. 打开设置→社区插件选项
2. 关闭受限模式（如果已启用）
3. 点击“浏览”按钮，然后搜索“记住光标位置”这个选项。
4. 安装并启用该插件。

### 手动安装

1. 从发布页面下载最新版本。
2. 将文件提取到你的存储库的 `.obsidian/plugins/remember-cursor-position/` 目录下。
3. 在设置中启用该插件 → 社区插件页面

## 设置

| 设置               | 描述                                            |
| ---------------- | --------------------------------------------- |
| 默认光标位置           | 当没有保存该文件的任何位置时该怎么办（选择开始/结束/在脚注之前/默认模式——选择无操作） |
| 数据文件名            | 存储位置的 JSON 文件的路径                              |
| 在打开新笔记后出现了延迟     | 在点击带有部分锚点的链接时，可以防止不必要的滚动操作。                   |
| 保存数据之间的延迟时间      | 位置数据库多久会一次性写入到磁盘中一次                           |
| 删除已删除文件的条目       | 将那些在存储库中已不存在的文件置为“已删除”状态。                     |
| 删除那些时间超过一定限制的条目。 | 自动丢弃在所选期间未更新过的位置信息。                           |
| 可保留的条目数量上限       | 通过仅保留最近访问过的文件来限制数据库的大小。                       |
