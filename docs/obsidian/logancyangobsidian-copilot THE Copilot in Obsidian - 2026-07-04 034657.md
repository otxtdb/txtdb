## 那究竟是什么？

Obsidian 的 Copilot 是一款强大的 AI 助手。它支持基于聊天的方式来搜索数据库中的内容，同时还能处理网页和 YouTube 上的信息。此外，它还具有出色的上下文处理能力，其功能也在不断扩展中。所有这些功能都体现在 Obsidian 高度可定制的工作环境中。而最重要的是，你始终能够掌控自己的数据。

## 为什么

如今的 AI 巨头们想把用户牢牢困在自己的体系中：用户的资料存储在他们的服务器上，用户的输入数据也被限制在他们的模型范围内。此外，用户还要不断支付各种费用才能继续使用这些服务。一旦这些巨头调整价格、关闭某些功能或终止用户的账户，用户之前所付出的一切努力都将付诸东流。

我们正在打造完全相反的东西。我们的目标是创造一种无需依赖任何特定服务提供商的、可便携的智能体验。数据永远属于用户自己。用户可以自由选择使用任何大语言模型。想象一下：当有全新的模型问世时，用户可以在自己的硬件上运行它。该模型会记住用户的各种信息（即长期记忆），能够执行用户事先定义的各种命令和操作（这些命令和操作通常以 Markdown 格式保存）。这样一来，该模型就能成为用户真正的智能助手和伙伴。这才是真正与用户共同成长的 AI，而不是让用户受制于某种订阅服务的 AI。

这就是我们所坚信的未来。如果您认同这一愿景，请支持这个项目吧！

## 主要特点/核心功能

- 🔒 您的数据完全属于您自己：数据在本地进行搜索和存储。如果您使用自托管模型，还能完全掌控自己的数据。
- 🧠 自带模型：只需使用任何与 OpenAI 兼容的模型或本地模型，即可获取有价值的洞察、建立联系并创建各种内容。
- 🖼️ 多媒体内容解析：可以直接在网页、YouTube 视频、图片、PDF 文件、EPUB 格式的文档中查看内容，或者通过实时网络搜索来获取所需信息。
- 🔍 智能搜索功能：无需任何设置，即可通过聊天方式在您的存储空间中搜索所需内容。嵌入功能为可选选项。Copilot 能立即提供搜索结果。
- ✍️ 作曲工具与快捷命令：可通过聊天方式与所创作的乐谱进行互动，只需点击一下即可应用各种更改。
- 🗂️ 项目模式：根据文件夹和标签来创建适合 AI 处理的上下文环境。就像 NotebookLM 的功能，只不过是集成在你的数据存储系统中而已！
- 🤖 智能代理模式（高级版）：解锁具有内置工具调用功能的智能代理。无需手动输入命令。Copilot 会自动在需要时触发保险箱功能、网络搜索或其它相关工具。

## 开始使用吧

### 安装 Obsidian Copilot

1. 打开 Obsidian → 设置 → 社区插件。
2. 关闭安全模式（如果已启用）。
3. 点击“浏览”，搜索“Copilot for Obsidian”。
4. 点击“安装”，然后点击“启用”。

### 设置 API 密钥

**免费用户**

1. 进入 Obsidian → 设置 → Copilot → 基本设置，然后点击“设置键值”。
2. 请选择您想要使用的人工智能服务提供商（例如：OpenRouter、Gemini、OpenAI、Anthropic、Cohere），然后粘贴相应的 API 密钥。建议使用 OpenRouter。

**Copilot Plus/Believer**

1. 在您的控制面板上复制您的许可证密钥。别忘了加入我们精彩的 Discord 社区吧！
2. 进入 Obsidian → 设置 → Copilot → 基本设置，然后将该密钥粘贴到 Copilot Plus 对应的字段中。

## 常见问题解答

**为什么“保险库搜索”找不到我的笔记呢？**

If you're using the Vault QA mode (or the tool `@vault` in Plus), try the following:

- Ensure you have a working embedding model from your AI model's provider (e.g. OpenAI). Watch this video: [AI Model Setup (API Key)](https://www.youtube.com/watch?v=mzMbiamzOqM)
- Ensure your Copilot indexing is up-to-date. Watch this video: [Vault Mode](https://www.youtube.com/watch?v=hBLMWE8WRFU)
- If issues persist, run **Force Re-Index** or use **List Indexed Files** from the Command Palette to inspect what's included in the index.
- ⚠️
	**Don’t switch embedding models after indexing** —it can break the results.
**为什么我的 AI 模型会返回错误代码 429：“配额不足”？**

Most likely this is happening because you haven’t configured billing with your chosen model provider—or you’ve hit your monthly quota. For example, OpenAI typically caps individual accounts at $120/month. To resolve:

- ▶️
	Watch the “AI Model Setup” video: [AI Model Setup (API Key)](https://www.youtube.com/watch?v=mzMbiamzOqM)
- 🔍 Verify your billing settings in your OpenAI dashboard
- 💳 Add a payment method if one isn’t already on file
- 📊 Check your usage dashboard for any quota or limit warnings

If you’re using a different provider, please refer to their documentation and billing policies for the equivalent steps.

**为什么我会遇到令牌数量限制的错误呢？**

Please refer to your model provider’s documentation for the context window size.

⚠️

If you set a large **max token limit** in your Copilot settings, you may encounter this error.
- **Max tokens** refers to *completion tokens*, not input tokens.
- A higher output token limit means less room for input!

🧠 Behind-the-scenes prompts for Copilot commands also consume tokens, so:

- Keep your message length short
- Set a reasonable max token value to avoid hitting the cap

💡 For QA with unlimited context, switch to the **Vault QA** mode in the dropdown (Copilot v2.1.0+ required).
