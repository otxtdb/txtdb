BRAT 可以帮助你快速安装那些正处于开发中的插件或主题。本指南详细介绍了在测试插件或主题时需要执行的各项常见操作。

## 测试插件

### 添加测试版插件

1. 从 Obsidian 的“社区插件”中安装 BRAT 插件。
2. 获取你想要测试的 GitHub 仓库的链接。该插件的开发者可以为你提供这个链接。
	> ```bash
	> It will look something like: GitMurf/my-plugin or https://github.com/GitMurf/my-plugin
	> ```
3. 打开命令面板，然后运行命令 BRAT：添加用于测试的测试版插件。如果你希望该插件的版本保持不变，可以使用命令 BRAT：添加基于某个发布版本的固定版本的测试版插件。
4. 使用第 2 步中的链接，将其复制到弹出的窗口中。
5. 点击“添加插件”——等待几秒钟，BRAT 会告诉你当前的处理情况。
6. 在 BRAT 确认安装完成后，进入“设置”中的“社区插件”选项卡。
7. 刷新插件列表
8. 找到你刚刚安装的 beta 插件，然后将其启用。

### 正在更新测试版插件

- 可以通过命令面板来更新插件：运行“检查所有测试版插件的更新情况”以及“更新”命令即可。
- 可选地，可以配置 beta 插件，使其在启动 Obsidian 时自动更新。该功能可在设置的“Obsidian42-BRAT”选项卡中开启。

### 停止 Beta 插件的更新/删除某个 Beta 插件

- 停止对测试版插件的更新（第一步）
	- 在设置的“BRAT”选项卡中，点击那些你想停止更新的测试版插件的旁边的“x”按钮。在“x”按钮的位置，会出现一个确认按钮，用于确认是否要停止对该测试版插件的更新。
		- 当您从 BRAT 中移除该插件后，该插件仍然会保留在您的 Obsidian 数据库中。您仍然可以通过 Obsidian 的“检查更新”功能来获取该插件的更新。如果您真的想彻底移除该插件，请务必按照以下步骤操作。
- 从 Obsidian 中删除测试版插件（第 2 步：可选）
	- 如果你想删除该插件，还需要再执行一步操作。请进入设置中的“社区插件”选项卡，找到该测试版插件，然后像卸载其他插件一样将其卸载即可。
		- 您还需要按照第一步的说明，从 BRAT 中删除对该测试版插件的引用。否则，BRAT 会继续对该插件进行更新。

## 主题测试

### 从代码仓库中获取一个测试版主题吧。

BRAT 可以帮助你测试那些正在开发中的主题。要使用此功能，请按照以下步骤操作：

1. 打开命令面板，然后选择“从 GitHub 仓库获取测试用 beta 主题”这一命令。
2. 接下来，系统会提示你输入该主题所存储的 GitHub 仓库的 URL 地址。

BRAT 会首先确认该主题确实存在，然后将其下载下来，并将您当前的主题替换为这个测试版主题。

### 从仓库中更新测试版主题

- 使用主题更新命令后，BRAT 会检查所有的测试版主题，看是否有更新。如果有更新，它会自动下载更新内容，并通知用户。
