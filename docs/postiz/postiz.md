## 您终极的 AI 社交媒体调度工具  
[Postiz](https://postiz.com/)：Buffer.com、Hypefury、Twitter Hunter 等产品的替代方案  
  
**Postiz 提供了你管理社交媒体帖子所需的一切，  
建立受众、获取潜在客户并发展你的业务。
  

# 简介
- 安排你所有的社交媒体帖子（许多 AI 功能）
- 用分析来衡量你的工作。
- 与其他团队成员协作，交换或购买帖子。
- 邀请你的团队成员协作、评论和安排帖子。
- 目前，托管版本与自托管版本之间没有区别。
- 非常适合与 N8N、Make.com、Zapier 等平台进行自动化（API）集成。

## 技术栈
- Pnpm 工作区（单仓库）
- NextJS (React)
- NestJS
- Prisma（默认使用 PostgreSQL）
- Temporal
- Resend（邮件通知）

## Postiz 合规性
- Postiz 是一款开源的、可自托管的社交媒体排程工具，支持 X（前身为 Twitter）、Bluesky、Mastodon、Discord 等平台。
- Postiz 托管服务使用官方的、平台批准的 OAuth 流程。
- Postiz 不会自动或抓取社交媒体平台的内容。
- Postiz 不会收集、存储或代理用户的 API 密钥或访问令牌。
- Postiz 从不要求用户将 API 密钥粘贴到我们的托管产品中。
- Postiz 用户始终直接通过社交平台（例如，X、Discord 等）进行身份验证，确保平台合规性和数据隐私。
