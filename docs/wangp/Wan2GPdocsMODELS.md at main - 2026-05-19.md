## 模型概述

WanGP 支持多种视频生成模型，每个模型都针对不同的使用场景和硬件配置进行了优化。

大多数模型可以与 Loras 加速器结合（参考 Lora 指南），以在几乎不损失质量的情况下将视频生成速度提升 2 倍或 3 倍

## Wan 2.1 文本到视频模型

请注意，术语 *文本到视频* 指的是底层的 Wan 架构，但由于其经过长期大幅改进，许多派生的文本到视频模型现在可以使用图像生成视频。

#### Wan 2.1 文本到视频 1.3B

- **规模** : 130 亿参数
- **VRAM**: 最小 6GB
- **速度** : 快速生成
- **质量** : 适合规模的优质
- **最适合** : 快速迭代，低端硬件
- **命令** : `python wgp.py --t2v-1-3B`

#### Wan 2.1 文本转视频 14B

- **大小** : 140 亿参数
- **VRAM**: 推荐 12GB+
- **速度** : 慢但质量更高
- **质量** : 优秀细节和连贯性
- **最佳用途** : 最终制作视频
- **命令** : `python wgp.py --t2v-14B`

#### Wan Vace 1.3B

- **类型** : ControlNet，用于高级视频控制
- **VRAM**: 至少 6GB
- **功能** : 运动迁移、对象注入、图像修复
- **最适合** : 高级视频处理
- **命令** : `python wgp.py --vace-1.3B`

#### Wan Vace 14B

- **类型** : 大型 ControlNet 模型
- **VRAM**: 推荐 12GB+
- **功能** : 所有 Vace 功能，质量更高
- **最佳适用** : 专业视频编辑工作流程

#### MoviiGen (实验性)

- **分辨率** : 声称支持 1080p
- **显存** : 需要 20GB+
- **速度** : 生成速度非常慢
- **特性** : 应生成电影般的视频，专门针对 2.1 / 1 的宽高比
- **状态** : 实验阶段，欢迎反馈

## Wan 2.1 图像到视频模型

#### Wan 2.1 Image2Video 14B

- **规模** : 140 亿参数
- **VRAM**: 推荐 12GB+
- **速度** : 慢但质量更高
- **质量** : 优秀细节和连贯性
- **最适合** : 大多数 Loras 适用于此模型
- **命令** : `python wgp.py --i2v-14B`

#### FLF2V

- **类型** : 开始/结束帧专家
- **分辨率** : 优化 720p
- **官方** : Wan 团队支持
- **应用场景** : 带有特定端点的图像转视频

## Wan 2.1 专业模型

#### 多任务

- **类型** : 多人对话头像动画
- **输入** : 声音轨道 + 图片
- **适用于** : 人物
- **应用场景** ：支持最多两人的口型同步和声音驱动动画

#### 幻想说话

- **类型** : 讲头动画
- **输入** : 声音轨道 + 图片
- **适用对象** : 人物和物体
- **应用场景** : 唇形同步和声音驱动动画

#### 幽灵

- **类型** : 人物/物体传输
- **分辨率** : 在 720p 下表现良好
- **要求** : 至少 30 步以获得良好效果
- **最适合** : 在视频之间转移主体

#### Recam Master

- **类型** : 观点变化
- **要求** : 81 帧以上的输入视频，15 步以上的去噪步骤
- **应用场景** : 从不同角度查看同一场景

#### Sky Reels v2 扩散

- **类型** : 扩散强制模型
- **专业领域** : "无限长度"视频
- **特点** : 高质量连续生成

## Wan Fun InP 模型

#### Wan Fun InP 1.3B

- **大小** : 13 亿参数
- **VRAM**: 最低 6GB
- **质量** : 对于其大小来说不错，适合较低配置的硬件
- **最适合** : 入门级图像动画
- **命令** : `python wgp.py --i2v-1-3B`

#### Wan Fun InP 14B

- **参数量** : 140 亿参数
- **显存** : 推荐 12GB+
- **质量** : 更好的最终图像支持
- **限制** : 现有 loras 效果不佳

## Hunyuan 视频模型

#### Hunyuan 视频文本转视频

- **质量** : 顶尖的开源 t2v 模型之一
- **VRAM**: 推荐 12GB+
- **速度** : 较慢的代但效果出色
- **功能** : 优越的文本贴合度和视频质量，最长可达 10 秒视频
- **最适合** : 高质量文本转视频生成

#### Hunyuan 视频定制

- **专业领域** ：身份保留
- **应用场景** ：将特定人物注入视频中
- **质量** : 字符一致性极佳
- **最适合** : 以字符为中心的视频生成

#### Hunyuan Video Avatar

- **专长** : 生成长达 15 秒的高质量语音/歌曲驱动视频
- **应用场景** : 将特定人物注入视频中
- **质量** : 角色一致性极佳
- **最适合** : 以角色为中心的视频生成，与声音同步的视频

## LTX 视频模型

#### LTX 视频 13B

- **专业领域** : 长视频生成
- **分辨率** : 快速 720p 生成
- **VRAM**: 通过 WanGP 优化（需求减少 4 倍）
- **最适合** : 更长时间的影片

#### LTX 视频 13B 精简版

- **速度** ：不到一分钟即可生成
- **质量** ：速度虽快，质量极高
- **最适合** ：快速原型设计和即时结果

## 模型选择指南

### 按硬件（显存）

#### 6-8GB 显存

- Wan 2.1 T2V 1.3B
- Wan Fun InP 1.3B
- Wan Vace 1.3B

#### 10-12GB VRAM

- Wan 2.1 T2V 14B
- Wan Fun InP 14B
- Hunyuan 视频（优化版）
- LTX 视频 13B

#### 16GB+ VRAM

- 所有模型均支持
- 可能支持更长的视频
- 更高分辨率
- 多个同时运行的 Loras

#### 20GB+ VRAM

- MoviiGen（实验性 1080p）
- 非常长的视频
- 最高质量设置

### 按使用场景

#### 快速原型设计

1. **LTX 视频 13B 精炼版** - 速度最快，高质量
2. **Wan 2.1 T2V 1.3B** - 快速，高质量
3. **CausVid Lora** - 4-12 步，非常快

#### 最佳质量

1. **Hunyuan Video** - 整体最佳 t2v 质量
2. **Wan 2.1 T2V 14B** - 优秀 Wan 质量
3. **Wan Vace 14B** - 控制生成最佳

#### 高级控制

1. **Wan Vace 14B/1.3B** - 运动迁移，物体注入
2. **Phantom** - 人物/物体迁移
3. **FantasySpeaking** - 声音驱动动画

#### 长视频

1. **LTX Video 13B** - 专为长度设计
2. **Sky Reels v2** - 无限长度视频
3. **Wan Vace + 滑动窗口** - 最长 1 分钟

#### 较低硬件配置

1. **Wan Fun InP 1.3B** - 图像转视频
2. **Wan 2.1 T2V 1.3B** - 文本到视频
3. **Wan Vace 1.3B** - 高级控制

## 性能比较

### 速度（相对）

1. **CausVid Lora** (4-12 步) - 最快
2. **LTX Video Distilled** - 非常快
3. **Wan 1.3B 模型** - 快
4. **Wan 14B 模型** - 中等
5. **Hunyuan 视频** - 较慢
6. **MoviiGen** - 最慢

### 质量（主观）

1. **Hunyuan Video** - 最高总分
2. **Wan 14B 模型** - 优秀
3. **LTX Video 模型** - 非常好
4. **Wan 1.3B 模型** - 良好
5. **CausVid** - 良好（随步数变化）

### 显存效率

1. **Wan 1.3B 模型** - 最高效
2. **LTX 视频** （含 WanGP 优化）
3. **Wan 14B 模型**
4. **Hunyuan 视频**
5. **MoviiGen** - 效率最低

## 模型切换

WanGP 允许在不重启的情况下切换模型：

1. 使用网页界面的下拉菜单
2. 模型按需加载
3. 卸载上一个模型以节省 VRAM
4. 在可能的情况下保留设置

## 模型选择技巧

### 首次使用者

从 **Wan 2.1 T2V 1.3B** 开始，熟悉界面并测试您的硬件。

### 生产工作

使用 **Hunyuan Video** 或 **Wan 14B** 模型以获得最终输出质量。

### 实验

**CausVid Lora** 或 **LTX Distilled** 用于快速迭代和测试。

### 专业任务

- **VACE** 用于高级控制
- **FantasySpeaking** 用于头像对话
- **LTX Video** 用于长序列

### 硬件优化

始终从 VRAM 能处理的最高模型开始，然后根据需求在速度与质量之间调整设置。
