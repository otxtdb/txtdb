## VACE 控制网指南

VACE 是一个强大的 ControlNet，能够实现视频到视频和参考到视频的生成。它允许你将自己的图像注入输出视频，动画化角色，执行修复/扩展，以及继续现有视频。

## 概述

VACE 可能是目前可用的最强大的 Wan 模型之一。使用它，你可以：

- 将人物或物体注入场景
- 动画角色
- 执行视频修复和扩展
- 继续现有视频
- 将运动从一视频转移到另一视频
- 改变场景的风格，同时保留场景的结构

## 入门指南

### 模型选择

1. 从下拉菜单中选择 "Vace 1.3B" 或 "Vace 13B"
2. 注意：VACE 在启用 Riflex 选项的视频（最长 7 秒）上效果最佳

您也可以使用任何派生的 Vace 模型，例如 Vace Fusionix，或者将 Vace 与 Loras 加速器（如 Causvid）结合使用。

### 输入类型

#### 1\. 控制视频

控制视频是包含您想要操作指令的源材料。因此，Vace 期望在控制视频中看到一些关于预期处理类型的视觉提示：例如用其他内容替换某个区域，将 Open Pose 线框转换为人体动作，给某个区域上色，将图像区域的深度迁移等...

例如，如果你的控制视频包含颜色 127（灰色），它将被视为需要修复的区域，并用你的文本提示和/或参考图像（见下文）的内容替换。同样地，如果控制视频的帧包含 Open Pose 线框（基本上是一些首尾相连的直线，描述一个人的姿势），Vace 将根据文本提示和任何参考图像（见下文）自动将这个 Open Pose 转换为真实的人。

你可以使用 Vace 团队提供的标注工具自行构建控制视频（参见底部的 Vace 资源），或者选择 WanGP（推荐选项）根据你提供的信息动态生成 Vace 格式的控制视频。

WanGP 生成 Vace 控制视频需要以下信息：

- 一个 *控制视频* ：这个视频不应被标注工具修改，可以直接从 YouTube 或你的相机获取
- *控制视频处理* ：这是你希望在控制视频上应用的处理类型。例如， *转移人体动作* 会从你的视频中生成 Open Pose 信息，以便你可以将相同的动作转移到生成的角色上。如果你只想进行 *空间外绘* 或 *时间内绘/外绘* ，可以选择 *保持不变* 的处理。
- *处理区域* ：你可以将处理目标定位到特定区域。例如，即使控制视频中有多个人，你可能只想替换其中一个人。如果你决定定位一个区域，你需要提供一个 *视频蒙版* 。这类视频可以使用 WanGP 内置的 Matanyone 工具轻松创建（见下方的 Matanyone 文档）。WanGP 可以对蒙版内外应用不同类型的处理。

另一个优点是你可以将上述所有效果与 Outpainting 结合使用，因为如果你要求这样做，WanGP 会自动在控制视频中创建一个 Outpainting 区域。

默认情况下，如果控制视频的帧数少于你请求的帧数，WanGP 会要求 Vace 以控制视频的"相同精神"生成新帧。

请注意，在发生任何变化之前，控制视频和视频蒙版将被重新采样到 Vace 的帧率（通常为 16）并调整到你所请求的输出大小。

#### 2\. 参考图像

使用参考图像，您可以将自己选择的人物或物体注入视频中。您还可以强制图像在视频的特定帧号出现。

如果参考图像是人物或物体，建议开启背景移除功能，这将用白色替换背景。对于背景图像或特定位置注入的帧，则不需要这样做。

建议在文本提示中明确描述注入的人物或物体，以便 Vace 能够将参考图像与新生成的视频关联起来，这将增加您找到注入的人物或物体的机会。

### 理解 Vace 控制视频和蒙版格式

如上所述，WanGP 将根据您的指令调整控制视频和视频蒙版。您可以在生成预览框中预览新控制视频和视频蒙版的第一帧（只需点击缩略图）以检查您的请求是否被正确理解。您也可以通过启动带有 *\--save-masks* 命令的应用程序，要求 WanGP 将完整的生成控制视频和视频蒙版保存在 WanGP 的主文件夹中。

查看控制视频和视频蒙版的背景颜色：蒙版视频是最重要的，因为根据其像素的颜色，控制视频将被不同地解释。如果蒙版中的某个区域是黑色，则相应的控制视频区域将保持原样。相反，如果蒙版中的某个区域是纯白色，则该区域将应用 Vace 处理。如果没有蒙版视频，Vace 处理将应用于整个视频帧。该处理本身的性质将取决于控制视频中该区域的内容。

- 如果控制视频中的区域为灰色（127），则该区域将根据文本提示或图像参考被替换为新的内容
- 如果一个区域在 Wireframe Open Pose 格式中表示一个人，它将被一个由 Open Pose 描述的动作动画化的人所替换。这个人的外观将取决于文本提示或图像参考。
- 如果一个区域包含多种灰度，这些将被假定为表示不同的图像深度，Vace 将尝试生成位于相同深度的新内容

存在更多的 Vace 表示形式。有关所有不同的映射，请参考官方 Vace 文档。

### 其他处理

下面的大多数处理过程以及与控制视频相关的可以合并在一起。

- **时间外绘**  
	时间外绘需要一个现有的 *源视频* 或 *控制视频* ，它相当于添加缺失的帧。如果你使用一个源视频，则意味着你希望继续（新帧将被添加到该视频的末尾）；或者如果你提供一个控制视频，其中包含的帧数少于你请求生成的数量，这种情况也是隐含的。
- **时序修复**  
	通过时间修复，你要求 Vace 生成现有帧之间应该存在的缺失帧。有两种方法可以实现：
	- *注入参考图像* ：每张图像被注入到你选择的位置，Vace 将填补这些帧之间的空白
		- *控制视频中保留的帧* ：如果使用控制视频，你可以要求 WanGP 隐藏其中的一些帧，让 Vace 为控制视频的这些部分生成"替代帧"。
- **空间外绘**  
	这项功能会在控制视频现有帧的顶部、底部、左侧或右侧创建新内容。您可以通过指定相对于现有帧的额外内容百分比来设置每个方向的内容量。请注意，生成的视频将针对您指定的分辨率。如果该分辨率与您的控制视频分辨率对应，您可能会丢失细节。因此，使用空间外绘时选择更高分辨率可能更合适。  
	空间外绘有两种方法：
	- *注入参考帧* ：新内容将添加到注入帧周围
		- *控制视频* : 新内容将被添加到整个控制视频的所有帧上

### 示例 1：在一个视频中用另一个人替换其中一人，同时保留背景

1. 在 Vace 中，选择 *控制视频处理* = **转移人体姿态** ， *处理区域* = **蒙版区域**
2. 在 *Matanyone 视频蒙版创建器* 中，加载您的源视频，并创建一个蒙版，其中您目标了特定的人
3. 点击 *导出到控制视频输入和视频蒙版输入* ，以转移原始视频（现在成为 *控制视频* ）和黑色 & 白色蒙版（现在定义 *视频蒙版区域 ）*
4. 在 Vace 中，在 *参考图像* 中选中 **注入风景/人物/物体** 并上传一张或多张新人物的照片
5. 生成

这个方法也适用于同时处理多个人物（你只需要在 *Matanyone* 中为多个人物创建蒙版），如果新人物比原始人物大，你也可以调整滑块 *扩展/缩小蒙版* ，当然，如果你不想使用图像进行替换，也可以使用文本 *提示* 。

### 示例 2：更改某些角色的背景

1. 在 Vace 中，选择 *控制视频处理* = **修复** ， *处理区域* = **非遮罩区域**
2. 在 *Matanyone 视频遮罩创建器* 中，加载您的源视频，并创建一个遮罩，其中您选择了要保留的人物
3. 点击 *导出到控制视频输入和视频遮罩输入* ，将原始视频（现在成为 *控制视频* ）和黑白遮罩（现在定义 *视频遮罩区域 ）一起传输*
4. 生成

如果 *控制视频进程* 等于 **深度** ，那么背景虽然仍然会有所不同，但它的几何形状将与控制视频中的相似

### 示例 3：向左扩展视频并在这个新区域注入一个角色

1. 在 Vace 中，选择 *控制视频进程* = **保持不变**
2. *按百分比控制视频外扩* 在 *左* 输入框中输入值 40
3. 在 *参考图像* 中选择 **注入风景 / 人物 / 物体** 并上传一张或多张人物图片
4. 输入 *提示* 例如 "一个人正从左侧走来"（当然你需要一个更准确的描述）
5. 生成

### 创建面部/物体替换遮罩

Matanyone 是一个工具，用于生成需要与控制视频结合的视频遮罩。它非常实用，因为你只需要在第一帧中指示你想要遮罩的区域，它就会通过考虑运动来计算后续帧的遮罩区域。

1. 在 Matanyone 中加载你的视频
2. 点击第一帧中的面部或物体
3. 通过点击 **设置蒙版 来验证蒙版**
4. 通过点击“生成视频抠像”来生成控制视频的副本（便于传输）和新的蒙版视频
5. 通过 *导出到控制视频输入和视频掩码输入 导出到 VACE*

### 高级 Matanyone 技巧

- **负点提示** : 如果遮罩超出期望区域，从当前选择中移除部分内容
- **子遮罩** : 创建多个独立的遮罩，然后将它们组合。如果你难以精确选择所需内容，这可能很有用。

## 长视频窗口滑动

通过合并多个窗口生成最长1分钟的视频：视频越长，质量下降越明显。但如果生成的视频主要重复使用未修改的控制视频，这种效果将不太明显。

当此功能启用时，需要注意 Vace 的每个位置参数（ *注入参考帧* 的位置， *控制在控制视频中保留的帧* 的位置）都与第一个窗口的第一帧相关。这很方便，因为改变滑动窗口的大小不会产生任何影响，并且允许您预先定义所有窗口的注入帧。

同样地，如果你通过提供 *源视频* 来使用 *继续视频文件* ，这个源视频将被视为第一个窗口，位置参数将相对于源视频的第一帧进行计算。此外， *重叠窗口大小* 参数将对应于源视频中被暂时外画以生成新内容的帧数。

### 工作原理

- 每个窗口使用控制视频的相应时间段
- 示例：0-4秒控制视频→第一个窗口，4-8秒→第二个窗口，以此类推。
- 自动重叠管理确保平滑过渡

### 公式

这个公式给出了特定滑动窗口数量下的生成帧数：

```pgsql
Generated Frames = [Nb Windows - 1] × [Window Size - Overlap - Discard] + Window Size
```

### 多行提示（实验性）

如果你启用 *文本提示通过回车符将被用于新的滑动窗口* ，你可以预先为每个窗口定义不同的提示：

- 每个提示通过回车符分隔
- 每行提示将用于不同的窗口
- 如果窗口多于提示行，最后一行会重复

## 推荐设置

### 质量设置

- **跳过层引导** ：使用默认配置打开以获得更好的效果（在有 Causvid 的 FusioniX 中无配置时无用）
- **长提示** ：使用详细描述，特别是对于参考图像中未包含的背景元素
- **步骤** ：使用至少 15 步以获得良好质量，如果使用原始 Vace 模型，则使用 30 步以上以获得最佳效果。但使用 Vace Funsionix 或使用 Causvid 或 Self-Forcing 等 LoRA 时，8-10 步就足够了。

### 滑动窗口设置

对于非常长的视频，正确配置滑动窗口：

- **窗口大小** ：为你的内容设置适当的持续时间
- **重叠帧数** ：足够长以保持运动连续性，足够短以避免模糊传播
- **丢弃最后帧** : 从每个窗口中至少删除 4 帧（VACE 1.3B 倾向于模糊最后帧）
- **添加重叠噪声** : 可能或不可能随时间减少质量退化

### 背景移除

WanGP 包括自动背景移除选项：

- 用于包含人物/物体的参考图像
- **不要使用** 此功能用于风景/场景参考图像（第一个参考图像）
- 如果您对自动背景移除工具不满意，可以使用 Matanyone 的图像版本进行精确的背景移除

## 故障排除

### 结果质量差

1. 使用更长、更详细的提示
2. 启用跳过层指导
3. 增加步数（30+）
4. 检查参考图像质量
5. 确保正确创建掩码

### Windows 不一致

1. 增加重叠帧
2. 在窗口间使用一致的提示
3. 向重叠帧添加噪声
4. 如果丢失过多内容，减少丢弃帧

### 内存问题

1. 使用 VACE 1.3B 而不是 13B
2. 减少视频长度或分辨率
3. 减小窗口大小
4. 启用量化

### 模糊结果

1. 减少重叠帧
2. 增加丢弃最后帧
3. 使用更高分辨率的参考图像
4. 检查控制视频质量

## 最佳效果提示

1. **详细提示** ：描述场景中的所有元素，特别是参考图像中未包含的部分
2. **高质量参考图像** ：使用高分辨率、光线充足的参考图像
3. **精确遮罩** ：花时间使用 Matanyone 创建精确的遮罩
4. **迭代方法** ：从短视频开始，然后扩展成功结果
5. **背景准备** : 从对象/人物参考图像中移除复杂背景
6. **一致的光照** : 使参考图像与预期场景之间的光照相匹配
