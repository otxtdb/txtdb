本节将说明如何使用 HTTP 服务器 [Apache](https://httpd.apache.org/) 设置 SearXNG 实例。如果你使用了[安装脚本](https://docs.searxng.org/admin/installation-scripts.html#installation-scripts)并且没有特殊偏好，你可以使用 [searxng.sh](https://docs.searxng.org/utils/searxng.sh.html#searxng-sh-overview):

$ sudo \-H ./utils/searxng.sh install apache

如果你对设置 Apache 有特殊兴趣或问题，下一节可能会给你一些指导。

## [The Apache HTTP server](https://docs.searxng.org/admin/#id5)[¶](https://docs.searxng.org/admin/#the-apache-http-server "Link to this heading")

如果 [Apache](https://httpd.apache.org/) 没有安装，现在就安装它。如果 [apache](https://httpd.apache.org/) 对你来说很新， [入门指南](https://httpd.apache.org/docs/current/en/getting-started.html) 、 [配置文件](https://httpd.apache.org/docs/current/en/configuring.html)和[用于描述指令的术语](https://httpd.apache.org/docs/current/en/mod/directive-dict.html) 文档提供了初步的指引。此外还有一个列表。 [Apache 指令](https://httpd.apache.org/docs/trunk/mod/directives.html) *随身携带* 。

sudo \-H apt-get install apache2

sudo \-H pacman \-S apache
sudo \-H systemctl enable httpd
sudo \-H systemctl start http

sudo \-H dnf install httpd
sudo \-H systemctl enable httpd
sudo \-H systemctl start httpd

现在在 [http://localhost](http://localhost/) 你应该能看到某种 *Welcome* 或 *Test* 页面。这个默认站点是如何配置的，取决于 Linux 发行版（比较 [Apache 指令](https://httpd.apache.org/docs/trunk/mod/directives.html) ）。

less /etc/apache2/sites-enabled/000-default.conf

在这个文件中，有一行设置 [DocumentRoot](https://httpd.apache.org/docs/trunk/mod/core.html#documentroot) 指令：

DocumentRoot /var/www/html

而 *welcome* 页面是位于 `/var/www/html/index.html` 的 HTML 文件。

less /etc/httpd/conf/httpd.conf

In this file, there is a line setting the [DocumentRoot](https://httpd.apache.org/docs/trunk/mod/core.html#documentroot) directive:

DocumentRoot "/srv/http"
<Directory "/srv/http"\>
    Options Indexes FollowSymLinks
    AllowOverride None
    Require all granted
</Directory>

The *welcome* page of Arch Linux is a page showing the directory located at `DocumentRoot`. This *directory* page is generated by the Module [mod\_autoindex](https://httpd.apache.org/docs/2.4/mod/mod_autoindex.html):

LoadModule autoindex\_module modules/mod\_autoindex.so
...
Include conf/extra/httpd-autoindex.conf

less /etc/httpd/conf/httpd.conf

In this file, there is a line setting the `DocumentRoot` directive:

DocumentRoot "/var/www/html"
...
<Directory "/var/www"\>
    AllowOverride None
    \# Allow open access:
    Require all granted
</Directory>

On fresh installations, the `/var/www` is empty and the *default welcome page* is shown, the configuration is located at:

less /etc/httpd/conf.d/welcome.conf

### [Debian 的 Apache 布局](https://docs.searxng.org/admin/#id6) [¶](https://docs.searxng.org/admin/#debian-s-apache-layout "Link to this heading")

请注意，Debian 的 Apache 布局与标准的 Apache 配置有很大不同。详情请参阅 [apache2.README.Debian](https://salsa.debian.org/apache-team/apache2/raw/master/debian/apache2.README.Debian) ( `/usr/share/doc/apache2/README.Debian.gz` )。在 Debian 上您应该知道的某些命令：

- [apache2ctl](https://manpages.debian.org/jump?q=apache2ctl)：Apache HTTP 服务器控制接口
- [a2enmod](https://manpages.debian.org/jump?q=a2enmod), [a2dismod](https://manpages.debian.org/jump?q=a2dismod): 开启/关闭模块
- [a2enconf](https://manpages.debian.org/jump?q=a2enconf), [a2disconf](https://manpages.debian.org/jump?q=a2disconf): 开启/关闭配置
- [a2ensite](https://manpages.debian.org/jump?q=a2ensite), [a2dissite](https://manpages.debian.org/jump?q=a2dissite): 开启/关闭站点

### [Apache 模块](https://docs.searxng.org/admin/#id7) [¶](https://docs.searxng.org/admin/#apache-modules "Link to this heading")

要加载额外的模块，在大多数发行版中，您需要取消注释包含相应 [LoadModule](https://httpd.apache.org/docs/mod/mod_so.html#loadmodule) 指令的行，除了在 [Debian 的 Apache 布局](https://docs.searxng.org/admin/#debian-s-apache-layout) 中。

[Debian 的 Apache 布局](https://docs.searxng.org/admin/#debian-s-apache-layout)使用 [a2enmod](https://manpages.debian.org/jump?q=a2enmod) 和 [a2dismod](https://manpages.debian.org/jump?q=a2dismod) 来激活或禁用模块：

sudo \-H a2enmod ssl
sudo \-H a2enmod headers
sudo \-H a2enmod proxy
sudo \-H a2enmod proxy\_http
sudo \-H a2enmod proxy\_uwsgi

In the `/etc/httpd/conf/httpd.conf` file, activate [LoadModule](https://httpd.apache.org/docs/mod/mod_so.html#loadmodule) directives:

LoadModule ssl\_module           modules/mod\_ssl.so
LoadModule headers\_module       modules/mod\_headers.so
LoadModule proxy\_module         modules/mod\_proxy.so
LoadModule proxy\_http\_module    modules/mod\_proxy\_http.so
LoadModule proxy\_uwsgi\_module   modules/mod\_proxy\_uwsgi.so

In the `/etc/httpd/conf/httpd.conf` file, activate [LoadModule](https://httpd.apache.org/docs/mod/mod_so.html#loadmodule) directives:

LoadModule ssl\_module           modules/mod\_ssl.so
LoadModule headers\_module       modules/mod\_headers.so
LoadModule proxy\_module         modules/mod\_proxy.so
LoadModule proxy\_http\_module    modules/mod\_proxy\_http.so
LoadModule proxy\_uwsgi\_module   modules/mod\_proxy\_uwsgi.so

### [Apache 站点](https://docs.searxng.org/admin/#id8) [¶](https://docs.searxng.org/admin/#apache-sites "Link to this heading")

在 [Debian 的 Apache 布局](https://docs.searxng.org/admin/#debian-s-apache-layout)中，你创建一个 `searxng.conf` 文件，包含 `<Location /searxng >` 指令，并将此文件保存到 *sites available* 文件夹中的 `/etc/apache2/sites-available`。要启用 `searxng.conf`，使用 [a2ensite](https://manpages.debian.org/jump?q=a2ensite)：

sudo \-H a2ensite searxng.conf

In the `/etc/httpd/conf/httpd.conf` file add a [IncludeOptional](https://httpd.apache.org/docs/mod/core.html#includeoptional) directive:

IncludeOptional sites-enabled/\*.conf

Create two folders, one for the *available sites* and one for the *enabled sites*:

mkdir \-p /etc/httpd/sites-available
mkdir \-p /etc/httpd/sites-enabled

Create configuration at `/etc/httpd/sites-available` and place a symlink to `sites-enabled`:

sudo \-H ln \-s /etc/httpd/sites-available/searxng.conf \\
              /etc/httpd/sites-enabled/searxng.conf

In the `/etc/httpd/conf/httpd.conf` file add a [IncludeOptional](https://httpd.apache.org/docs/mod/core.html#includeoptional) directive:

IncludeOptional sites-enabled/\*.conf

Create two folders, one for the *available sites* and one for the *enabled sites*:

mkdir \-p /etc/httpd/sites-available
mkdir \-p /etc/httpd/sites-enabled

Create configuration at `/etc/httpd/sites-available` and place a symlink to `sites-enabled`:

sudo \-H ln \-s /etc/httpd/sites-available/searxng.conf \\
              /etc/httpd/sites-enabled/searxng.conf

## [Apache 的 SearXNG 站点](https://docs.searxng.org/admin/#id9) [¶](https://docs.searxng.org/admin/#apache-s-searxng-site "Link to this heading")

uWSGI

使用 [mod\_proxy\_uwsgi](https://uwsgi-docs.readthedocs.io/en/latest/Apache.html#mod-proxy-uwsgi) / 不再使用旧的 [mod\_uwsgi](https://uwsgi-docs.readthedocs.io/en/latest/Apache.html#mod-uwsgi)。

要将传入的请求代理到 SearXNG 实例，Apache 需要的 [mod\_proxy](https://httpd.apache.org/docs/current/mod/mod_proxy.html) 模块 ([Apache 模块](https://docs.searxng.org/admin/#apache-modules) ).

HTTP 标头

使用 [ProxyPreserveHost](https://httpd.apache.org/docs/trunk/mod/mod_proxy.html#proxypreservehost)，传入的 `Host` 头会被传递给代理的主机。

根据你的 SearXNG 安装监听的内容，你需要一个 http [mod\_proxy\_http](https://httpd.apache.org/docs/current/mod/mod_proxy_http.html)) 或 socket ([mod\_proxy\_uwsgi](https://uwsgi-docs.readthedocs.io/en/latest/Apache.html#mod-proxy-uwsgi)) 与上游通信。

安装脚本[安装脚本](https://docs.searxng.org/admin/installation-scripts.html#installation-scripts)安装了[参考配置](https://docs.searxng.org/admin/installation-searxng.html#use-default-settings-yml)和默认监听套接字的 [uWSGI 配置](https://docs.searxng.org/admin/installation-uwsgi.html#uwsgi-setup) 。你可以像示例中那样安装和激活自己的 `searxng.conf`。 [Apache 站点](https://docs.searxng.org/admin/#apache-sites) .

\# -\*- coding: utf-8; mode: apache -\*-

LoadModule ssl\_module           /mod\_ssl.so
LoadModule headers\_module       /mod\_headers.so
LoadModule proxy\_module         /mod\_proxy.so
LoadModule proxy\_uwsgi\_module   /mod\_proxy\_uwsgi.so
\# LoadModule setenvif\_module      /mod\_setenvif.so
#
\# SetEnvIf Request\_URI /searxng dontlog
\# CustomLog /dev/null combined env=dontlog

<Location /searxng\>

    Require all granted
    Order deny,allow
    Deny from all
    \# Allow from fd00::/8 192.168.0.0/16 fe80::/10 127.0.0.0/8 ::1
    Allow from all

    \# add the trailing slash
    RedirectMatch  308 /searxng$ /searxng/

    ProxyPreserveHost On
    ProxyPass unix:/usr/local/searxng/run/socket|uwsgi://uwsgi-uds-searxng/

    \# see flaskfix.py
    RequestHeader set X-Forwarded-Proto %{REQUEST\_SCHEME}s
    RequestHeader set X-Script-Name /searxng

    \# see botdetection/trusted\_proxies.py
    RequestHeader set X-Real-IP %{REMOTE\_ADDR}s
    RequestHeader append X-Forwarded-For %{REMOTE\_ADDR}s

</Location>

\# To serve the static files via the HTTP server
#
\# Alias /searxng/static/ /usr/local/searxng/searxng-src/searx/static/

\# -\*- coding: utf-8; mode: apache -\*-

LoadModule ssl\_module           /mod\_ssl.so
LoadModule headers\_module       /mod\_headers.so
LoadModule proxy\_module         /mod\_proxy.so
LoadModule proxy\_http\_module    /mod\_proxy\_http.so
\# LoadModule setenvif\_module      /mod\_setenvif.so
#
\# SetEnvIf Request\_URI /searxng dontlog
\# CustomLog /dev/null combined env=dontlog

<Location /searxng\>

    Require all granted
    Order deny,allow
    Deny from all
    \# Allow from fd00::/8 192.168.0.0/16 fe80::/10 127.0.0.0/8 ::1
    Allow from all

    \# add the trailing slash
    RedirectMatch  308 /searxng$ /searxng/

    ProxyPreserveHost On
    ProxyPass http://127.0.0.1:8888

    \# see flaskfix.py
    RequestHeader set X-Forwarded-Proto %{REQUEST\_SCHEME}s
    RequestHeader set X-Script-Name /searxng

    \# see botdetection/trusted\_proxies.py
    RequestHeader set X-Real-IP %{REMOTE\_ADDR}s
    RequestHeader append X-Forwarded-For %{REMOTE\_ADDR}s

</Location>

\# To serve the static files via the HTTP server
#
\# Alias /searxng/static/ /usr/local/searxng/searxng-src/searx/static/

重启服务：

sudo \-H systemctl restart apache2
sudo \-H service uwsgi restart searxng

sudo \-H systemctl restart httpd
sudo \-H systemctl restart uwsgi@searxng

sudo \-H systemctl restart httpd
sudo \-H touch /etc/uwsgi.d/searxng.ini

## [禁用日志](https://docs.searxng.org/admin/#id10) [¶](https://docs.searxng.org/admin/#disable-logs "Link to this heading")

为了更好的隐私保护，你可以禁用 Apache 日志。在上述示例中激活其中一行，并 [重启 apache](https://docs.searxng.org/admin/#restart-apache)：

SetEnvIf Request\_URI "/searxng" dontlog
\# CustomLog /dev/null combined env=dontlog

  
`CustomLog` 指令会禁用整个（虚拟）服务器的日志，当服务的 URL 没有路径组件（`/searxng`）时使用它，即当 SearXNG 位于根目录（`/`）时。
