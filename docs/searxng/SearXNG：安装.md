*您有太多的选择* ，选择您喜欢的安装方式。


- [安装容器](https://docs.searxng.org/admin/installation-docker.html#installation-container)
- [安装脚本](https://docs.searxng.org/admin/installation-scripts.html#installation-scripts)
- [逐步安装](https://docs.searxng.org/admin/installation-searxng.html#installation-basic)

  
[逐步安装](https://docs.searxng.org/admin/installation-searxng.html#installation-basic)是*如何构建 SearXNG 实例* （参见 [uWSGI 设置](https://docs.searxng.org/admin/architecture.html#architecture-uwsgi) ）的绝佳示例。如果你没有特别的偏好，建议使用[安装容器](https://docs.searxng.org/admin/installation-docker.html#installation-container)或 [安装脚本](https://docs.searxng.org/admin/installation-scripts.html#installation-scripts)

注意

SearXNG 发展迅速，你应该定期阅读我们的[迁移并保持关注！](https://docs.searxng.org/admin/update-searxng.html#migrate-and-stay-tuned) 部分。如果你想升级现有的实例，你应该先阅读这一部分！
