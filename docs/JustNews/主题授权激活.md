WPCOM所出售的商业主题需要进行激活和授权才能使用。授权只是为了确认是我们的付费用户，并且便于后续更新版本的推送。

### 激活码获取

主题购买后都会生成一个激活码，进入WPCOM[用户中心>我的服务](https://www.wpcom.cn/member/product)，点击`授权下载`以后即可看到，如图：

![激活码获取](https://www.wpcom.cn/uploads/2015/11/14483770757823.png)

### 主题安装

在上面的步骤中我们获取到了激活码，同时主题下载也是在这个页面。下载好主题以后，在wordpress后台`外观>主题>添加>上传主题`里面上传主题压缩包文件，然后启用主题即可完成主题的安装。

 安装教程

主题安装如有问题可以查看这里更详细的教程：[第三方wordpress主题安装教程](https://www.wpcom.cn/help/6.html)

### 主题激活

安装主题后，进入wordpress后台左边导航的`主题激活`，填写WPCOM注册的邮箱和你获取的激活码完成激活操作。在成功授权后将自动跳转到主题设置页面。 ![主题激活](https://www.wpcom.cn/uploads/docs/auth.png)

### 常见问题

激活过程中经常有用户会遇到激活失败的情况，**主要原因有**：

1. 激活需要在外网环境下，也就是说不能在本机电脑上激活测试。这是由于激活是一个认证的过程，授权服务器会对请求进行验证，如果是在本地测试，我们的授权服务器可能无法连接到您的内网环境，也就无法完成验证和激活；
2. 如果使用的是万网/阿里云的虚拟主机，并使用默认提供的二级测试域名激活，也是无法完成授权的。万网/阿里云默认提供的域名访问需要输入FTP帐号信息才能访问，所以也是无法完成授权；
3. 激活请求被拦截。由于部分客户网站的服务器使用了安全软件（或者CDN），会对请求进行过滤和拦截，目前发现部分使用`安全狗`、`宝塔防火墙`的服务器网站激活会出现被拦截的情况，建议暂时先关闭此类软件再激活。我们后续也将跟进优化此问题。
4. 网络问题。这种情况很少出现，但也是有可能，因为实际使用中我们发现有些用户使用的服务器网络非常不稳定，并且在海外，所以激活请求超时的情况比较常见，建议多试几次。

#### 解决办法：

1. 不要在本地进行测试，可以上传到线上服务器进行测试；
2. 如果出于测试需要不想使用正式域名（或者正式域名正在备案），可以使用已备案的域名随便解析一个二级域名用于测试激活，后续正式上线再更换成正式域名；
3. 若安装了安全软件或者CDN，比如`安全狗`、`宝塔防火墙`，请先停用相关服务再激活；
4. 如果是因为网络问题无法激活，建议您可以提交服务单，技术人员会提供进一步协助

### 授权域名个数说明

每个主题我们支持`1个网站`授权（按网站数量计算），子域名和顶级域名如果是单独的网站都会计算数量，如有更多网站需要授权，则需要另外支付授权费用或者重新购买主题，具体请联系客服。

如果前期测试过程中使用了测试域名，网站上线后需要更换成正式域名，可以提交服务单申请取消之前的测试域名授权，取消之后按照正常的授权操作重新激活即可。
