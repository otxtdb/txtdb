监控列表收集所有您的监控。使用它来查看、添加和管理它们。

  
这是您的监控列表将显示的样子：

![Watchlist - List of monitors](https://distill.io/docs/web-monitor/what-is-watchlist/images/watchlist.png "Watchlist - List of monitors")

##   
什么是监控？

  
监控是一个具有唯一 URL 的单一网页，添加到 Distill 中以监视变化。

##   
如何查看监控列表？

  
您可以通过浏览器扩展或网页应用查看和管理监控列表。当您通过扩展登录时，Distill 会将所有监控同步到云端，以便您可以在任何地方访问监控列表。

  
如果使用浏览器扩展，点击工具栏中的 Distill 图标 → 点击“前往监控列表”。

![Distill Menu Popup](https://distill.io/docs/web-monitor/what-is-watchlist/images/go-to-watchlist.png "Distill Menu Popup")

  
如果使用 Web 应用，请[登录](https://accounts.distill.io/login)您的 Distill 账户以查看监控列表。
