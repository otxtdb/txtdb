您可以在 Distill 中**导出**和**导入**监视器，以：

- 批量添加监控 URL
- 创建数据的手动备份
- 在不同账户间转移监控

>   
> 我们建议进行**定期备份** ，以防止意外数据丢失。

---

##   
导出格式：JSON 与 CSV

| 格式 | 用例 |
| --- | --- |
| **JSON** | 最适合**备份** 。包含每个监控器的配置。 |
| **CSV** | 最适合**批量导入** 。上传多个 URL 进行全页监控。      (不包含监控器配置。) |

---

##   
导出监视器 (JSON)

1. 在你的**监控列表**中，使用复选框选择你想要导出的监控。  
	*  
	提示：使用搜索进行筛选，然后全选。*
2. 点击**汉堡菜单 (≡)** → **导出 → JSON**。
	![Downloading JSON of selected monitor](https://distill.io/docs/web-monitor/how-to-export-and-import-monitors/images/selected-seives-export.jpg)
3. 在弹出的窗口中，选择：
	- **已选择的监控器** （基于您的选择），或
	- **所有监控器** （导出整个监控列表）。  
		  
		然后点击**下载** 。
	>   
	> **注意：** 与监控器相关的操作不包括在内。您可以在导入时重新添加它们。
	![Downloading JSON of selected monitors](https://distill.io/docs/web-monitor/how-to-export-and-import-monitors/images/download-seive.jpg)
4. 导出的文件将保存在您系统的**下载**文件夹中。

---

##   
导入监视器（JSON）

1. 在**监视列表**中，点击**汉堡菜单（≡）** → **导入 → JSON**。
	![Import monitor JSONs to watchlist](https://distill.io/docs/web-monitor/how-to-export-and-import-monitors/images/import-monitor-steps.jpg)
2. 选择以下选项之一：
	- 从你的设备中选择 **JSON 文件** ，或
	- **将 JSON** 直接粘贴到编辑器中。
	![Import monitor to watchlist](https://distill.io/docs/web-monitor/how-to-export-and-import-monitors/images/import-monitor.jpg)
3. 在编辑器中预览文件内容，以确认它们是否正确。
	![Import monitor to watchlist](https://distill.io/docs/web-monitor/how-to-export-and-import-monitors/images/json-import-preview.jpg)
4. 点击 **下一步** 以可选：
	- 通过 **添加操作** 添加常用操作（适用于所有导入的监控器），或
	- 跳过此步骤。
	![Import monitors and add action](https://distill.io/docs/web-monitor/how-to-export-and-import-monitors/images/adding-action-import.jpg)
5. 选择这些显示器将运行的设备（例如，云或本地）。
6. 点击 **Import**。

---

##   
导出监视器（CSV）

1. 在你的**监控列表**中，使用复选框选择监控。
	- 全部不勾选以导出整个监控列表。
2. 点击**汉堡菜单 (≡)** → **导出 → CSV**。
3. 点击**下载** 。

---

##   
通过 CSV 批量 URL 导入

  
在您的 CSV 文件中包含以下列以导入 URL 列表：

- **姓名**
- **URL**
- **标签** *(可选；逗号分隔，例如 `  测试,北美洲  `)*
- **内容类型** *(可选；如未提供，默认为网页)*

  
支持的 `Content Type` 值：

| 类型 | 代码 |
| --- | --- |
| 网页 | 2 |
| XML | 4 |
| 输入 | 5 |
| PDF | 7 |
| DOC | 8 |
| JSON | 9 |

**  
示例 CSV（包含标题+2 行）：**

```csv
Name,URL,Labels,Content Type
Distill Blog,https://distill.io/blog/,News,2
Example Docs,https://example.com/file.pdf,"Docs,Team",7
```

###   
导入监视器（CSV）

  
使用 **CSV 导入**功能，可以一次性创建大量**整页监控器** 。

  
👉 使用我们的 [CSV 模板](https://distill.io/docs/web-monitor/how-to-export-and-import-monitors/bulk-import-csv-template.csv)开始操作。

1. 在您的**监控列表**中，点击**汉堡菜单(≡)** → **导入 → CSV**。
	![Export monitors to CSV file](https://distill.io/docs/web-monitor/how-to-export-and-import-monitors/images/import-to-csv.jpg)
2. 选择：
	- **如果你已有 CSV 文件，请选择该文件** ，或者
	- 使用模板创建一个。
	![Import monitors with csv](https://distill.io/docs/web-monitor/how-to-export-and-import-monitors/images/import-csv.jpg)
3. Distill 将自动检测列属性。如有需要，您也可以手动匹配它们。
	![Import monitors with csv](https://distill.io/docs/web-monitor/how-to-export-and-import-monitors/images/column-headers.jpg)
4. 点击 **下一步 → 配置选项和操作** 。
	- （可选）添加一个常用操作。
	- 点击 **Import**。

##   
导出中包含的数据

| 数据字段 | JSON 导出 | CSV 导出 | 注释 |
| --- | --- | --- | --- |
| 监控 URL | ✓ | ✓ |  |
| 监控名称 | ✓ | ✓ |  |
| 内容类型 | ✓ | ✓ | CSV 值：网页、订阅源、PDF、Word、JSON、站点地图、XML |
| 检查计划 | ✓ | — |  |
| 时间戳 | ✓ | — | JSON 包含一个通用时间戳；CSV 分为创建/修改 |
| 条件 | ✓ | — | 仅 JSON |
| 标签/标记 | ✓ | ✓ | CSV 列名： **监控标签** |
| 配置（选择器） | ✓ | — |  |
| 监控状态（开/关） | ✓ | — |  |
| 创建于 | — | ✓ | 仅 CSV |
| 最后检测到的变更时间 | — | ✓ | 仅 CSV |
| 文本（监控片段） | — | ✓ | 仅 CSV |
| 错误状态 | — | ✓ | 仅限 CSV |

  
⚠️ 导出中不包含：操作和变更历史。您可以在导入时设置常用操作。
