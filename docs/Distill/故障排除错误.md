### SELECTION\_EMPTY

通过点击日志中的“查看详情”链接查看结账页面快照。快照是在页面加载时被截取的，但 Distill 找不到页面中选定的内容。

`SELECTION_EMPTY` 错误的一些常见原因包括：

1. 之前显示器工作正常，但开始出现这个错误。之前选中的元素可能已不存在于页面上。你可以创建一个新显示器，或者用视觉选择器更改现有显示器的选择，看看是否能正常工作。
2. 当选定元素在延迟后加载时，这可能发生在元素是动态的，加载延迟后才会启动。在这种情况下，你可以在配置中添加延迟。要添加延迟，可以进入现有显示器 [的配置](https://distill.io/docs/web-monitor/config-and-advanced-monitor-options/) ，把延迟改成某个值。这个数值以秒为单位。通过设置 `延迟 ` ，Distill 会等待页面加载的延迟期，然后检查元素。
3. 当你选择了带有文本的元素，但预期它会变成无文本，而你想收到无文本变化的提醒时，你可以在选择中加入额外的元素。一个很好的例子是页面的 `<title>` 元素。标签的 XPath 选择器是 title，CSS 选择器是 `title` 。
4. 当页面阻挡了来自 Distill 服务器的访问时。在这种情况下，页面向服务器发送错误响应。你可以用代理在云端运行检查。请查看： [https://distill.io/docs/web-monitor/monitor-webpage-using-proxy-servers/](https://distill.io/docs/web-monitor/monitor-webpage-using-proxy-servers/) 。或者，你也可以用本地检查在浏览器中运行显示器。

### E\_ASSERT

当自定义断言条件在宏/爬取器执行过程中失败时，会触发该错误。

- 这意味着你的记录器中某个步骤期望某事是真的，但条件没有被满足。
- 缺少预期的元素或内容
- 页面加载方式与预期不同
- 断言逻辑需要更新

##### 要修正：

- 在记录器中打开断言步骤
- 检查条件（例如 element\_exists（html））
- 如果断言不再适用，可以调整或删除
- 回放录音器测试步骤是否通过

![assert-failed.png](https://distill.io/docs/web-monitor/troubleshooting-errors/images%2Fassert-failed.png)

### E\_BROWSER

当 Distill 的扩展无法打开新的浏览器标签页或窗口时，通常会出现错误——通常是由于浏览器或其设置的问题。

- 浏览器被屏蔽标签页或窗口创建。
- 进入 `设备设置 > 高级` 设置，将“加载无法在后台加载的页面”改为 **窗口** 或 **置顶窗口** 。
- 刷新扩展或浏览器。
- 试着重启浏览器。

当验证码验证失败或需要验证但未正确完成时，会触发该错误。

- 使用代理服务器以避免验证码（CAPTCHA）挑战
- 使用专用的云设备。更多信息请参见 [“使用专用云设备”检查](https://distill.io/docs/web-monitor/dedicated-cloud-devices/) 。

### E\_CONFIG

`E_CONFIG` 是显示器配置错误。当监视器配置无效时，它会被记录。以下是导致此错误的一些常见原因：

- 显示器配置有问题或者不是有效的 JSON。
- 监视器的 URL 要么是空的，要么是无效的。
- 对于网页显示器，当显示器的选择器类型无效时，我们支持 XPATH、CSS 和 JS 选择器。 ![supported-selector-types.png](https://distill.io/docs/web-monitor/troubleshooting-errors/images%2Fsupported-selector-types.png)

### E\_CONNREFUSED

当远程服务器拒绝接受客户端的连接时，就会发生这种情况。这种错误在任何类型的显示器上都可能遇到。如果你在网页监视器上遇到这个错误，请在 [配置](https://distill.io/docs/web-monitor/config-and-advanced-monitor-options/ "config") 中将 `动态` 设置为 `true` 。 应该能修正这个错误。

### E\_CONNRESET

这通常是因为网络连接意外重置，通常是由于服务器或网络问题引起的。

### E\_CONTEXT404

该错误表示无法找到所请求的上下文或资源。请核实网址是否正确，或检查页面结构是否更改。

### E\_CRAWL\_URL\_LIMIT\_EXCEEDED

当爬虫超过设定的 URL 限制时，通常由于该限制对所找到的链接数量来说过低，就会发生在 Sitemap 监控器中。URL 限制设置限制了爬虫可以访问的 URL 数量。如果爬取过程中实际发现的 URL 数量超过该限制，监控器会抛出该错误。

从以下任一地点提高网址限制：

- 查看爬虫：打开显示器，进入爬虫设置，更新 URL 限制字段。
- 观看列表顶部栏 → 爬虫选项：打开相关爬虫并直接更新网址限制。 ![crawl-url-limit.png](https://distill.io/docs/web-monitor/troubleshooting-errors/images%2Fcrawl-url-limit.png)

### E\_DOC\_PARSE

带有 `Word 文档` 类型的监视器可能会遇到此错误。当 Word 文档无法正确解析时，就会发生这种情况。这种错误可能发生的情形包括：

- 该文档不是有效的 Word 文档。
- 文件损坏了。
- 确保不password-protected.

### E\_ELEMENT\_NOT\_FOUND

找不到页面元素。这可能由多种原因引起，例如：

- 该元素不存在于页面上。
- 该元素存在，但不可见或无法接触。
- 该元素的选择器错误或已更改。你可以试着用视觉选择器打开显示器，模拟并检测出错的选择器。

### E\_FEED

当解析数据流出现错误时， ` 会记录 E_FEED` 。当推送的 URL 返回的内容不是有效的推送时，就会发生这种情况。你可以在显示器配置里检查该订阅源的 URL，确认是否返回有效的订阅源。

### E\_FIELDS\_NOT\_FOUND

当 JSON 选择器面板中没有选择字段时，会出现此错误。

- 在 `“选择属性 ` ”左侧面板中至少选择一个属性
- 如果没有选择任何内容，蒸馏后的响应将为空 {}

![fields-not-found.png](https://distill.io/docs/web-monitor/troubleshooting-errors/images%2Ffields-not-found.png)

### E\_FILTER\_HTML

当系统无法从网页中提取所选内容时，就会发生这种情况。

- 检查页面结构是否发生变化
- 使用可视化选择器重新选择内容
- 添加动态内容加载的延迟

### E\_FORMAT

当数据格式不符或无法正确解析时，会出现此错误：例如，预期数字但接收到字符串。

- 如果源页面结构发生变化或返回意外数据，使用受管爬虫时就会发生这种情况。
- 如果你用的是管理式刮刀， [请联系客服](https://distill.io/docs/contact-us/ "contact") 寻求帮助。
- 如果你用的是用户自制抓取器，请检查记录器中的解析器部分，并相应更新预期类型。

### E\_FRAME\_REQUEST

当 Distill 无法找到被选中内容的监控帧时，它会在 E\_FRAME\_REQUEST 中出错。

解决 方案：

- 监视器在后续检查中应能成功检查。
- 在配置里加个 `延迟 ` 。
- 检查页面是否会重定向，并相应更新显示器的网址。

### E\_INTERRUPT

当抓取作或宏执行在完成前被中断时，通常由于网络连接问题、超时，就会发生这种情况。

- 检查中断是否是因为超时设置
- 检查你的网络连接，重试作，或确认目标网站是否可访问。

### E\_INVALID\_PARAMS

当显示器预期某个特定类型或格式，但收到的格式不再支持时，通常因使用了旧版本的应用程序而出现。

- [将 Distill 应用升级](https://distill.io/apps/web-monitor/) 到最新版本以确保兼容性。
- 升级后，再试着运行显示器。

### E\_INVALID\_TYPE

这种情况发生在系统预期有某种数据但得到的是其他类型——比如文件被移动、删除或服务格式变更时。例如，你设置了对 PDF、XML 或 JSON 文件的监控，但系统现在收到的是一个网页或错误信息。

- 检查一下浏览器里 URL 是否还能以预期格式（PDF、JSON、XML 等）打开。
- 如果 URL 显示的内容不符，请查找正确的新 URL。
- 在“选项页面”中更新 URL 并添加正确的新链接。

## E\_JAVASCRIPT

当网页上执行 JavaScript 选择器时，通常会被记录。

1. 请查看错误信息详情，了解具体问题所在。
2. 确认你引用的任何元素或变量确实存在于页面上。

![javascript-selector.png](https://distill.io/docs/web-monitor/troubleshooting-errors/images%2Fjavascript-selector.png)

### E\_MACRO

当宏运行时出现错误， ` 记录会 E_MACRO` 。这种情况可以在宏观的任何阶段发生。要查看错误详情，可以在错误页面查看宏步骤的错误。点击检查 [日志](https://distill.io/docs/web-monitor/how-to-view-log-of-checks/) 中的 `“查看详情 ` ”链接 前往错误页面。

![macro-error-page.png](https://distill.io/docs/web-monitor/troubleshooting-errors/images%2Fmacro-error-page.png)

宏最后出错的步骤可以在错误详情部分找到。页面的快照会在遇到错误的那一刻进行。这有助于编辑宏，以应对之前未知的场景。

### E\_MISSING\_INPUT

所需的宏输入字段为空。

- 确保所有必需字段都已在宏的选项页面输入字段中填写。
- 检查是否有缺失参数。
- 核实输入字段名称和值是否正确。

![missing-input.png](https://distill.io/docs/web-monitor/troubleshooting-errors/images%2Fmissing-input.png)

### E\_NOT\_FOUND

当无法解析监视器 URL 中的服务器域名时，就会发生这种情况。这种情况可能发生在：

- 服务器的域名在 DNS 中不可用。
- 服务器的域名无效。

你可以在配置里检查显示器的 URL，确认是否包含有效的域名。

### E\_PAGE\_NOT\_FOUND

当无法找到请求页面时，会出现此错误。这可能由多种原因引起，例如：

- URL 不正确或已更改。
- 检查页面是否被移动或移除。
- 如果页面移动了，就在配置里更新显示器的 URL。

### E\_PARSE

这发生在数据解析失败时，通常是由于宏或管理爬虫在记录器中输入字段的配置问题。

- 输入字段配置错误或选项页面的数据类型不匹配，或者手动编辑配置文件 JSON 中的不兼容值——检查输入字段值，确保它们符合预期数据类型。

![parse-fields.png](https://distill.io/docs/web-monitor/troubleshooting-errors/images%2Fparse-fields.png) ![parse-fields-json.png](https://distill.io/docs/web-monitor/troubleshooting-errors/images%2Fparse-fields-json.png)

### E\_PDF\_PARSE

当解析 PDF 文档出现问题时，会记录这个错误。

- 确认文件是否为有效的 PDF 文件
- 试着用 PDF 阅读器打开 PDF 检查是否有损坏。
- 检查 PDF 是否设置了密码保护

### E\_PROXY

当代理服务器无法连接到你监控的远程服务器时，就会发生这种情况。最常见的情况是默认代理服务器的 IP/位置被远程服务器封锁。

在这种情况下，试着使用不同的代理服务器。了解一下： [使用代理服务器进行检查](https://distill.io/docs/web-monitor/monitor-webpage-using-proxy-servers/) 更多信息请见。

### E\_REQUEST

这种情况发生：

- 对于静态网页监控器，当服务器返回错误响应时，比如状态不是 200。在这种情况下，试着在 [配置](https://distill.io/docs/web-monitor/config-and-advanced-monitor-options/ "config") 里把 `动态` 选项设 `为 true` 。 检查页面是否正确加载。
- 对于 XML、JSON 和 UPTIME 监控器：
	- URL 无效或资源不存在。
	- 请求方法不正确。
	- 服务器不支持该请求。
	- 要找出错误的根本原因，检查响应并使用请求编辑器相应配置请求。
	![json-request-editor.png](https://distill.io/docs/web-monitor/troubleshooting-errors/images%2Fjson-request-editor.png)

### E\_REQUEST\_BAD\_GATEWAY

这种情况发生在服务器无法从它依赖的另一台服务器那里获得正确响应时。

- 过一段时间后再试一次显示器检查。
- 检查目标网站是否有问题。
- 请查看官网状态页面，了解已知问题。

### E\_REQUEST\_FORBIDDEN

这个错误意味着网站阻止了你试图监控的页面访问。

可能出现此错误的原因：

- 页面需要登录或需要身份验证。
- 页面期待某些 Cookie。

要修正：

- 如果页面需要登录，确保你的显示器已认证。可以看看 [“使用专用云设备进行检查”](https://distill.io/docs/web-monitor/dedicated-cloud-devices/)
- 如果页面受到防火墙或安全设置保护，可能需要使用代理服务器访问。

### E\_REQUEST\_INTERNAL\_SERVER\_ERROR

此错误表明在处理请求时发生了意外的服务器端错误。

- 过一段时间后再试一次显示器检查。
- 检查网站是否存在技术问题。

### E\_REQUEST\_NOT\_FOUND

当请求的资源无法被找到时，就会发生这种情况。

- 确认网址是否正确且未被更改。
- 试着直接在浏览器里访问该网址。
- 如果资源移动了，就更新监视器网址。

### E\_REQUEST\_SERVICE\_UNAVAILABLE

这种情况发生在服务暂时无法使用时，通常是由于维护或过载。

- 过一段时间后再试一次显示器检查。
- 检查网站是否正在维护。
- 使用代理服务器通过不同网络进行路由。

### E\_REQUEST\_TOO\_MANY\_REQUESTS

当速率超过且短时间内请求过多时，会触发该错误。

- 减少监测频率。

### E\_REQUEST\_UNAUTHORIZED

当需要认证但未提供或无效时，就会发生这种情况。

### E\_SSLCERT

当服务器的 SSL/TLS 证书无效时，就会发生这种情况。这种错误可能有多种原因。以下是一些常见的场景：

- 当网站域名不在服务器证书中时，
- 当服务器的证书过期时。

### E\_TIMEOUT

当 Distill 无法加载页面内容时，会出现此错误。这种情况可能发生在以下几种情况下：

1. **本地监视器超时** ：本地监视器不会加载到后台标签页。有些页面需要激活标签页才能完全加载。你可以点击查看页面的标签来验证这一点。如果点击它时检查没有错误，但如果有错误，说明该页面需要激活才能进行检查。在这种情况下，你可以采用以下任一种方法：
	- 使用 Distill 的 [桌面应用](https://distill.io/apps/web-monitor/) 本地监控
	- 在云端通过 Distill 服务器监控
2. **云监控超时** ：当网站拒绝接受某些 IP 的连接时，云监控超时。在这种情况下，可以尝试在云端使用代理服务器。更多信息请查看： [https://distill.io/docs/web-monitor/monitor-webpage-using-proxy-servers/](https://distill.io/docs/web-monitor/monitor-webpage-using-proxy-servers/) 。或者，你也可以用本地检查在浏览器中运行显示器。
3. **请求超时** ：当对远程服务器的请求因响应时间过长而失败时发生。这种错误在任何类型的显示器上都可能遇到。
4. **解决方案** ：
	- 如果云监控器不能配合任何代理，那么大多数情况下，使用本地监控器是可行的。
	- 对于网页监视器，你可以在 [配置](https://distill.io/docs/web-monitor/config-and-advanced-monitor-options/) 中将 `动态` 设置为 `true` 。

### E\_TYPE\_UNKNOWN

当显示器类型不被支持时，会出现这个错误。以下是支持的显示器类型： ![supported-monitor-types.png](https://distill.io/docs/web-monitor/troubleshooting-errors/images%2Fsupported-monitor-types.png)

### E\_UNKNOWN

这是一种通用错误代码，用于无法确定或分类错误的具体原因。一般来说， `E_UNKNOWN` 错误是指未分类的错误，不属于本页描述的其他类别。

### E\_VALIDATION\_FAILED

当提取的数据不符合监控器定义的验证规则时，会抛出该错误。

- 当某个必需字段为空或缺失时，这种情况就会发生
- 对于用户创建的爬虫，请查看记录器中的“验证者”部分，确保规则与预期的数据格式一致
- 如果使用管理式抓取器，请联系客服寻求帮助
