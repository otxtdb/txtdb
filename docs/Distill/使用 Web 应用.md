>   
> Distill Web App 可在 [https://monitor.distill.io](https://monitor.distill.io/) 访问。

###   
在 Distill Web App 中添加监控

1. 前往 [https://monitor.distill.io](https://monitor.distill.io/) 可用的 Distill Web App。
2. 点击 `  添加监控  `。在这里，您可以选择要跟踪的页面类型（ [根据监控类型选择步骤的详细信息](https://distill.io/docs/web-monitor/what-is-distill/) ）。
	![adding monitor using Distill Web App](https://distill.io/docs/web-monitor/using-web-app-to-track-webpage-changes/images/web-app.jpg)
3. 如果你选择了“网页”作为监控类型，源页面将打开。在此处粘贴网页的 URL，然后点击“开始”。

![adding monitor in Distill Web App](https://distill.io/docs/web-monitor/using-web-app-to-track-webpage-changes/images/add-url-web-app.jpg)

4. 视觉选择器将打开。将鼠标悬停在您想要监控的页面区域周围。选中您想要的内容后，点击“保存”图标。

![Visual selector view in Web App](https://distill.io/docs/web-monitor/using-web-app-to-track-webpage-changes/images/visual-selector-webapp.jpg)

  
如果您想监控页面的不同部分，可以进行多次选择。

  
使用“展开”、“收缩”和“删除”选项来调整选中区域的大小。 [有关如何使用视觉选择器的更多信息，请在此处阅读。](https://distill.io/docs/web-monitor/what-is-visual-selector/)

  
要监控整个页面，您可以跳过选择步骤，只需点击“保存”按钮。或者，您可以点击`更多选项 ` -> `  选择整个页面  `。

5. “选项”页面将打开。修改操作、计划等，并保存。您将能够在[监视列表](https://distill.io/docs/web-monitor/what-is-watchlist/)中查看所有您监控的网页。
6. 要查看记录在监控器上的更改，请点击预览。这将展开[更改历史](https://distill.io/docs/web-monitor/change-history-and-highlighted-changes/) 。

![Visual selector view and checking changes](https://distill.io/docs/web-monitor/using-web-app-to-track-webpage-changes/images/watchlist-change.jpg)
