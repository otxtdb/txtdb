监控器的配置包含 JSON 格式的参数。这些参数用于从网页中提取监控内容。

##   
如何查看配置？

  
你可以从“选项”窗口导航到监控器的配置。以下是你可以遵循的步骤来进入配置：

1. 点击监控器的“向下箭头”图标以查看快速操作项。
2. 点击“编辑选项”。这将打开选项窗口。![Quick action items for a Monitor](https://distill.io/docs/web-monitor/config-and-advanced-monitor-options/images/quick-actions.jpg "Edit Options")
3. 点击“打开网页选择器”旁边的齿轮图标，配置视图将打开。其中包含页面选项以及您选择器中已选择和未选择的元素。![Button to view config of a Monitor](https://distill.io/docs/web-monitor/config-and-advanced-monitor-options/images/config-ui.jpg "Show Config")

  
您可以选择在配置视图中编辑您的显示器配置，或者使用配置 JSON 文件。

## Config parameters 

  
当添加显示器时，Distill 会自动创建配置。以下是配置中的参数及其默认值。您可以将默认值更改为符合您的要求。

1. `index`: 默认生成。其值基于选择。对于 iframe 内的选择，索引应与 iframe 的索引匹配。
2. `excludes`: 排除选择的选取器列表。
3. `includes`: 包含选择的选取器列表。
4. `type`: 根据选取器类型，它可以取三种值之一：“CSS”、“XPath”或“JS”。默认选取器为 CSS（浏览器扩展为 XPath）。
5. `expr`: 选中或排除文本的选择器表达式。
6. `dynamic`: 可以设置为“true”或“false”。true 值会加载网页的动态内容，而 false 则不会。
7. `delay`: Distill 在检查页面是否有更改之前会等待延迟时间段。默认设置为 2。它可以取 0 到 20 的值。单位是秒。
8. `ignoreEmptyText`: 默认设置为 `true。` 在这种情况下，当所选元素不包含任何文本时，会在错误日志中注册错误代码“SELECTION\_EMPTY”。如果您希望将空文本视为变更，请将其设置为 `false`。
9. `includeStyle`: 默认设置为 `false`。如果将其设置为 `true`，则会在提取的数据中包含网页的样式表。

##   
如何等待页面加载完成后再提取内容？

  
有时，网页或网页的特定部分可能需要较长时间加载。如果使用默认设置进行监控，Distill 可能在其检查期间无法找到内容，导致数据不完整或错误。为解决此问题，您可以在监控器的配置中增加 `delay` 设置。这将指示 Distill 在检查页面之前等待指定的时间（以秒为单位）加载页面内容。您可以尝试不同的延迟值，并检查哪种设置最适合该页面。您可以在配置界面中添加延迟，或在 Config JSON 中添加。

**  
方法 1：在配置中设置延迟：**

1. 当您按下“打开网页选择器”按钮旁边的齿轮图标时，配置界面会打开，如下所示。
	![Config UI with delay](https://distill.io/docs/web-monitor/config-and-advanced-monitor-options/images/add-delay.jpg)
2. 展开`页面选项 `，在`等待时长`文本框中输入延迟间隔（以秒为单位）

**  
方法 2：使用 Config JSON 设置延迟：**

1. 按照以下方式打开监控器的配置 JSON。JSON 编辑器将打开。
	![Config with delay highlighted](https://distill.io/docs/web-monitor/config-and-advanced-monitor-options/images/config-json-view.jpg)
2. 搜索 `delay` 参数。它的默认值取决于设备，为 2 或 0。
3. 将延迟时间更改为一个较高的数值（10或12），最高可达20，并保存配置。
	![Config with delay highlighted](https://distill.io/docs/web-monitor/config-and-advanced-monitor-options/images/config-delay.jpg)

##   
如何在配置中批量进行更改？

  
您可以使用 `  批量编辑  ` 功能一次性更新多个监控器的配置。

  
以下是您可以遵循的步骤：

1. 选择您要应用新配置的显示器。
2. 点击批量编辑 -> 配置。
3. 粘贴新的配置并保存。

![Option to Batch Edit config](https://distill.io/docs/web-monitor/config-and-advanced-monitor-options/images/batch-edit-config.jpg "Batch Edit Config")
