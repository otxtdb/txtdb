动态网页很常见，而像 Chrome、Opera 和 Firefox 这样的浏览器阻止它们在后台加载。Distill 会打开一个新标签页检查这些页面是否有变化，检查结束后关闭该标签页。

###   
如何在新标签页中防止检查？

- 在后台或全局窗口中运行检查。进入“高级设置”，选择页面的开启和执行检查>。选择标签或窗口会为每个检查打开一个标签页或窗口。选择“背景......”它在幕后保持检查，这对静态网页很有效。![checks in a new tab](https://distill.io/docs/web-monitor/extensions-open-new-tab-for-checks/images/checks-in-tab.png "checks in a new tab")
- 用“置顶窗口”预留一个最小窗口用于检查，这样每次都不会开关。
- 如果网页内容是静态的，在配置中将`动态`参数改为 `false`。如果不确定，可以试着更改配置看看是否有帮助。

更改配置：

1. [  
	进入配置窗口](https://distill.io/docs/web-monitor/config-and-advanced-monitor-options/ "config")
2. 将 `“dynamic”改为 true`，“`dynamic”：false`。
3. 保存配置和选项。
