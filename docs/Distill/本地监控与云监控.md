在 Distill 中，根据检查运行的位置，您将有两种类型的监控器：本地监控器和云监控器。

### 云监控

  
当您的监控器（被监控的网页）设置为云设备时，它被称为云监控器。如果您从 [Web 应用](https://monitor.distill.io/)添加监控器，设备默认设置为云（Distill 服务器）。在这种情况下，监控器会在 Distill 的服务器上检查变化。您会看到云监控器的设备处有一个“云”图标。

### 本地监控

  
当你通过 Distill 的浏览器扩展或桌面应用程序添加监控时，它们会被设置到你的本地设备（浏览器或 PC）上，并称为本地监控。这些监控使用你的浏览器或 PC 来检查变化，这些设备必须正在运行。检查可以在你的浏览器中执行，以在后台、标签页（默认）或粘性窗口中进行。请注意，只有静态网页才可以在后台进行检查。在桌面应用程序中，检查将在你的本地计算机上执行。

  
当您从浏览器扩展工具栏打开监控列表时，本地监控会显示为桌面图标。如果您使用的是网页应用，本地监控会显示为浏览器图标（Chrome、Firefox、Edge 或 Opera），以及桌面应用的电脑符号。

  
您可以设置多个本地设备进行检测。例如，您可以在几台笔记本电脑或同一台笔记本电脑上的不同浏览器（Chrome、Firefox、Opera、Edge）上安装 Distill 的浏览器扩展。这些情况中的每一种都被视为一个独立的设备。

##   
本地监控与云监控的区别

  

| **云监控** | **本地监控** |
| --- | --- |
| 在 Distill 服务器上对云进行监控检查 | 浏览器中的监控检查 |
| 如果电脑关闭或浏览器未打开，将无法工作 | 需要打开电脑的浏览器 |
| 支持 PDF 和 XML 监控 | PDF 和 XML 监控不被支持 |
| Flexi 套餐的最小检查间隔为 2 分钟 | 最小检查间隔为5秒 |
| 云监控支持代理 [^1] | 代理不支持 |
| 检查数量受订阅计划限制 | 无限检查 |

##   
如何更换设备？

  
要更换设备，你需要点击设备图标并选择你想要运行监控的设备。你也可以通过选择多个监控来批量更换设备，点击批量编辑 -> 设备 -> 选择设备。

![icon to change run device](https://distill.io/docs/web-monitor/cloud-local-monitors/images/change-run-device.png "Icon to change run device ")

##   
如何管理设备列表？

  
如上图所示，点击设备图标并选择“编辑”来管理设备。或者，您可以打开 [https://monitor.distill.io/#/settings/devices/](https://monitor.distill.io/#/settings/devices/) 查看和管理您的设备列表。这将打开设备列表并显示所有设备。每个设备都有一个“编辑”按钮，您可以使用它来重命名设备名称。如果您不打算使用某个设备，可以通过点击该设备的“删除”图标来删除它。以下是设备列表的参考图片，您可以在其中编辑设备名称并删除不需要的设备。

![device list showing four devices](https://distill.io/docs/web-monitor/cloud-local-monitors/images/manage-devices.jpg)

##   
在“选择设备运行”下，“Any Local Device”是什么意思？

  
如果你有多个本地设备（Distill 的浏览器扩展），并且希望在任何打开的本地浏览器中运行监控检查，那么“任何本地设备”最适合你。如果设置了操作，你将在检查监控的本地设备上收到弹窗和声音提醒。 [查看日志](https://distill.io/docs/web-monitor/how-to-view-log-of-checks/)在这种情况下是设备特定的，不会同步。例如，如果你的家用浏览器检查了 Monitor A 的变更，那么 Monitor A 的查看日志将只显示在你的家用浏览器日志中，不会显示在任何其他设备上。

## 常见问题解答

  
何时使用本地监控器？

  
使用本地监控器来检查您电脑上的网站。它们通过您的浏览器扩展或 Distill 桌面应用程序运行检查，确保在任何活动的本地浏览器或设备上进行监控。如果您要跟踪的网站位于您的地理区域内，没有限制，并且不需要代理，那么本地监控器是一个不错的选择。

  
何时在云端监控页面？

  
使用云监控器进行持续网页跟踪，即使您的电脑关闭或浏览器已关闭。使用[代理](https://distill.io/docs/web-monitor/monitor-webpage-using-proxy-servers/)与云监控器一起，监控需要从特定区域访问的网页。

  
如何减少设备负载？

To reduce device load from frequent checks, reset the number of concurrent workers. The default is 3, with a maximum of 10. That is, by default, three workers check the first three monitors simultaneously, then sequentially handle the remaining monitor in the queue until every monitor in the queue has been checked. 

  
如果您想一次只检查一个监控器，您可以在设置 -> 高级选项中将并发工作线程设置为1

  
云监控如何记录变更检查？

  
每次 Distill 检查云中的监控器以检测变化时，都会计算一次检查。在云中，检查以 7 秒为单位进行计数。如果一次检查持续 7 秒以内，则计为一次检查。如果持续超过 7 秒但少于 15 秒，则计为两次。

  
**注意：** Distill 浏览器扩展在本地设备上与桌面应用程序的检查是无限制的，而云检查则有限制。

  
为什么本地监控器可以工作，但我的云监控器不行？

  
你会遇到网站阻止云服务器请求的情况。在这种情况下，你需要使用 [Distill 代理](https://distill.io/docs/web-monitor/monitor-webpage-using-proxy-servers/) 。Flexi 和企业版计划允许你将自定义代理添加到 Distill 云监控器中。
