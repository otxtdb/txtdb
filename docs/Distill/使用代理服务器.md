##   
什么是代理服务器？

  
代理服务器是一种作为服务网站和请求客户端之间的中介的服务器应用程序。当客户端发送网络请求时，请求首先发送到代理服务器。代理服务器随后代表客户端进行网络请求，从网络服务器收集响应，并将网页数据转发给客户端，以便客户端可以在自己的浏览器中查看页面。

##   
为什么使用代理服务器进行 Distill 云检查？

  
在 Distill 云中，监控器使用数据中心 IP 池进行检查。这是一个所有 Distill 订阅者共享的 IP 池。这些 IP 主要来自美国地区。

  
以下是您可能需要使用代理服务器进行 Distill 云检查的几个案例：

1. 当网站阻止来自数据中心 IP 的请求时。
2. 当需要从特定地区访问网站时。

##   
如何使用代理服务器监控网页变化？

  
要使用 Distill 提供的代理，请按照以下步骤操作：

1. 点击显示器上的“编辑选项”进入选项页面。
2. 点击“打开网页选择器”。
3. 当你点击“代理 - 共享池”时，你会看到一个下拉列表，其中包含你可以选择的代理。你可以选择所需的代理并保存。
![steps to add proxy to a webpage monitor](https://distill.io/docs/web-monitor/monitor-webpage-using-proxy-servers/images/add-proxy-to-monitor.jpg)

###   
如何管理代理并添加新的代理？

>   
> 添加自定义代理的功能在 Flexi 和企业版计划中可用。

  
您可以通过点击上方图片中所示的“管理代理”来访问代理页面。或者，您可以通过以下步骤从代理页面导航到代理服务器列表：

1. 从 [Web 应用](https://monitor.distill.io/)中打开您的观看列表，并点击如下所示的汉堡按钮 ☰。
2. 点击“代理”。
![steps to manage proxy from watchlist](https://distill.io/docs/web-monitor/monitor-webpage-using-proxy-servers/images/manage-proxy.jpg)

3. 这将打开代理页面。您可以点击“添加新代理”来添加您自己的代理服务器进行检测。
![steps to manage proxy from watchlist](https://distill.io/docs/web-monitor/monitor-webpage-using-proxy-servers/images/add-new-proxy.jpg)

4. 一个弹窗会打开，你需要为你的代理添加一个名称，然后继续添加一个使用用户名和密码进行身份验证的代理。
![steps to add new proxy](https://distill.io/docs/web-monitor/monitor-webpage-using-proxy-servers/images/steps-to-add-new-proxy.jpg)

  
用户名:密码@地址:端口。例如：alpha:bravo@我的代理主机:9000

5. 点击“保存”。

##   
代理方案和价格详情

  
代理服务器可在专业方案及以上版本中使用。您可以在 [https://monitor.distill.io/#/w/0/proxies/](https://monitor.distill.io/#/w/0/proxies/) 查看您的方案可用的代理。在 Flexi 和 Enterprise 方案中，您可以使用自定义代理。

  
您还可以在代理页面查看代理的价格详情。使用代理的成本会计入账户中的检查次数。如果某个代理的成本是 N，使用该代理的一次检查将被计为 N 次检查。例如，使用“Residential - US”代理进行每次监控检查将消耗 7 次检查。

###   
如何处理 EPROXY 错误？

  
当代理服务器无法连接到您正在监控的远程服务器时，会出现 EPROXY 错误。这种情况通常发生在远程服务器封锁了默认代理服务器的 IP 地址/位置。当您遇到此错误时，尝试为网页监控使用不同的代理服务器。
