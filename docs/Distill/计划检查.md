您可以通过导航到监控器的选项页面来为监控器计划检查。

![Setting interval for checks on the webpage](https://distill.io/docs/web-monitor/schedule-checks/images/check-schedule.jpg)

  
点击下拉菜单查看检查选项。

  
或者，您也可以从监控列表中点击监控器的计划。

![Setting interval for checks on the webpage](https://distill.io/docs/web-monitor/schedule-checks/images/check-schedule-via-watchlist.jpg)

###   
监控器的计划选项

| **计划选项** | **描述** |
| --- | --- |
| `Interval` | 设置定期检查网页的计划，在固定时间间隔内进行检查。使用本地监控器进行更小的时间间隔检查。示例：每3小时监控检查网页 |
| `Random` | 在固定计划之外，向检查网页添加随机时间点。在随机检查中设置最小和最大值，以便检查在指定的时间范围内进行。示例：在2小时到5小时之间随机检查网页。 |
| `Live` | 实时持续监控网页。仅当页面使用 JavaScript 自动更新内容时才使用。仅用于本地监控。示例：监控实时拍卖网页以跟踪实时竞价活动。 |
| `Cron Tab` | 定时并自动化在特定时间检查网页。您可以指定时间、日期、星期、月份，以任意组合方式设置。仅在高级计划中提供。示例：在每天上午8:00安排检查新闻网站，每个工作日进行。 |

![Setting time for checks with cron tab](https://distill.io/docs/web-monitor/schedule-checks/images/cron-tab.jpg)

  
此外，您还可以为检查安排时间段。

1. 通过点击浏览器工具栏中的 Distill 水滴图标，导航到本地监控列表
2. 点击左下角的设置齿轮图标。
3. 点击高级。
4. 根据您的需求设置时间段。
![Setting interval for checks on the webpage](https://distill.io/docs/web-monitor/schedule-checks/images/time-slot-view.jpg)

- 开始时间：监控在给定一天内开始的时间。
- 结束时间：给定日内监控结束的时间。
- 星期几：确定检查将在一周中的哪一天或哪几天进行。它允许您指定检查是否应在特定的工作日进行。

  
通过组合这些设置，您可以定义检查发生的特定时间段。例如：

- 开始时间：上午9:00
- 结束时间：下午5:00
- 日期：周一至周五

  
在这个例子中，检查的时间段为工作日的上午9点到下午5点。检查将在周一到周五的这段时间内进行。
