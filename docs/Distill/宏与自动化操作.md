##   
在 Distill 中，宏是什么？

  
宏允许您记录在网页上执行的一系列操作。网页操作的一些示例包括滚动、按钮点击或页面上的表单填写。一旦您记录了宏，您就可以在网页上重播它。

  
在 Distill 中，您可以使用宏两种方式：

1. 用于监控网页的所需部分，其中内容仅在执行网页操作（按钮点击、滚动等）后显示。
2. 作为 Distill 检查网页变化后的宏操作。当 Distill 检测到监控内容的变化时，宏将在网页上重播操作。

  
当页面 URL 在提交表单、排序、筛选、登录或搜索等操作后不发生变化时，请使用宏。宏可以复制这些操作，带你到达所需的页面视图。

  
您需要遵循两个步骤来监控需要宏的网页：

1. 创建一个宏来记录网页上的操作流程。
2. 使用保存的宏，在监控网页的特定部分之前播放它。

##   
如何创建宏？

  
您可以从[网络应用](https://monitor.distill.io/)或浏览器扩展创建宏。

1. 点击汉堡图标中的“宏”选项。它将打开 [https://monitor.distill.io/#/w/0/macros/](https://monitor.distill.io/#/w/0/macros/) 处的“宏”页面。

![A menu with Macro option](https://distill.io/docs/web-monitor/macro-to-record-replay-actions/images/029-macros-option.jpg)

2. 在相应的占位符中输入“宏名称”和“URL”，然后点击“添加新宏”按钮。它将在 Distill 的远程浏览器中打开 URL。
3. 页面加载后，您可以执行网页操作以显示最终内容。您还会在右侧面板中看到每个操作的相应步骤，如下所示。![steps in the Macro](https://distill.io/docs/web-monitor/macro-to-record-replay-actions/images/029-recorded-steps.jpg)
4. \[ *可选* \] 点击“重播”按钮以确保已正确捕获操作流程。
5. 点击“保存”按钮以保存宏。

  
保存宏后，宏列表将打开并显示新添加的宏。

##   
如何使用宏进行监控？

  
您可以使用宏来对页面进行选择以进行监控。这适用于云监控和本地监控。要将其用于本地监控，您必须在选项页面或监控列表中更改设备。

  
使用宏的步骤：

1. 从[观察列表](https://monitor.distill.io/)中点击“添加网页”按钮。输入 URL 并点击“前往”。
2. 在可视化选择工具栏中，点击“宏”菜单选项。它将显示该 URL 的所有保存的宏。从下拉列表中选择宏。
	![list of macros to choose from](https://distill.io/docs/web-monitor/macro-to-record-replay-actions/images/029-select-macro.jpg)
3. 点击宏的播放按钮。这将播放录制的操作，并到达最终页面，您可以在该页面进行选择以进行监控。
	![play button for the macro](https://distill.io/docs/web-monitor/macro-to-record-replay-actions/images/029-play-macro.jpg)
4. 一旦宏完成播放，将选择模式设为“开启”以进行选择。保存选择。
	![visual selector button](https://distill.io/docs/web-monitor/macro-to-record-replay-actions/images/029-visual-selector.jpg)
5. 您可以从选项页面配置检查间隔、设备等设置并保存。

##   
检查后如何使用宏操作？

  
宏操作适用于本地监控器。

  
当您的监控器检测到变化时，您可以设置宏操作来重放页面上的操作步骤。

1. 按照[上述](https://distill.io/docs/web-monitor/macro-to-record-replay-actions/#how-to-create-a-macro)说明创建宏，以记录在检测到更改后要执行的操作。
2. 通过点击“添加网页”从监视列表中为该网页创建一个监视器。
3. 在选项页面，点击“添加操作”并从操作列表中选择“运行宏（用于本地监控）”。
![Macro Action](https://distill.io/docs/web-monitor/macro-to-record-replay-actions/images/029-macro-action.jpg)

  
以下是一些可以使用宏操作的场景：

- **当商品有货时自动添加到购物车：** 您可以设置一个监控器来跟踪已售罄的产品。当视觉选择器在产品页面上检测到从“已售罄”变为“添加到购物车”的变化时，使用宏操作来自动将商品添加到您的购物车。它将在新标签页中打开页面并重播宏中记录的操作。

如何编辑宏？

  
您可以编辑、添加或删除现有宏的步骤。

1. 导航至宏列表：[https://monitor.distill.io/#/w/0/macros/](https://monitor.distill.io/#/w/0/macros/)。
2. 点击需要编辑的宏的“打开录制器”按钮。
3. 点击下方所示的下拉箭头进行步骤编辑。这将打开一个带有下拉菜单的菜单。
![Edit Macro Step](https://distill.io/docs/web-monitor/macro-to-record-replay-actions/images/029-overflow-menu-icon-macros.jpg)

4. 您可以选择 `  替换  `、`  在之前插入步骤  `、`  在之后插入步骤  ` 和 `  删除  ` 该步骤。
5. 与步骤相关联的属性和值可以通过点击进行编辑。编辑后，点击对勾按钮。

![Edit Macro Step](https://distill.io/docs/web-monitor/macro-to-record-replay-actions/images/029-edit-step.jpg)

  
6\. 完成后点击“保存”以保存对宏所做的更改。

  
保存的修改将应用于使用此宏的所有监视器。

##   
宏中的条件是什么？

  
在宏的步骤中，您可以添加一个条件块（IF…ELSE）。它允许您根据条件是否评估为真或假来执行特定步骤。它与编程语言中的 IF…ELSE 结构相似。

  
您可以在多种场景中使用宏条件块，包括但不限于：

- 管理间歇性弹窗：您可以使用条件块来处理偶尔出现的弹窗。如果检测到弹窗，宏将执行指定的步骤集；否则，它将继续执行备用序列。
- 确保持续访问：对于需要身份验证的页面，条件块可以自动化登录过程。如果正在监控页面并发现自己被注销，这特别有用。

  
具体来说，对于跟踪访问密码保护页面的本地监视器，您可能会遇到会话超时导致被登出的问题。在这种情况下，您可以在宏中插入一个 IF…ELSE 条件块来检查登录状态。如果已登出，宏可以自动执行步骤重新登录，防止错误并确保持续监控。

在宏录制器中添加 *if…else* 的步骤：**

1. 点击您想要添加条件的操作。这将打开一个带有列表的下拉菜单。选择 *if…else*。

在宏步骤中有一个“添加子句”的选项。这能让你检查多个条件，每个条件都可能导致步骤的不同结果。按照以下步骤使用 ELSE…IF 添加子句。

1. 点击溢出按钮，在适用的位置之前或之后选择“添加子句”选项。

2. 在检查多种情况时，你可以将 ELSE…IF 与 IF 块结合使用。

**  
如何在宏录制器中使用 *断言* 表达式？**

  
*断言*表达式用于宏执行过程中的错误检查。

- 使用断言来验证宏步骤执行时网页的预期行为。
- 如果由于宏中的步骤缺少响应而导致断言失败，它将引发异常以停止执行后续步骤。
- 断言将使用错误代码 `E_ASSERT` 使监视器出错。

  
例如，在开始检查其内部任何部分之前，验证页面是否存在。

  
为此，在宏步骤中使用“断言”表达式来检查页面是否包含“404”或“页面未找到”等文本。如果页面确实包含这些文本，我们将断言一个错误，并返回文本“页面不存在”。

![Using assert expression in the macro steps](https://distill.io/docs/web-monitor/macro-to-record-replay-actions/images/029-assert.jpg)

  
当你运行监控时，如果页面未找到，宏将断言一个错误并停止进一步检查的执行。

![Using assert expression in the macro steps](https://distill.io/docs/web-monitor/macro-to-record-replay-actions/images/029-assert-details.jpg)

##   
宏中的循环是什么？

  
宏中的循环允许您通过重复执行一个操作块来自动化重复性任务。在 Distill 宏中，您可以使用两种主要类型的循环：**For 循环**和 **While 循环** 。每种循环根据重复的性质和循环应运行的条件服务于不同的目的。

### For 循环

  
For 循环用于遍历一组值或元素。当您需要执行特定次数的操作或遍历元素数组时，它们特别有用。在 Distill 中，您可以用多种方式使用 For 循环：

1. **遍历元素** ：如果一个网页有多个相似的元素（如列表中的项目或标签），你可以设置一个 For 循环来逐个对每个元素执行操作。
2. **使用范围进行迭代** ：您可以使用 `range()` 函数指定一个范围来执行指定次数的循环。这对于执行诸如多次点击按钮或通过递增页码进行分页导航等任务很有用。

### While 循环

  
While 循环会在每次迭代前评估条件，并且循环会持续进行，直到条件不再为真。这种循环适用于事先不知道迭代次数，必须动态确定的情况。例如，你可以使用 While 循环来持续点击“加载更多”按钮，直到它在网页上不再出现。

##   
如何在宏步骤中添加循环

**  
在宏录制器中添加 While 循环的步骤：**

1. 选择您希望循环的操作。将出现一个下拉菜单。从列表中选择 `while loop`。
	![add while loop in macro recorder](https://distill.io/docs/web-monitor/macro-to-record-replay-actions/images/while-loops-in-macro.png)
2. 将添加一个 `while` 块。点击提示符文本展开下拉菜单，以查看和设置循环的条件。使用 `AND / OR` 命令添加逻辑，并通过选择添加语句将您的步骤包含在循环中。
![add while loop condition](https://distill.io/docs/web-monitor/macro-to-record-replay-actions/images/while-loop-block.png)

**  
在宏录制器中添加 For 循环的步骤：**

1. 选择你想要引入循环的操作。将出现一个下拉菜单。选择 `for loop`。
	![add for loop in macro recorder](https://distill.io/docs/web-monitor/macro-to-record-replay-actions/images/for-loop-in-macro.png)
2. 将创建一个 for 块。通过点击提示符文本来展开此块，以访问和设置迭代器选项。
3. 要执行预定的次数循环，可以使用 `range` 函数。例如，要重复执行操作五次，使用 `range(5)`。这将设置循环执行主体的步骤五次，每次迭代时将迭代变量值设置为从 0 到 4。
![add for loop range](https://distill.io/docs/web-monitor/macro-to-record-replay-actions/images/for-loop-block-range.png)

4. 要遍历匹配特定选择器的元素集合，选择一个选择器作为迭代器。然后循环将处理每个由选择器找到的元素中的步骤。迭代变量在每次迭代中将被分配给每个元素的对应选择器。
![add for loop selector](https://distill.io/docs/web-monitor/macro-to-record-replay-actions/images/for-loop-block-selector.png)

  
注意：默认情况下，循环的迭代变量名为 item，但可以根据需要重命名。

![rename for loop var](https://distill.io/docs/web-monitor/macro-to-record-replay-actions/images/for-loop-block-rename.png)

##   
步骤及其描述

1. **点击** (`click`): 模拟在指定元素（如按钮或链接）上鼠标点击，触发任何关联的动作或事件。
2. **拖动** (`drag`): 通过点击、按住和移动元素，在浏览器内复制拖放操作，将元素从一个位置移动到另一个位置。
3. **聚焦** (`focus`): 将焦点设置在指定元素（如输入字段或下拉菜单）上，使其成为用户交互的活跃目标。
4. **按键** (`keypress`): 在焦点元素上模拟键盘按键事件，例如输入字母或按 Enter 键。
5. **鼠标移动** (`mousemove`): 模拟鼠标指针在指定元素上的移动，触发任何相关的悬停效果或事件。
6. **打开** (`open`): 在浏览器中打开指定的 URL，导航到目标网页。
7. **滚动** (`scroll`): 将浏览器窗口滚动到指定的位置或元素，使目标进入视图。
8. **SELECT** (`select`): 选择下拉菜单或类似元素中的选项，将其设为活动选项。
9. **TYPE** (`type`): 模拟在聚焦的输入字段（如文本框或搜索栏）中输入文本。
10. **WAIT\_DOC** (`wait_doc`): 暂停宏执行，直到网页内容完全加载。
11. **WAIT\_FOR\_DURATION** (`wait_for_duration`): 在宏执行中引入指定时长的暂停，通常以毫秒为单位。
12. **WAIT\_FOR\_ELEMENT** (`wait_for_element`): 等待网页上指定的元素变得可用后，再继续宏执行。

##   
故障排除及如何检查宏是否正常工作

  
当你回放宏时，步骤序列将被执行，成功执行的步骤将带有绿色对勾。如果宏工作正常，你将看到所有记录的步骤旁边都有绿色对勾。

![check if macro is working correctly](https://distill.io/docs/web-monitor/macro-to-record-replay-actions/images/029-check-macro.jpg)

  
宏通常在以下情况出错：

- 页面加载不正确。
- 页面加载正确，但页面是当前无法用已录制的步骤处理的新类型页面。
- 页面加载正确，但用于构建选择器的元素标识符已更改。由于无法正确定位元素，步骤会失败。

  
如果遇到错误，你会发现宏无法继续执行到有问题的步骤。如果问题宏关联了监控器，它将显示一个 *EMACRO* 错误消息。点击`查看详情`了解更多关于问题的信息。

![check if macro is working correctly](https://distill.io/docs/web-monitor/macro-to-record-replay-actions/images/029-emacro.jpg)

  
检查日志将提供宏回放失败的位置和步骤的详细信息。您可以返回重新播放宏，找出有问题的步骤，并进行编辑或重新录制该步骤。

![check if macro is working correctly](https://distill.io/docs/web-monitor/macro-to-record-replay-actions/images/029-error-details.jpg)
