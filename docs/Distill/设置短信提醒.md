当网站发生变化时，您可以通过短信/文本提醒接收通知。要获取短信提醒，您需要登录您的 Distill 账户并添加一个电话号码到您的账户中。登录并添加电话号码后，在监控器的选项下添加“获取短信”操作。

## 要求

- 短信提醒仅适用于付费客户。
- 手机号码必须验证后才能用于接收短信提醒。

### 内容限制

  
短信提醒的内容必须符合 [Twilio 的通信政策](https://www.twilio.com/en-us/legal/messaging-policy) 。如果短信提醒的内容违反了 Twilio 的通信政策，该短信提醒将被阻止或删除。禁止内容列表见[禁止内容类别](https://help.twilio.com/articles/360045004974-Forbidden-Message-Categories-for-SMS-and-MMS-in-the-US-and-Canada) 。禁止内容列表包括但不限于以下内容：

- 成人内容
- 讨厌
- 酒精
- 枪支
- 烟草
- 电子烟/电子香烟
- 高风险金融服务
- 第三方获客服务及营销
- 债务追收或减免
- 快速致富计划
- 非法药物/物品
- 处方药
- 赌博

  
Distill 使用机器学习来检测和屏蔽禁止内容。如果您认为您的短信提醒被错误地屏蔽了，请联系 [Distill 支持](https://distill.io/docs/contact-us/) 。

###   
如何添加电话号码？

  
添加电话号码的步骤：

- 前往[邮件与电话](https://monitor.distill.io/#/settings/emails_phones/ "https://monitor.distill.io/#/settings/emails_phones/") 。
- **添加号码** : 填写号码并点击 `  添加  `。号码应为国际格式。例如，应以“+”号开头，后接国家代码和号码。
- **验证号码** : 手机号将收到一条包含验证码和验证链接的消息。手机号将保持未验证状态，直到验证完成。

![Add a phone to Distill Web Monitor](https://distill.io/docs/web-monitor/get-sms-alert-on-webpage-change/images/add_phone.png "Add a phone to Distill Web Monitor")

###   
如何添加或删除短信提醒？

  
在您将手机号码添加到 Distill 账户并在 Distill 网页应用或浏览器扩展中登录后，您可以按照以下步骤添加 SMS：

- 点击显示器右键菜单图标。它会弹出一个包含特定操作和选项的菜单。
- 点击添加操作。将打开一个包含待执行操作的弹窗。
- 点击“获取短信”。它将显示您添加的手机号码。如果添加了多个手机号码，请从下拉列表中选择。

![Get SMS alert on changes - Distill Web Monitor](https://distill.io/docs/web-monitor/get-sms-alert-on-webpage-change/images/get_sms.png "Get SMS alert on changes - Distill Web Monitor")

  
要停止接收短信提醒，请点击监控的上下文菜单图标，然后点击“获取短信”操作旁边的“删除”图标。
