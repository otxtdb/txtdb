>   
> 适用于在 PC 上运行的本机监控器。

  
您可以为网页监控器检测到的变化接收音频通知。除了默认声音外，您可以添加自定义警报或全局禁用音频通知。

###   
如何添加音频警报操作？

  
在选项窗口中添加音频通知，或点击向下的箭头图标选择“添加操作”并选择“音频通知（用于本地监视器）”。

![Audio notification - Distill Web Monitor](https://distill.io/docs/web-monitor/audio-notification-on-change/images/audio-alert.jpg)

  
请注意，此选项不适用于云监控。

###   
如何添加自定义声音警报？

  
您可以选择默认声音或为通知添加自定义音频文件。我们支持 MP3 和 OGG 格式。

  
要添加自定义音频，请按照以下步骤操作：

1. 从监控列表中点击“设置”。
2. 进入“操作”选项卡。在“提示音”部分，添加音频文件并保存更改。

  
添加新声音后，从下拉列表中选择它用于任何监控器。

![Add custom sound - Distill Web Monitor](https://distill.io/docs/web-monitor/audio-notification-on-change/images/custom-audio.jpg "Add custom sound - Distill Web Monitor")

###   
如何从全局设置中禁用音频通知？

  
要禁用所有监控器的音频通知，请前往设置 → 操作，并取消勾选“启用音频通知”。

##### 常见问题解答

####   
为什么我没有收到音频警报？

  
音频警报仅在 Distill 检测到监控器发生变化时才会触发。以下是故障排除方法：

1. 检查监控器的日志：进入监控列表并查看[检查日志](https://distill.io/docs/web-monitor/how-to-view-log-of-checks/) 。确保网页最近被检查过。如果日志中没有最近的时间戳或记录错误，音频警报可能无法播放。
2. 验证设置：确保已启用音频通知。如果已禁用，您将不会收到警报。
