###   
什么是运行时间监控？

  
运行时间监控是指定期检查网站或网络服务，以确保其可用性和正确响应的过程。您可以使用它来检测网站的停机或性能问题，以便及时解决。您还可以用它来监控一个最初无法访问的页面，该页面后来变得公开可访问。

###   
用于正常运行时间监控的 HTTP 方法

- **GET**：从指定资源获取数据，是用于正常运行时间检查最常用的方法。
- **POST**、**PUT**、**PATCH**、**DELETE**：这些方法通常用于创建、更新或删除资源，不常用于正常运行时间监控。您可能需要它们用于 Web 服务。

### 需要监控的属性

  
当客户端向服务器发起请求时，服务器会返回一个 HTTP 响应消息。该消息包含多个组成部分。在添加 URL 进行正常运行时间监控时，您可以选择这些属性。

- **状态码** : HTTP 状态码提供了关于 HTTP 请求成功或失败的信息。常见的代码包括 200（成功）、404（未找到）和 500（内部服务器错误）。这是进行正常运行时间检查时最常用的。
- **头部** ：响应头部提供了关于服务器响应和返回数据的额外信息。
- **正文** ：响应正文包含实际内容，例如：网页的 HTML，JSON 或 XML 格式的数据，通常用于 API。正文较少用于正常运行时间检查，因为通常只需验证网站是否可访问，而不一定需要监控其内容。对于内容监控，您可以使用 Distill 添加网页监控。

  
对于正常运行时间监控，服务器响应中通常最关键的方面是`状态`行以及可以指示服务器健康和性能的特定头部，例如 `Content-Type`、`Content-Length`，以及可能用于健康检查的自定义头部。

###   
如何使用 Distill 添加一个 Uptime 监控？

1. 从网络应用程序打开监视列表 [https://monitor.distill.io](https://monitor.distill.io/)，或导航到您的扩展程序的监视列表。
2. 点击 `  添加监控  ` -> `Uptime`。
	![Adding uptime monitor](https://distill.io/docs/web-monitor/uptime-monitor/images/uptime-monitor.jpg)
3. 在 URL 字段中输入您要监控的网页服务的 URL。如果您的网页服务需要这些参数、标题或正文内容才能访问，请点击“添加查询参数”按钮来配置任何额外的 HTTP 请求参数、标题或正文内容。
4. 点击“GO”按钮。此操作将向指定 URL 发送 HTTP GET 请求。![adding uptime monitor URL](https://distill.io/docs/web-monitor/uptime-monitor/images/uptime-add-url.jpg)
5. 选择 [“属性”](https://distill.io/docs/web-monitor/uptime-monitor/#properties-to-monitor) 进行监控，并在“精炼”选项卡中查看预览。
![getting response from page while checking uptime](https://distill.io/docs/web-monitor/uptime-monitor/images/uptime-monitor-properties.jpg)

6. 点击“保存”按钮。它将打开监控配置的选项页面。
7. 设置所需的检查间隔、警报操作和条件。
8. 完成后，点击“保存”，Uptime monitor 应该会出现在您的监控列表中。

###   
如何监控尚未存在的 URL？

  
有时您可能需要监控一个暂时不可用但未来可能会可用的页面。在这种情况下，您可以使用 Uptime monitor 来监控该 URL。在添加此监控时，您可以选择 `status` 属性。当页面变为公开可访问时，`status``code` 将从 `404` 变为 `200`。

![select status to check uptime](https://distill.io/docs/web-monitor/uptime-monitor/images/d034-page-status-check.png)
