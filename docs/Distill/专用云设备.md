>   
> 专用云设备适用于所有付费计划。

  
当你在 Distill 中配置监控时，你可以决定检查是在你的本地机器上通过扩展、Distill 的云服务器，或者现在通过你自己的**专用云设备**运行。这些设备是一种新型的客户端，它们就像在 Distill 的基础设施中托管的本地浏览器。它保留浏览器数据，如 cookies、本地存储、代理等，以便在检查中保持一致的页面状态。

>   
> 小技巧：将每个专用云设备视为云中的个人浏览器。

## 优势

- **多站点支持** ：可与任意数量的网站配合使用，这是相对于配置文件的一个优势。如果您需要访问同一网站的多个账户，可以创建多个设备。
- **持久性** ：每个设备都保留自己的浏览器配置文件，用于保存 cookies、本地存储、代理等。云监控可以配置使用这些设备执行检查。
- **多标签页支持** ：专用云设备视图支持标签页。在配置设备时，您可以打开多个标签页。
- **按需调试** ：当执行检查时出现问题，例如意外弹窗、验证码或布局变化，您可以在专用云设备中打开页面以进行审查和调整设置或授权操作。

##   
为什么使用专用云设备？

- 为任意数量的网站配置偏好设置，如“货币”、“位置”。
- 将登录会话存储以访问授权内容。

##   
创建专用设备

  
要创建新设备，请按照以下步骤操作：

1. 前往您的[关注列表](https://monitor.distill.io/) 。点击工具栏中的汉堡图标☰，然后点击“设备”。
	![Device Option in Menu](https://distill.io/docs/web-monitor/dedicated-cloud-devices/images/devices-options-in-menu.png)
2. 本页面列出了本地设备和专用云设备。提供设备名称，然后点击“添加新的云设备”按钮。
	![adding a new device](https://distill.io/docs/web-monitor/dedicated-cloud-devices/images/adding-new-device.png)
3. 应该创建一个新设备。
	![New dedicated cloud device is shown](https://distill.io/docs/web-monitor/dedicated-cloud-devices/images/new-dedicated-cloud-device.png)
4. 点击 Configure 按钮。它应该会打开远程浏览器并新建一个标签页。打开你想要保存数据的网站。我将使用 [monitor.distill.io](https://monitor.distill.io/) 作为示例。
	![Default Browser View](https://distill.io/docs/web-monitor/dedicated-cloud-devices/images/browser-view.png)
	  
	4.1 由于我未登录，它打开 [accounts.distill.io](https://accounts.distill.io/login)。
	  
	4.2 登录后，会打开监控列表页面。
	![Rendered Watchlist in Device Browser View](https://distill.io/docs/web-monitor/dedicated-cloud-devices/images/rendered-in-browser-view.png)
5. 设置完您的个人资料后关闭设备。这将同时关闭浏览器。

##   
如何使用专用设备与监控配合？

- 添加新监控时，从设备列表中选择你想使用的设备。![Cloud Devices List in the Add Web Monitor flow](https://distill.io/docs/web-monitor/dedicated-cloud-devices/images/dedicated-client-in-devices-menu.png)
- 打开你想监控的网站，我将打开[监控列表](https://monitor.distill.io/)页面。![Visual Selector loads the watchlist](https://distill.io/docs/web-monitor/dedicated-cloud-devices/images/watchlist-loaded.png)
- 配置选择器，然后点击导航栏中的保存按钮![Configuring the selectors in the Visual Selectors](https://distill.io/docs/web-monitor/dedicated-cloud-devices/images/configure-selectors.png)
- 在编辑选项页面，设备已经被选中，配置您想要进行的更改，然后点击保存按钮。![Edit Options page](https://distill.io/docs/web-monitor/dedicated-cloud-devices/images/edit-options.png)
- 监控器将被创建，并在第一次运行后显示所选内容。![Data after the first run](https://distill.io/docs/web-monitor/dedicated-cloud-devices/images/monitored-data.png)

  
如果您已经创建了一个监控器：

1. 前往监控列表
2. 点击向下的箭头图标，选择“编辑选项”。
3. 选项页面打开。在此，从下拉菜单中选择您要使用的设备。![List of devices in the Edit options page](https://distill.io/docs/web-monitor/dedicated-cloud-devices/images/edit-options-change-device.png)

##   
如何清除专用设备的浏览数据？

- 点击“打开远程浏览器”按钮，以打开您想要清除的设备的浏览器。![Configure button in the Device View](https://distill.io/docs/web-monitor/dedicated-cloud-devices/images/configure-a-dedicated-device.png)
- 点击工具栏中的“清除设备数据”按钮。![Clear button in the Device View](https://distill.io/docs/web-monitor/dedicated-cloud-devices/images/clear-device-data.png)

## 限制

  
如果保存页面的 cookie 过期了，您需要重新配置它。
