## JSON API 监控  
通过使用 JSONPath 或 jq 来检测变更并监控 JSON API 中的数据，根据需要过滤、解析和重构 JSON。

[![image](https://raw.githubusercontent.com/dgtlmoon/changedetection.io/master/docs/json-filter-field-example.png)](https://raw.githubusercontent.com/dgtlmoon/changedetection.io/master/docs/json-filter-field-example.png)

  
这会重新解析 JSON，并为文本应用格式化，使得监控和检测 JSON API 结果的变化变得非常容易

[![image](https://raw.githubusercontent.com/dgtlmoon/changedetection.io/master/docs/json-diff-example.png)](https://raw.githubusercontent.com/dgtlmoon/changedetection.io/master/docs/json-diff-example.png)

### JSONPath 还是 jq？  
对于更复杂的解析、过滤和修改 JSON 数据，推荐使用 jq，因为它内置了运算符和函数。有关 JQ 的更具体信息，请参阅[相关文档](https://stedolan.github.io/jq/manual/) 。

  
`JQ` 的一个大优势是你可以在 JSON 过滤器中使用逻辑，比如只显示值大于/小于的项目等。

  
更多信息和示例请参见维基 [https://github.com/dgtlmoon/changedetection.io/wiki/JSON-Selector-Filter-help](https://github.com/dgtlmoon/changedetection.io/wiki/JSON-Selector-Filter-help)。

###   
解析嵌入 HTML 中的 JSON！  
当你启用 `json：` 或 `jq：` 过滤器时，甚至可以自动提取并解析 HTML 页面内嵌入的 JSON！对于基于 JSON 构建内容的网站来说，非常方便，比如许多电商网站。

```
<html>
...
<script type="application/ld+json">

{
   "@context":"http://schema.org/",
   "@type":"Product",
   "offers":{
      "@type":"Offer",
      "availability":"http://schema.org/InStock",
      "price":"3949.99",
      "priceCurrency":"USD",
      "url":"https://www.newegg.com/p/3D5-000D-001T1"
   },
   "description":"Cobratype King Cobra Hero Desktop Gaming PC",
   "name":"Cobratype King Cobra Hero Desktop Gaming PC",
   "sku":"3D5-000D-001T1",
   "itemCondition":"NewCondition"
}
</script>
```

  
`json：$..价格`还是 `JQ：..价格`可以是 `3949.99`，或者你可以提取整个结构（用 JSONpath 测试网站验证）。

  
应用程序还支持通知您它可以自动跟踪这些信息
