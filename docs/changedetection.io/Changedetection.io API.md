# Changedetection.io API  
通过我们的 RESTful API 将您的changedetection.io与其他系统连接。

  
使用在`设置 ` > `API` 中为您生成的 API 密钥。

![](https://user-images.githubusercontent.com/275001/169546445-3e9e18fa-9649-4867-9cd7-6bb5f6d87ffe.png)

  
如果已启用，始终包含 `x-api-key` 头部值，从全局设置页面复制/粘贴密钥。

  
所有 API 文档现已可在 [https://changedetection.io/docs/api\_v1/index.html](https://changedetection.io/docs/api_v1/index.html) 获取。
