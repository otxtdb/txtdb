我的目标是让技术栈相对“平坦”，我希望大家觉得自己可以做出有意义的改变，不想把提交者限制在只懂 Vue/React/Angular 或其他框架的人。我觉得唯一非常合适的框架是 Flask Python 框架。

  
截至 2022 年，互联网充斥着难以深入学习的领域特定框架，即使如此，也没人愿意为这些代码库贡献，它们过时了，而且通常（除了 VueJS 等类似软件）会限制谁能贡献代码库。

  
不过我同意将来前端使用 VueJS 或类似工具会*更*合理，但目前 JavaScript 需求较少，目前手工完成更好。

  
另一个例外是用 SASS 预处理器写大量 CSS 时省脑筋，但即使是 `Node` 的世界也有很多改进空间，我尽可能详细地记录了 Node 版本和重建主题的步骤。

  
说到存储（`store.py`），我同意这有点疯狂，但另一方面，它运行得非常好，不过如果我能找到一种非 SQL 的存储方式，而且不会涉及大量领域特定的集成代码，我肯定支持。
