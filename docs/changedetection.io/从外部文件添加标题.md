(`0.43+`) 您可以使用文本文件为每个请求添加额外的请求头

  
文本文件与您的主数据存储目录相关

  
以下所有选项均适用于 Plaintext、Playwright/Browserless，可能也适用于 selenium（未经测试）

  
目前用于请求头的文本文件是一个简单的纯文本文件，如果您使用 Docker，可以使用 `-v` 命令将其挂载到容器中 `-v /local/path/headers.txt:/datastore/headers.txt`

```
My-header: some value
Another-header: another-value
```

### 全局适用于所有监控`/datastore/headers.txt`

### 单个监控`/datastore/d4e929f1-d467-491f-94e9-139537b9bd91/headers.txt`

  
上述 UUID 可以在 UI 界面中该页面的 **\[编辑\]** 链接中查看（或从 `url-watches.json` 数据文件中获取）

### 任何组标签  
如果你的标签类似于 `Favourite`，那么

`/datastore/headers-favourite.txt`

  
所有空格和其他字符都会被移除，标签名始终为小写，例如

`GitHub Releases` -> `headers-githubreleases.txt`
