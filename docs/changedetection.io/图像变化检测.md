有时手表的滤镜只包含一张图片。

  
目前，它changedetection.io只支持检测网页*正文*的变更，不过你也可以在 URL 中使用 `source：` keyword 来让 changedetection 返回 HTML 源代码。

  
这意味着你可以用 changedetection 检测 HTML 是否引用了不同的图片源。

  
例如——源在 [https://the-site-you-are-watching.com](https://the-site-you-are-watching.com/) 为

```
<HTML>
<BODY>
   <div id="wrapper">
      <img src="november-calendar.jpg">
   </div>
   <div id="other stuff">
     our new calendar!
    </div>
</BODY>
</HTML>
```

  
然后在**可视化选择器**中选择“wrapper”元素

###   
如何检测图像的变化？  
请使用**`来源：`** 卢克......

  
通过在网址开头加上“`source：`”， `source:https://the-site-you-are-watching.com` 并设置 CSS/xPath 过滤器（在 **Visual Selector** 工具中创建），当网站“`”变成 november-calendar.jpg`“`december-calendar.jpg`”时，你会收到通知。

  
自0.45.3版本起，我们尝试添加消息以帮助识别此事发生时间

  
除了提示 `Got HTML content but no text found (With 200 reply code),` （因为只有图片），如果你指定了过滤器/选择器，它会尝试通过说“ `Got HTML content but no text found (With 200 reply code), it's possible that the filters you have give an empty result or contain only an image.` ”
