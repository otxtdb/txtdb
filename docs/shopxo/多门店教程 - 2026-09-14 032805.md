# 序言

**多门店插件**

派单+转单+核销+代客下单+商品(独立售价+库存+商品)+批次+次卡+员工和薪水自动抽成+充值+收银+桌码+O2O店铺运营模式，线上线下完美结合、适用（社区+餐饮+美容美发+在线预约+门店消费+自提+外送+快递），可配置起步价，配送距离限制订单提交，支持达达配送，支持插件结合使用（支持配送员骑手）


# 店铺申请流程

    店铺申请流程

     1.进入数据 → 多门店 → 基础配置中，开启用户中心菜单入口（门店中心）


![店铺申请流程1.png](https://storecdn.shopxo.net/static/upload/images/plugins_doc/doc/19/2025/07/09/1752025363348125.png)

      2.进入商城登录页，输入注册好的账号密码，登录成功。


![店铺申请流程2.png](https://storecdn.shopxo.net/static/upload/images/plugins_doc/doc/19/2025/07/09/1752025474519618.png)

  

      3.进入商城首页，点击个人中心。

  

![店铺申请流程3.png](https://storecdn.shopxo.net/static/upload/images/plugins_doc/doc/19/2025/07/09/1752025577962264.png)

  

     4.进入个人中心页，点击门店中心入口。

  

![店铺申请流程4.png](https://storecdn.shopxo.net/static/upload/images/plugins_doc/doc/19/2025/07/09/1752025728327772.png)

  

     5.进入门店申请页面，点击立即申请。

  

![店铺申请流程5.png](https://storecdn.shopxo.net/static/upload/images/plugins_doc/doc/19/2025/07/09/1752025783848165.png)

  

      6.弹出入驻协议弹窗，同意并入驻。（进入后台去设置入驻协议内容，也可以设置跳过入驻协议）

  

![店铺申请流程6.png](https://storecdn.shopxo.net/static/upload/images/plugins_doc/doc/19/2025/07/09/1752025826923606.png)

  

      7.进入后台数据模块 → 多门店 → 店铺相关，输入入驻协议相关内容，如不输入内容则跳过统一协议的步骤。

  

![店铺申请流程7.png](https://storecdn.shopxo.net/static/upload/images/plugins_doc/doc/19/2025/07/09/1752025884656633.png)

  

       8.点击同意并入驻按钮后，弹出店铺申请弹窗，编辑添加相关内容，带※号的是必填项，填写完成后即可申请成功。

  

![店铺申请流程8.png](https://storecdn.shopxo.net/static/upload/images/plugins_doc/doc/19/2025/07/09/1752025943116297.png)

  

     9.点击保存后，进入提交审核页面，点击提交审核，进入审核环节。

  

![店铺申请流程9.png](https://storecdn.shopxo.net/static/upload/images/plugins_doc/doc/19/2025/07/09/1752025998461834.png)

  

      10.打开后台系统，点击数据模块 → 多门店 → 门店管理 ，进入门店管理页面。

  

![店铺申请流程10.png](https://storecdn.shopxo.net/static/upload/images/plugins_doc/doc/19/2025/07/09/1752026069513383.png)

  

      11.在门店管理页面，点击列表右侧操作区域内审核按钮。

  

![店铺申请流程11.png](https://storecdn.shopxo.net/static/upload/images/plugins_doc/doc/19/2025/07/09/1752026112261417.png)

  

     12.弹出审核弹窗，在弹窗底部显示拒绝和通过等按钮，点击通过，则审核通过，点击拒绝则重新提交审核内容。

  

![店铺申请流程12.png](https://storecdn.shopxo.net/static/upload/images/plugins_doc/doc/19/2025/07/09/1752026150588773.png)

  

      13.审核通过后，刷新门店管理中心审核页面，进入到门店管理中心首页，完成门店审核。

  

![店铺申请流程13.png](https://storecdn.shopxo.net/static/upload/images/plugins_doc/doc/19/2025/07/09/1752026186747914.png)



# 开启用户中心菜单入口（门店中心）

  

  开启/关闭用户中心中的 门店中心 菜单入口

   **第一步：**应用 → 应用管理 → 多门店 → 基础配置 → 开启/关闭用户中心菜单入口（门店中心）

               当开关开启时，商城用户中心显示门店中心菜单入口；关闭时则隐藏该入口。

   **第二步：**进入商城 → 个人中心 → 门店中心 

                 登录商城系统后，进入个人中心，左侧菜单栏的业务管理下可见门店中心入口。

![门店中心图.png](https://storecdn.shopxo.net/static/upload/images/plugins_doc/doc/19/2025/06/27/1750988826311541.png)


# 开启基础模式

  

    开启/关闭基础模式

     应用 → 应用管理 → 多门店 → 基础配置 → 开启/关闭基础模式（门店管理端）             

     1. 当开关与门店管理端按钮同时开启时，门店管理中心顶部导航将仅显示门店信息和配置信息。

     2. 当开关关闭时，门店管理中心顶部导航将正常全部显示。

![基础模式图1.png](https://storecdn.shopxo.net/static/upload/images/plugins_doc/doc/19/2025/06/27/1750992130788533.png)

     应用 → 应用管理 → 多门店 → 基础配置 → 开启/关闭基础模式（用户端）             

     1. 当开关与用户端展示基础按钮同时开启时，用户端只显示门店介绍等基础信息。

     2.当开关与用户端展示商品按钮同时开启时，用户端只显示商品信息。

     3.当开关与用户端展示基础+商品按钮同时开启时，用户端显示商品和基础信息。

     2. 当开关关闭时，用户端只显示商品信息。

![基础模式图2.png](https://storecdn.shopxo.net/static/upload/images/plugins_doc/doc/19/2025/06/27/1750992156170248.png)

# 门店管理分配商品时默认启用

   门店管理分配商品时默认启用

     应用  → 应用管理  → 多门店 → 基础配置 → 开启/关闭门店管理分配商品时默认启用             

      1.当开关开启时，门店管理分配商品启用。

      2.当开关关闭时，门店管理分配商品关闭。

  ![分配商品默认启用1.png](https://storecdn.shopxo.net/static/upload/images/plugins_doc/doc/19/2025/06/27/1751002299529436.png)

     **如何去查看和使用此功能**

     1.点击门店管理，进入门店管理列表页面。

![分配商品默认启用2.png](https://storecdn.shopxo.net/static/upload/images/plugins_doc/doc/19/2025/06/27/1751002325452972.png)

  

     2.进入门店管理列表页面后，点击商品按钮。

![分配商品默认启用3.png](https://storecdn.shopxo.net/static/upload/images/plugins_doc/doc/19/2025/06/27/1751021072575492.png)

  

      3.进入商品列表页面后，点击新增按钮。

![分配商品默认启用4.png](https://storecdn.shopxo.net/static/upload/images/plugins_doc/doc/19/2025/06/27/1751021092599384.png)

  

    4.进入门店商品添加页面输入商品名称进行搜索，搜索到的结果展示在左侧商品列表中，点击左侧商品列表箭头，进行商品添加。（门店管理

    分配商品时候默认启用时，右侧启用按钮开启状态，反之，关闭）

![分配商品默认启用5.png](https://storecdn.shopxo.net/static/upload/images/plugins_doc/doc/19/2025/06/27/1751021112868756.png)



# 后台商品管理列表/新增/编辑（门店关联）

   后台商品管理列表/新增/编辑（门店关联）

     应用 → 应用管理  → 多门店 → 基础配置 → 开启/关闭后台商品管理列表/新增/编辑（门店关联）            

      1.当开关开启时，商品管理列表页面中操作区域内门店按钮显示，点击进入后可进行门店商品关联操作。

      2.当开关开启时，商品管理列表页面中操作区域内点击编辑按钮，进入商品编辑页面后，选择顶部导航中的扩展数据，也可进行门店商品

         关联操作。

      3.当开关关闭时，商品管理列表页面中操作区域内门店按钮不显示，无法进行门店商品关联操作。

      4.当开关关闭时，商品管理表页面中操作区域内点击编辑按钮，进入商品编辑页面后，选择顶部导航中的扩展数据，门店商品关联操作区

         域不显示，无法进行门店关联操作。

![新增编辑门店关联1.png](https://storecdn.shopxo.net/static/upload/images/plugins_doc/doc/19/2025/06/27/1751004577522107.png)

  

     **如何去查看和使用此功能**

      1.进入商品管理页面，点击门店按钮后，在门店弹窗中进行门店商品关联操作，点击保存按钮完成操作。

![新增编辑门店关联2.png](https://storecdn.shopxo.net/static/upload/images/plugins_doc/doc/19/2025/06/27/1751021401562473.png)

    2.进入商品管理页面，点击编辑按钮后，进入到商品编辑页面。

![分配商品默认启用3.png](https://storecdn.shopxo.net/static/upload/images/plugins_doc/doc/19/2025/06/27/1751021608178813.png)

  

    3.进入商品编辑页面后，选择顶部导航中的扩展数据，进行门店商品关联操作。

![新增编辑门店关联4.png](https://storecdn.shopxo.net/static/upload/images/plugins_doc/doc/19/2025/06/27/1751021630200283.png)

# 开启下单选择类型

水票业务

1. 新建配置商品：80元10次水票

2. 新建消费商品：10元桶装水

3. 将配置商品 和 消费商品配置到新建次卡中对应配置项

4. 第一步 用户先购买 配置商品【80元10次水票】支付后获得次卡

5. 第二步 用户再去购买 消费商品【10元桶装水】在订单确认页面可以自主选择次卡进行按照购买的数量按次划卡提交订单

# 核验批次

1.进入后台系统 → 多门店 → 批次管理 ，点击列表右侧操作区域内订单按钮。

  

![后台核验1.png](https://storecdn.shopxo.net/static/upload/images/plugins_doc/doc/19/2025/08/21/1755768005572369.png)

  

2.在订单弹窗中，选择相应的订单，点击核验数据内的核验按钮。

  

![后台核验2.png](https://storecdn.shopxo.net/static/upload/images/plugins_doc/doc/19/2025/08/21/1755768026196989.png)

  

3.点击核验按钮后，弹出核验弹窗，点击确认完成核验流程。（备注信息为选填）

  

![后台核验3.png](https://storecdn.shopxo.net/static/upload/images/plugins_doc/doc/19/2025/08/21/1755768045622037.png)
