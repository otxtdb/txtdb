## 杂项

在这个选项卡中，您可以设置：

- 在登录页面使用图形验证码（CAPTCHA）（是或否）：在登录页面，每次用户想要登录时，都需要输入 CAPTCHA 验证码
- 使用某些模块的高级权限（是或否）：一些模块提供高级权限以实现更细粒度的控制。
- 会话超时：用户会话将在此时间后标记为“待删除”。PHP 会话的删除由系统处理，并取决于 Dolibarr 的安装位置。

## 密码

### 生成和验证密码的规则

您可以选择三种已实现的密码验证规则之一：

- **个人设置** ：在“密码模式描述”部分自行定义要遵循的规则
- **无限制** ：用户可以随心所欲：  [![Warning.png](https://wiki.dolibarr.org/images/c/cb/Warning.png)](https://wiki.dolibarr.org/index.php/File:Warning.png)完全不建议使用！
- **标准**  ：8 个字符，包含共享的数字和小写字母。

要激活一条规则，点击"激活"链接。

### 参数

三个附加参数：

- 加密数据库中存储的密码（不是明文）。强烈建议启用此选项。
- 加密存储在 conf.php 中的数据库密码。强烈建议启用此选项。
- 在登录页面上不显示“忘记密码”链接

## 文件上传

四个可用参数：

- 上传文件的最大大小（设置为 0 则禁止任何上传）：以 kb 为单位。  
    

注意： 你的 PHP 配置也会定义限制，无论此参数的值如何。

- Unix/Linux/BSD/Mac 文件系统上新文件的 UMask 参数（默认为 0664）
- 到杀毒软件命令的完整路径（用于分析上传的文件）  
    

ClamWin 示例：c:\\Progra~1\\ClamWin\\bin\\clamscan.exe  
ClamAv 的示例：/usr/bin/clamscan

- 命令行中的更多参数  
    

ClamWin 的示例：--database="C:\\Program Files (x86)\\ClamWin\\lib"  
然后你将获得用于测试文件上传的表单（根据设置）

## 外部/互联网访问

### 超时

对外部站点可以设置两个超时：

- 连接超时（秒）
- 响应超时时间（秒）

### 代理服务器

如果 Dolibarr 需要通过代理服务器访问互联网，请在此处填写信息。注意：这一点与您互联网浏览器的设置没有直接关联，它仅用于允许 Dolibarr 访问某些稀有资源，如 RSS 源或来自服务器的外部新闻源。  
首先将“使用代理服务器（否则直接访问互联网）”的选项设置为“是”。然后输入下方的四个字段：

- 代理服务器：名称/地址
- 代理服务器：端口
- 代理服务器：登录/用户
- 代理服务器：密码

## 默认权限

默认权限是自动授予所有新用户的权限，它们不会影响现有用户。对于每个模块（内部或外部），您必须授权读取、编辑、删除权限。某些模块可以定义更多权限。要授予权限，点击加号（+）图标，或点击减号（-）图标来移除它。

小心，这个屏幕允许设置默认规则，适用于所有新用户。为了更精确地设置，请转到用户->右侧屏幕，您可以创建安全组并将其分配给用户。继承权限将显示为“继承”权限，并且无法更改。
