## 公司/组织

第一步是定义您的公司/组织信息。为此，从主页选择菜单" **主页-> 设置-> 公司/组织** "，并添加您的公司/组织信息。

- **名称：** 您的公司/组织的名称

- [![Logo size.jpg](https://wiki.dolibarr.org/images/thumb/5/5c/Logo_size.jpg/300px-Logo_size.jpg)](https://wiki.dolibarr.org/index.php/File:Logo_size.jpg)

  **标志：** 在此处添加您的公司标志（.png、.jpg 或 .gif）。它接受任何尺寸，但建议使用高度为 130 像素且宽度最多为 800 像素的标志。这里有一个小示意图，展示在 PDF 上的结果。推荐使用 png 格式。

- **方形标志：** 在此处添加您的方形标志（.png 或 .jpg），它将用于应用程序右上角

- **财政年度：** 定义您的财政年度起始月份

- **国家：** 定义您的国家：其他选项取决于此选择。

- **专业 ID X：** 专业 ID 字段用于存储公司的专业 ID。每个国家都需要其自己的专业 ID。例如，对于法国的公司，您可能会找到 SIRET、SIREN、NAF、RCS 和 EORI 编号，而对于阿根廷的公司，您会找到 CUIT/CUIL、 brutos、CIF Intra。Dolibarr 能够管理 6 个专业 ID。它们的标签通过翻译键 ProfIdXCC 定义（其中 X 是 1 到 6，XX 是公司国家代码，例如 XX=FR）。要添加新的专业 ID，您可以从菜单“主页 - 设置 - 翻译”中添加新的 ProfIdXCC 键翻译。如果您将翻译的值设置为“-”，则表示在应用程序中使用该语言的公司（国家代码为 XX）时，专业 ID 将被隐藏。

- **销售税（增值税）管理：** 定义您如何管理销售税（或不管理）。
- **第二种税:** 定义是否要使用第二种税（或不使用）。
- **第三种税:** 定义是否要使用第三种税（或不使用）。

## 模块

[![List of modules](https://wiki.dolibarr.org/images/thumb/c/c7/List_of_modules_en.png/300px-List_of_modules_en.png)](https://wiki.dolibarr.org/index.php/File:List_of_modules_en.png)

模块列表

模块的激活是第二个强制步骤。您将激活哪些模块取决于您打算如何使用 Dolibarr。在大多数情况下，您可能希望使用所有模块。您必须逐个激活每个模块。例如，要管理一家公司，您可能至少需要激活第三方、发票和产品模块，但很可能需要更多。

要激活一个模块，请转到页面" **主页-> 设置-> 模块** "，然后点击状态列中的"开/关"按钮来启用它。

- 如果"开/关"按钮像 [!['on/off' button in on position](https://wiki.dolibarr.org/images/f/fd/On_off_button_on.png) ](https://wiki.dolibarr.org/index.php/File:On_off_button_on.png)，则模块处于**开启**状态。
- 如果"开/关"按钮像 [!['on/off' button in off position](https://wiki.dolibarr.org/images/7/72/On_off_button_off.png) ](https://wiki.dolibarr.org/index.php/File:On_off_button_off.png)，则模块处于**关闭**状态。

标准模块列表定义在页面 [模块列表 ](https://wiki.dolibarr.org/index.php/Category:List_of_Modules)。

如果您不确定某个模块的功能，可以启用它并查看 Dolibarr（水平条）中出现了什么新的菜单项，启用模块后，请检查您是否授予了自己新启用功能的相关权限。您可以在任何时候启用或禁用模块。

一旦模块被启用，它可能需要进一步配置（如果模块需要自己的配置，请点击模块行右侧出现的设置图标）。有关更多信息，请参阅 [模块文档 ](https://wiki.dolibarr.org/index.php/Category:List_of_Modules)。

## 显示

[![Display settings](https://wiki.dolibarr.org/images/thumb/5/54/Display_settings_EN.png/300px-Display_settings_EN.png)](https://wiki.dolibarr.org/index.php/File:Display_settings_EN.png)

显示设置

在此页面上，您可以设置应用程序的默认语言以及屏幕的外观和感觉。在初次使用时，您可以保留所有默认值。

### 语言

在语言设置中，您可以设置默认语言。默认情况下，它被设置为“自动检测”，因此语言将自动设置为用户（即网页浏览器的语言）的语言。

*注意：* 激活多语言选项将允许您设置客户的偏好语言，以便用他们自己的语言打印发票/报价单/订单。产品翻译也将可用。

### 皮肤和颜色

在 Dolibarr 中有两种不同的预定义皮肤：

- eldy [![Eldy Theme thumb.png](https://wiki.dolibarr.org/images/7/71/Eldy_Theme_thumb.png)](https://wiki.dolibarr.org/index.php/File:Eldy_Theme_thumb.png)
- md [![Md theme thumb.png](https://wiki.dolibarr.org/images/4/43/Md_theme_thumb.png)](https://wiki.dolibarr.org/index.php/File:Md_theme_thumb.png)

更多皮肤可以到 dolistore [[1\]](https://www.dolistore.com/4-skins) 下载

您也可以在此设置中个性化皮肤颜色和外观。

*提示：若要在不进入此页面切换暗黑模式选项的情况下测试特定页面的暗黑模式，你可以添加参数 &THEME_DARKMODEENABLED=2 强制启用暗黑模式，或 &THEME_DARKMODEENABLED=0 强制关闭暗黑模式。*

### 杂项

在这一部分，你可以设置所有功能的默认值，例如 javascript 函数、列表长度、一周的第一天等。
你也可以设置一个“每日信息”，该信息将显示给所有用户。在这个信息中，你可以使用[变量替换系统 ](https://wiki.dolibarr.org/index.php/Variable_substitution_system)。

### 登录页面

在这一部分，您可以自定义登录页面，添加一条消息和背景图片。在消息中，您可以使用[变量替换系统 ](https://wiki.dolibarr.org/index.php/Variable_substitution_system)。
您还可以在登录页面上隐藏/显示" **需要帮助或支持** "链接

## 菜单

[![Menu Setup](https://wiki.dolibarr.org/images/thumb/1/1b/Menu_Setup.png/300px-Menu_Setup.png)](https://wiki.dolibarr.org/index.php/File:Menu_Setup.png)

菜单设置

在此处选择您希望为内部和外部用户以及电脑或智能手机使用的菜单管理器。菜单管理器会更改左侧和顶部菜单的标签、顺序和组织方式。有关更多信息，请参阅页面 [菜单系统 ](https://wiki.dolibarr.org/index.php/Menus_system)。

### 菜单处理程序

该软件包含两种不同的菜单处理器：

- Eldy ：这是默认菜单，菜单项是集中管理和硬编码的。你可以在该菜单中添加条目，但不能更改默认的菜单项。
- Auguria ：这是一个数据库菜单管理器。此菜单可以根据你的需求完全定制。

在菜单处理程序选项卡中，您可以选择内部和外部用户的菜单，以及适用于计算机或智能手机的菜单。

### 菜单编辑器

在此选项卡中，您可以自定义 **auguria** 菜单的每个菜单项，或 **eldy** 菜单的附加项，并创建新项

### 杂项

在此选项卡中，您可以选择未授权菜单项的行为。默认情况下，未授权的菜单项以灰色显示，但可以隐藏。

## 用户

最后一步是创建用户并分配权限。几乎所有的模块，即使之前已激活，如果没有分配权限也无法访问。为此，您可以进入菜单 **首页 -> 用户和组** 来定义用户及其权限。注意，在启用新模块时，您应该考虑检查并重置用户权限。可用的权限列表取决于已激活的模块（见上文）。建议在激活您想要使用的模块后配置权限。对于某些操作，如果您没有执行该操作的权限，Dolibarr 将不会显示该操作。您可能会错过一些有用或重要的功能。 **要给用户或您自己（如果您是管理员）分配权限，请进入首页 -> 用户和组，选择所需的用户，然后点击其“权限”选项卡。**

您可以通过配置默认权限（理解为每次创建新用户时自动分配的权限）来避免为每个新创建的用户执行这些配置步骤，具体操作是在菜单 [安全设置 ](https://wiki.dolibarr.org/index.php/Setup_Security)中配置默认权限。
