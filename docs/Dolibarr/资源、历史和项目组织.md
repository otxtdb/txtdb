##  [![Who.png](https://wiki.dolibarr.org/images/9/9b/Who.png)](https://wiki.dolibarr.org/index.php/File:Who.png)dolibarr 星系中的核心角色及其职责

当前的 dolibarr 团队是一群人，他们得到了各种物理或道德贡献者（公司、基金会）的帮助（或赞助）。接下来的章节将介绍 dolibarr 项目管理中每个人所担任的角色和职能。这使得人们能够理解项目的工作方式。一些角色和职能一直在等待候选人。

希望申请项目角色的志愿者被邀请在 dolibarr 论坛上留言。

如果您需要作为开发者参与的信息，页面[开发者常见问题解答 如何成为官方开发者](https://wiki.dolibarr.org/index.php/Developer_FAQ#How_to_be_an_official_developer "Developer FAQ")可能更有帮助。

以下链接显示了参与或曾经参与项目的角色列表： [角色列表](https://wiki.dolibarr.org/index.php/Category:Everybody "Category:Everybody")

  
以下章节将展示不同的角色职责，然后是所有非开发人员角色。所有这些角色都对 Dolibarr 项目活动做出贡献。

### 沟通、法律和保护角色

目标：拥有商标、保护、管理法律要求

目前担任此角色：Dolibarr 基金会 [https://asso.dolibarr.org](https://asso.dolibarr.org/)

### 开发者角色

#### 开发者等级 **Yoda**（GIT 合并者，主要版本发布管理者）

目标/权限：Dolibarr 项目的全局管理。将 PR 合并到 develop 分支。组织冻结、测试版、创建 develop 分支的发布和打包。宣布新主要版本的发布。

目前拥有此角色：

- [Laurent Destailleur](https://wiki.dolibarr.org/index.php/User:Eldy "User:Eldy") ([DoliCloud](https://www.dolicloud.com/)) - 自 2008 年 6 月起担任项目领导者，也被称为 BDFL（终身仁慈独裁者，参见 [https://en.wikipedia.org/wiki/Benevolent_dictator_for_life](https://en.wikipedia.org/wiki/Benevolent_dictator_for_life)）
- [Maxime Kohlhaas](https://wiki.dolibarr.org/index.php/Maxime_Kohlhaas "Maxime Kohlhaas") - 备用项目领导者
- [Juanjo Menent](https://wiki.dolibarr.org/index.php/Juanjo_Menent "Juanjo Menent") ([2Byte](https://2byte.es/)) - 备份项目领导者 - 退休/离职/已退出。
- [Rodolphe Quiédeville](https://wiki.dolibarr.org/index.php/Rodolphe_Qui%C3%A9deville "Rodolphe Quiédeville") - 初始作者/项目领导者（2002 年至 2008 年 6 月） - 退休/离职/已退出。

需要更多人担任此角色：否（根据定义，此角色仅限于项目领导者和备份）

轮换模式：当前角色任命其备份和继任者（如辞职）。如因强制辞职（死亡、放弃），则由备份 Yoda 负责任命此职位的继任者。

注意：为新的 Dolibarr 版本构建软件包的所有任务都定义在文件 **build/makepack-howto.txt** 中，该文件可在 Dolibarr 源代码中找到。

#### 开发者等级 **Jedi**（维护版本管理器）

目标/权限：进行 GIT 合并，并在已发布的版本（非开发分支）上测试拉取请求。还可能将开发分支中完成的修复回滚（GIT cherry-pick）。为维护版本创建发布版本，并发布这些版本的公告。

目前负责以下模块的工作：

- 对于分支 N-1： [Laurent Destailleur](https://wiki.dolibarr.org/index.php/Laurent_Destailleur "Laurent Destailleur")
- 对于分支 18.0： [Eric Seigne](https://wiki.dolibarr.org/index.php/Eric_Seigne "Eric Seigne") + Lionel Vessiller：职位空缺：否
- 对于分支 N-x：无 - 职位空缺：是

该角色需要更多人：是。如果您想担任此角色，请发送邮件至 contact@dolibarr.org

#### 开发者等级 **海军上将** (GIT 拉取请求者)

目标/权限：开发，向 GIT 仓库添加代码。

一旦你的第一个 GIT 推送请求被验证，你就会成为海军上将。要提交新功能或修复，你必须使用 GIT 推送请求系统，该系统不需要 GIT 写入权限。

该角色需要更多人：是（尤其是为了提交错误修复）

关于这个主题的文章：[FAQ 如何成为官方开发者](https://wiki.dolibarr.org/index.php/Developer_FAQ#How_to_be_an_official_developer "Developer FAQ")

目前或近期担任此角色的人（在 [https://github.com/Dolibarr/dolibarr](https://github.com/Dolibarr/dolibarr) 中找到的贡献者）：

- 参见 [https://github.com/Dolibarr/dolibarr/graphs/contributors](https://github.com/Dolibarr/dolibarr/graphs/contributors)

#### 开发者等级 **Z-6PO**（transifex.com 上的翻译者）

目标/权限：翻译文件中的修正翻译（或排版错误）。

目前拥有此角色：

- 很多人实际上是 Z-6PO。现在使用 transifex.com 平台提供翻译。所有在 Dolibarr transifex 项目中注册为翻译的用户都是 Z-6PO。

角色需要更多人：是（请前往 [https://explore.transifex.com/dolibarr-association/dolibarr/](https://explore.transifex.com/dolibarr-association/dolibarr/) 选择您的语言并申请帮助）

关于这个主题的文章： [翻译者文档](https://wiki.dolibarr.org/index.php/Translator_documentation "Translator documentation")

#### 开发者等级 **士兵**

目标/权限：运营论坛、社区、推广 Dolibarr 等……

此角色需要更多人：是（无限制）

目前拥有此角色：

- 数字过高无法计数。任何 Dolibarr 用户都是潜在的士兵。

#### 还有达斯·维达？

有一些寄生虫般的人用攻击性言论污染论坛，这反而减缓了 Dolibarr 的发展，而不是通过建设性批评来帮助改进。有些人粗鲁且别有用心。这些人就是达斯·维达。幸运的是，从统计数据来看，每年只有一两个达斯·维达……

##  [![Lug.png](https://wiki.dolibarr.org/images/1/10/Lug.png)](https://wiki.dolibarr.org/index.php/File:Lug.png)帮助项目

这是你可以做的任务列表，以帮助项目。

**如果你是一名开发者**

- 如果你是一名开发者，加入 Dolibarr 团队。有关此信息，请参阅[开发者常见问题解答](https://wiki.dolibarr.org/index.php/Developer_FAQ "Developer FAQ") 。
- [https://github.com/Dolibarr/dolibarr/blob/develop/.github/CONTRIBUTING.md](https://github.com/Dolibarr/dolibarr/blob/develop/.github/CONTRIBUTING.md)

**如果你说一种非英语语言**

- 将 Dolibarr 应用程序或 Dolibarr 网站翻译成你的语言。参见[翻译文档](https://wiki.dolibarr.org/index.php/Translator_documentation "Translator documentation") 。
- 向你的语言的信息网站或你自己的网站提交文章来推广 Dolibarr。至少，网站 [https://www.dolibarr.org](https://www.dolibarr.org/) 的链接永远不会是个坏主意。
