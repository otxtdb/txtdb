## 前提条件

在一个干净的环境中完全恢复，我们假设你：

- 已经备份了你的数据库（备份为转储文件，例如如果你使用的是 MySQL 或 MariaDb 数据库，则使用 mysqldump 工具完成）。
- 已经备份了你的文档文件目录。
- 你知道在旧的 Dolibarr 备份时使用的管理员用户登录名。

## 第一步 - 重新安装 Dolibarr 软件

如果你已经卸载了 Dolibarr，或者因为你在新服务器上尚未安装，你需要像使用新干净数据库一样安装 Dolibarr。

小心选择与之前相同的数据库类型（Mysql、PostgreSQL 等）。

你可以安装你选择的任何 Dolibarr 发行版（Dolibarr、DoliWamp、DoliMamp、任何其他 Linux 发行版等），但它必须与制作备份时使用的完全相同版本（vX.Y）。版本可能包含在数据库备份的文件名中。

## 第二步 - 恢复文档

在您新安装的 Dolibarr 中，以管理员用户身份进入菜单 **首页 / 系统工具 / 恢复** 。

Dolibarr 将显示您的文档文件应存储的位置。此目录必须为空（如果不是，您可以清理它）。接下来您需要做的是将保存的旧文档文件目录的内容复制到这个目录中。

## 第三步 - 恢复数据库

### MySql

将备份转储文件复制到与命令 **mysql** 相同的目录中。

如果你的备份文件是一个压缩归档，可能需要在之前解压缩文件：例如，一个名为mysqldump_dolibarr_2.7.0_200812021800.sql.bz2的 bzip 归档备份必须解压缩到mysqldump_dolibarr_2.7.0_200812021800.sql（在 Linux 下运行 bunzip myfile.bz2，或在 Windows 下使用 7zip）。

在你的新安装的 Dolibarr 中，使用管理员用户在菜单**首页/系统工具/恢复** 。

选择导入方法。

Dolibarr 提供了一个命令行来启动数据库恢复。点击"显示完整命令"。例如，你将得到：

mysql mydatabase -h localhost -u databaseuser -pdatabasepass < mybackupfile.sql

打开命令行外壳（Windows 的 DOS 命令行或 Linux 的 Shell 终端）。进入存储命令 **mysql** 和你的备份文件的目录。执行之前提供的命令。

  
**替代方案** ：您也可以使用 _phpMyAdmin_ 的导入标签来恢复您的备份文件（通常您不需要检查任何特定选项，但您的备份文件需要禁用 foreign_key_checks，见下文）。此外，这种方法不能保证，在某些情况下可能会失败。
