## 安装 Dolibarr

本章描述了首次安装 Dolibarr 的不同可用方法（从最简单到手动安装）。有关升级，请参阅下一章。

### 在你的专用计算机/服务器上安装（本地安装）

####  [![Logo windows.png](https://wiki.dolibarr.org/images/8/8c/Logo_windows.png)](https://wiki.dolibarr.org/index.php/File:Logo_windows.png)使用 DoliWamp

- **前提条件** : Windows

- **难度级别** : 非有经验的用户

请注意，只有少数版本的 Dolibarr 与此即用型 DoliWamp 软件包兼容。

此过程仅适用于 Windows 用户，并建议给没有计算机知识的用户。如果你有 Apache、PHP 和 Mysql 安装经验，下一章更适合你。

如果你有时间并想学习如何安装 Apache、PHP 和 MariaDB 服务器，请查看 [Windows 手动安装](https://wiki.dolibarr.org/index.php/Manual_installation_on_Windows "Manual installation on Windows")页面获取逐步说明。

然而，如果你是新手用户且使用 Windows，你可以使用 DoliWamp。DoliWamp 是专为 Windows 设计的 Dolibarr 分发版本。这个分发版本允许你在 Windows 下进行安装，并包含所有先决条件（Apache、Mysql、PHP），且无需计算机知识。以下是安装 DoliWamp 的步骤：

- 下载适用于 Windows DoliWamp 的 Dolibarr 最新版本。

为此，请查看 [Sourceforge 镜像](https://sourceforge.net/projects/dolibarr/files/Dolibarr%20installer%20for%20Windows%20%28DoliWamp%29/)

- 运行下载的.exe 文件并按照说明进行操作。

  

####  [![Logo ubuntu.png](https://wiki.dolibarr.org/images/2/28/Logo_ubuntu.png)](https://wiki.dolibarr.org/index.php/File:Logo_ubuntu.png)使用 DoliDeb（Debian 或 Ubuntu 的.deb 包）

- **前提条件** : Linux Ubuntu

- **难度** : 非经验用户

此过程仅适用于 Ubuntu 或 Debian Linux 用户，并建议给计算机知识较少的用户使用。如果你对 Apache、PHP 和 Mysql 的安装有经验，那么“使用标准软件包”章节更适合你。然而，如果你是新手用户且使用 Ubuntu，你可以使用 DoliDeb。DoliDeb 是针对 Debian 或 Ubuntu 的专用 Dolibarr 发行版。这个发行版允许你在 Ubuntu 下进行安装，并包含所有前提条件（Apache、Mysql、PHP），且无需计算机知识。

- 安装 DoliDeb 的步骤在页面 [Dolibarr for Ubuntu or Debian](https://wiki.dolibarr.org/index.php/Dolibarr_for_Ubuntu_or_Debian "Dolibarr for Ubuntu or Debian") 中有描述。

  

####  [![Logo rpm.png](https://wiki.dolibarr.org/images/thumb/c/c7/Logo_rpm.png/42px-Logo_rpm.png)](https://wiki.dolibarr.org/index.php/File:Logo_rpm.png)使用 DoliRpm（Fedora、Redhat、Mandriva、Mageia 或 OpenSuse 的.rpm 软件包）

- **前提条件** ：Linux Fedora、Redhat、Mandriva、Mageia 或 OpenSuse

- **难度** ：非经验用户

此过程仅适用于 Fedora、Redhat、Mandriva、Mageia 或 OpenSuse Linux 用户，并建议没有计算机知识的用户使用。如果你有 Apache、PHP 和 Mysql 安装经验，下一章“使用标准软件包”更适合你。然而，如果你是新手用户且使用 Fedora 或 Redhat，可以使用 DoliRpm。DoliRpm 是专门为 Fedora、Redhat 或 Mandriva 设计的 Dolibarr 发行版。这个发行版允许你在这些操作系统下进行安装，并包含所有前提条件（Apache、Mysql、PHP），且无需计算机知识。

- 安装 DoliRpm 的步骤描述在页面 [Dolibarr for Redhat or Fedora (rpm package)](https://wiki.dolibarr.org/index.php/Dolibarr_for_Redhat_or_Fedora_\(rpm_package\) "Dolibarr for Redhat or Fedora (rpm package)") 或 [Dolibarr for Mandriva or Mageia (rpm package)](https://wiki.dolibarr.org/index.php/Dolibarr_for_Mandriva_or_Mageia_\(rpm_package\) "Dolibarr for Mandriva or Mageia (rpm package)") 或 [Dolibarr for OpenSuse (rpm package)](https://wiki.dolibarr.org/index.php/Dolibarr_for_OpenSuse_\(rpm_package\) "Dolibarr for OpenSuse (rpm package)") 中。  
    

  

####  [![Gnu.png](https://wiki.dolibarr.org/images/2/2f/Gnu.png)](https://wiki.dolibarr.org/index.php/File:Gnu.png)With Dolibarr (标准 .zip 包或从 git，适用于 Windows、OS X、Mac OS、Linux、BSD、...)

- **前提条件** ：Apache、PHP 和数据库服务器（MySQL 或 PostgreSQL）已正确运行，且已知新数据库或服务器 root 的用户名/密码。

- **难度** ：对 Web 和数据库管理知识较少的用户。

这个程序描述了在 GNU/Linux 系统（Debian、Mandriva 等）上的手动（和建议）安装，稍作修改后也可用于其他操作系统。你可以使用这个教程来安装任何版本号大于等于 2.0.0 的 Dolibarr。

- 检查你已经正确安装了 Apache、PHP **7.1.0+** 以及数据库服务器（MySQL **5.1+** 或 PostGreSQL）（通过你的发行版的包管理器检查服务器上已安装的包列表）。如果没有，请安装它们（使用最新版本）。

- 检查服务器的主要 root 或管理员用户名/密码组合是否已知且能正常工作。如果这个 root 或管理员用户名/密码尚未定义，因此未知，请阅读下一章节。否则继续下一步：

##### 准备 MySQL 或 MariaDB 数据库

对于 Linux 用户，如果你刚刚安装了 MySQL 或 MariaDB 服务器，管理员用户是 **root**。如果 root 密码尚未设置，你必须运行以下命令来初始化密码：

mysql

进入 Mysql 界面后，运行 SQL 命令修改 root 密码：

grant all privileges on *.* to root@'localhost' identified by 'newrootpass' with grant option;

然后输入并 \q 退出。

要检查新用户/密码组合的连接是否正常，请启动命令

mysql -u root -p

然后输入您的密码 _newrootpass_，如果连接成功，输入 \q 退出。

##### 准备 PostgreSQL 数据库

对于 Linux 用户，如果您刚刚安装了 PostgreSQL 服务器，您必须运行以下命令来初始化管理员用户和密码。为此，请在文件 **/etc/postgresql/x.x/main/pg_hba.conf**（将 x.x 替换为您的 PostgreSQL 版本）中添加以下行

local   all         dolibarrowner    md5

此外，注释掉该行

#local   all         all                               ident

这行代码确保用于连接数据库的系统登录（即运行 Web 服务器的登录）与数据库账户相同（这种情况永远不会发生）。

然后从 root shell 中启动命令

sudo -s -u postgres
createuser dolibarrowner
psql -U postgres -d template1
alter user dolibarrowner with password 'dolibarrownerpass';
ALTER USER dolibarrowner WITH SUPERUSER;
ALTER USER dolibarrowner WITH CREATEDB;
ALTER USER dolibarrowner WITH CREATEROLE;
\du
\q
exit
sudo /etc/init.d/postgresql restart

您可以使用命令测试此用户的连接

psql -h localhost -p 5432 -d postgres -U dolibarrowner -W
\du
\l

如果连接正常，请输入您的 _dolibarrownerpass_ 作为密码，然后输入 \q 退出。

##### 在 Web 服务器上安装 Dolibarr 文件

- 进入安装 Dolibarr 的目录（您的 Web 服务器虚拟主机的 Web 根目录。有关虚拟主机设置的示例，请参见 [此页面](https://wiki.dolibarr.org/index.php/Webserver "Webserver") ）。

1. 对于 Debian 和 Ubuntu 系列，通常是：/var/www（较新版本：/var/www/html）
2. 对于 Mandriva、RedHat、Fedora：/var/www/html
3. 对于 Suse：/srv/www/htdocs

$ cd /var/www
or
$ cd /var/www/html

- 获取最后稳定版本的程序档案 **从 zip 文件**

为此，请查看 [Sourceforge Mirror](https://sourceforge.net/projects/dolibarr/files/Dolibarr%20ERP-CRM/) 并获取最新稳定版本的 URL

$ wget -O dolibarr.zip [https://sourceforge.net/projects/dolibarr/files/Dolibarr%20ERP-CRM/x.y.z/dolibarr-x.y.z.zip/download](https://sourceforge.net/projects/dolibarr/files/Dolibarr%20ERP-CRM/x.y.z/dolibarr-x.y.z.zip/download)

  

解压缩存档

$ unzip dolibarr.zip

**或从 git 仓库**

$ git clone --depth 1 -b X.Y http://github.com/Dolibarr/dolibarr.git dolibarr

将 X.Y 替换为你想要获取的版本号。如果你不介意下载项目的完整历史记录，可以移除"--depth 1"（程序员可能会觉得有用，但普通用户可能不会）。

- 将目录名 dolibarr-x.y.z 重命名为 dolibarr，以使目录名不依赖于版本（将 x.y.z 替换为源版本号）
    
    $ mv dolibarr-x.y.z dolibarr
    

- 更改'dolibarr'目录的权限和所有者，使其与运行 Web 服务器的组相同（在 debian 下假设为'www-data'，在 redhat、mandriva、fedora 下假设为'apache'）
    
    $ chmod -R 755 /var/www/dolibarr
    $ chown -R www-data:www-data /var/www/dolibarr
    or
    $ chmod -R 755 /var/www/html/dolibarr
    $ chown -R apache:apache /var/www/html/dolibarr
    

- 对于 Fedora 系统，由于 SELinux 通常已启用，建议运行以下命令使'dolibarr'目录符合 SELinux 的要求（否则你可能会收到很多警告）：
    
    $ semanage fcontext -a -t httpd_sys_rw_content_t '/var/www/html/dolibarr(/.*)?'
    $ restorecon -R -v '/var/www/html/dolibarr'
    

- 以 root 用户身份，在 dolibarr/htdocs/conf 目录下创建一个名为 conf.php 的空配置文件，并将 Web 服务器用户设置为文件所有者（例如在 Debian 上是 www-data，在 Mandriva、RedHat、Fedora 或其他发行版上是 apache 等）。这是必要的，因为 Web 服务器在安装过程中需要向此文件写入数据。
    
    $ cd dolibarr ; touch htdocs/conf/conf.php ; chown www-data htdocs/conf/conf.php
    
    注意：对于 Ubuntu 系统，不需要设置 htdocs 目录，只需将 htdocs 的所有文件和文件夹放置在/var/www/dolibarr 目录下，然后从浏览器访问<MyIP>/dolibarr/index.php（参考此讨论作为此补充说明的依据 [[1]](http://askubuntu.com/questions/874456/php-code-displays-in-browser?noredirect=1#comment1357943_874456)）

- 以 root 用户身份，创建一个用于保存 Dolibarr 生成的所有文件和存储的目录（如 PDF 发票、上传的图片等），并将此目录的所有权分配给必须为 Web 服务器（例如在 Debian 上是 www-data，在 Mandriva、RedHat、Fedora 上是 apache）。Web 服务器必须对此目录有写入权限。建议使用位于您的网页目录之外的目录，例如 - "/var/lib/dolibarr/documents"
    
    $ mkdir -p /var/lib/dolibarr/documents ; chown www-data /var/lib/dolibarr/documents
    

- 现在请用浏览器指向主页
    
    http://127.0.0.1/dolibarr/htdocs/
    
    或者如果你没有创建 htdocs 目录
    
    http://127.0.0.1/dolibarr/
    

- 按照安装步骤的说明进行操作，直到安装过程结束。

- 出于安全原因，我们建议在设置完成后，在 Dolibarr 文档目录中创建一个只有 root 用户可以删除的 install.lock 文件。这将锁定安装过程的再次调用（升级时您需要删除此文件）。如果未执行此操作，Dolibarr 将在管理员用户登录时向您显示警告。
    
    $ touch /var/lib/dolibarr/documents/install.lock; chmod go-w /var/lib/dolibarr/documents;

### 在共享 Web 主机提供商上安装（无终端/SSH 访问权限）

由于这取决于具体的 Web 主机提供商，因此无法提供在特定 Web 主机提供商上安装 Dolibarr 的通用文档。在大多数情况下，使用以下流程应该适用于大多数提供商：

- **前提条件** ：Apache Web 服务器、PHP 和数据库服务器（MySQL 或 PostgreSQL）已经正常运行，并且已知新数据库或服务器 root 的用户名/密码。

- **级别** : 具备少量 Web 和数据库管理知识的用户。需要知道如何使用工具（FTP、SFTP）将文件上传到服务器。

- 检查您是否已安装运行正常的 Apache Web 服务器、PHP 以及数据库服务器（推荐使用 MySQL 或 PostGreSQL）。

 [![Warning.png](https://wiki.dolibarr.org/images/c/cb/Warning.png)](https://wiki.dolibarr.org/index.php/File:Warning.png)警告，请检查 PHP 服务器和数据库服务器的代码页是否相同（推荐使用 utf8_general_ci）。

- 请确认服务器的主根用户名/密码组合是否已知且能正常工作。如果未知，请向您的网站托管提供商咨询。

- 从[此处](https://sourceforge.net/projects/dolibarr/files/Dolibarr+ERP-CRM/)获取最新稳定版本的应用程序压缩包，并在本地解压。

- 在您的网站根目录（通常称为 public_html）内创建一个名为 dolibarr 的文件夹，并将 htdocs 目录中的所有内容上传到该文件夹。您可以使用 [Filezilla](https://filezilla-project.org/download.php?type=client22) 等 FTP 客户端进行操作。

- 在 Dolibarr 目录下创建一个名为"documents"的目录，用于保存所有由 Dolibarr 生成和存储的文档（PDF 发票、上传的图片等）。Web 服务器必须对此目录有写入权限。您可以使用 FTP 客户端设置权限。

- 使用浏览器访问主页 index.php，例如dolibarr.mydomain.com/index.php。

- 按照设置步骤的说明进行操作，直到安装过程结束。

- 出于安全原因，强烈建议在设置完成后，在 documents 目录下创建一个名为 **install.lock** 的文件。这将锁定安装过程的再次调用（您需要在升级时删除它）。如果未执行此操作，Dolibarr 在以管理员用户登录时会向您显示一条警告信息。

## 升级 Dolibarr

本章描述了将 Dolibarr 现有安装从旧版本升级到新版本的过程。无论您从哪个版本升级到哪个版本，过程都是相同的，但会根据您最初安装时使用的发行版/操作系统而有所不同。您应该使用相同的系统进行升级。

  
**注意** （可选）：

在安装新程序文件之前最好删除旧的程序文件：旧文件可能会残留，导致出现错误和功能故障。

删除前，请记得保存您在安装中自定义的内容：

- 您的数据（文档文件夹和数据库）
- 如果你有外部模块，请将路径设置为 /custom -> 在更新前，务必确保你的外部模块与新版本兼容！
- /conf/conf.php : dolibarr 的主要参数
- 您的自定义模型和/或自定义 php 脚本（建议在新文件中报告您的修改，因为它们基于旧版本）

  

###  [![Logo windows.png](https://wiki.dolibarr.org/images/8/8c/Logo_windows.png)](https://wiki.dolibarr.org/index.php/File:Logo_windows.png)使用 DoliWamp（Windows .exe 包）

- 首先备份你当前的安装
- 下载新的 DoliWamp .exe 包。
- 运行下载的.exe 文件，并按照步骤操作，不要更改任何默认值。这将升级所有您的文件。
- 执行完毕后，您的浏览器会打开一个页面，提示您运行数据库升级。根据您的实际情况选择升级。

- 如果有多个版本较新，您的浏览器页面会循环启动升级向导，根据需要多次运行升级过程，逐个版本升级，直到您达到新安装的版本。

  

###  [![Logo ubuntu.png](https://wiki.dolibarr.org/images/2/28/Logo_ubuntu.png)](https://wiki.dolibarr.org/index.php/File:Logo_ubuntu.png)使用 DoliDeb（Debian 或 Ubuntu 的.deb 软件包）

- 首先备份你当前的安装
- 使用 Debian/Ubuntu 软件包的升级过程与安装过程相同（见前几章），因此就像安装软件包一样简单。

- 您还可以阅读页面 [Dolibarr for Ubuntu or Debian](https://wiki.dolibarr.org/index.php/Dolibarr_for_Ubuntu_or_Debian "Dolibarr for Ubuntu or Debian")。

  

###  [![Logo rpm.png](https://wiki.dolibarr.org/images/thumb/c/c7/Logo_rpm.png/40px-Logo_rpm.png)](https://wiki.dolibarr.org/index.php/File:Logo_rpm.png)使用 DoliRpm（Fedora、Redhat、Mandriva、Mageia 或 OpenSuse 的.rpm 软件包）

- 首先备份您当前的安装
- 使用 rpm 软件包升级的过程与安装过程相同，因此就像安装软件包一样简单（参见前几章）。

  

###  [![Gnu.png](https://wiki.dolibarr.org/images/2/2f/Gnu.png)](https://wiki.dolibarr.org/index.php/File:Gnu.png)使用 Dolibarr（标准.zip 包或从 Git 获取）

这是在手动升级标准发行版时使用的教程。

- 首先备份您当前的安装

- 进入你安装 Dolibarr 的目录（可能是你的 Web 根目录，例如 Debian 下的/var/www）
    
    $ cd /var/www
    

#### 对于使用 zip 文件安装的情况

- 从 zip 文件获取最新稳定版本的应用程序归档 **从 zip 文件**

为此，请查看 [Sourceforge Mirror](https://sourceforge.net/projects/dolibarr/files/Dolibarr%20ERP-CRM/) 以获取最新稳定版本网址

$ wget -O dolibarr.zip [https://sourceforge.net/projects/dolibarr/files/Dolibarr%20ERP-CRM/x.y.z/dolibarr-x.y.z.zip/download](https://sourceforge.net/projects/dolibarr/files/Dolibarr%20ERP-CRM/x.y.z/dolibarr-x.y.z.zip/download)

- 解压缩归档文件
    
    $ unzip dolibarr.zip
    

- 将所有新提取的文件（未压缩到 dolibarr-x.y.z 目录中的文件）复制到您放置旧版 Dolibarr 版本的目录中。这将用新文件覆盖旧文件，而不会删除特定于您安装的文件（如 conf.php 文件或补充的非官方安装模块）。
    
    $ cp -r dolibarr-x.y.z/* dolibarr
    

- 如果没有错误，现在你可以删除源文件目录
    
    $ rm -fr dolibarr-x.y.z
    

- 现在在浏览器中打开你的 Dolibarr。它应该会自动打开 install/页面，并在建议菜单中选择_更新_ 。

#### 对于使用 GIT 的安装

- 如果你已经克隆了仓库，可以通过检出一个版本标签来直接升级，如下所示：
    
    $ git checkout 13.0
    $ git pull origin 13.0
    

- 现在在浏览器中打开你的 Dolibarr。它应该会自动打开 install/页面。在建议的选项中选择_更新_ 。

### 升级注意事项

- 如果你收到消息提示安装过程被文件锁定，请删除 Dolibarr 根目录中存储的 install.lock 文件。

- **出于安全原因** ，安装完成后，您应该创建一个名为 install.lock 的文件到 Dolibarr 文档目录中。这将锁定安装过程的再次调用（您将需要在未来的升级中删除此文件）。如果未执行此操作，Dolibarr 在您使用管理员用户登录时会向您显示一条警告信息。
    
    $ echo > documents/install.lock
    $ chmod 444 documents/install.lock
    

- 如果你想要脚本化数据库升级过程（以避免通过网页浏览器进行升级），你可以从命令行运行这3个升级过程：
    
    $ cd htdocs/install
    $ php upgrade.php oldx.oldy.oldz x.y.z > output.html
    $ php upgrade2.php oldx.oldy.oldz x.y.z > output2.html
    $ php step5.php oldx.oldy.oldz x.y.z > output3.html
    
    注意：z 必须为 "0"，因为只有主版本才有迁移脚本可以运行。如果成功，返回码为 0，如果出错，返回码为 1（如果出现这种情况，请查看 output.html、output2.html 或 output3.html 文件）。
