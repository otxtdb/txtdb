## 操作系统 (Operating Systems)

几乎所有现代操作系统都得到支持。

- 客户端：任何能够运行网络浏览器的操作系统
- 服务器：任何支持带有 PHP 的网络服务器和 SQL 数据库的操作系统（见下文）。

例如：GNU/Linux、BSD、Windows（为获得更好的性能，避免使用 Windows 服务器）、MacOS、AIX、...

  
**Windows 7 用户注意：**

When using Windows 7 the Visual C++ Redistributable for Visual Studio 2012 Update 4 must be already installed.  
An error message during installation will indicate if this is missing.
**Make sure you choose the 32-bit version (vcredist_x86.exe).**
It can be obtained here:
* [https://www.microsoft.com/en-us/download/details.aspx?id=30679](https://www.microsoft.com/en-us/download/details.aspx?id=30679)

## 数据库

- MySQL **5.1+**（任何受支持的 MySQL 选项/参数）。

!! Do not use MySQL version 5.5.40 nor 5.5.41, this version has critical bugs with data loss.

如果使用选项模式=STRICT 返回一些警告或错误，请将它们报告给我们。

- MariaDB **5.1+**
- PostgreSQL **9.1.0+**

- MS SQL（实验性支持尚未工作）

- 数据库大小需求低于**每 100** 名注册到数据库的客户/供应商 **1Mb**。

  

## PHP

- 请参考下方列表了解详细的 PHP 需求。
- 必须启用用户会话支持（这是 PHP 的默认值）
- PHP 配置必须允许使用 128Mb 的内存（参数 PHP memory_limit）。
- 但是，如果 safe_mode 参数被设置

[所有版本的详细 PHP 要求](https://wiki.dolibarr.org/index.php/Releases "Releases") .

## 磁盘存储

- Dolibarr 程序文件在磁盘上使用大约 **150 MByte**。
- 额外的模块或模板需要一些额外的磁盘空间。
- Dolibarr 数据库文件在磁盘上使用大约 **35 MByte**。
- 数据库系统本身也需要一些磁盘空间，以及更多空间用于临时文件。

然而，如果你上传合并的文件或存储生成的 PDF 或 ODT 文档，将需要更多的磁盘空间。存储容量取决于附件的数量和大小。

## CPU

你可以在低配置的机器上使用 Dolibarr，例如旧的 Intel Pentium 处理器或同等配置。如果你有超过 30 名用户，建议使用 1GHz 或更快的 CPU。
