**帮助关于屏幕** : 其他设置

**菜单路径** : 首页 ► 设置 ► 其他

  

**简介**

某些选项在界面中不可见（通常是因为它们已过时或为测试功能）。在大多数情况下，您不需要这些功能，使用它们可能会使应用程序不稳定或无法按预期工作。

![Warning.svg](https://upload.wikimedia.org/wikipedia/commons/thumb/1/17/Warning.svg/40px-Warning.svg.png) This page contains the list of some advanced development parameters. In most cases, they are parameters for internal usage, development, external modules, features in development not stable or that may lead to security risk. For standard usage of Dolibarr, such parameters **SHOULD NOT** be used. All experimental options are NOT supported. They may be removed in a future, modified at any version and break stability of your application.

要启用/覆盖一个参数，您需要在`首页►设置►其他设置`中将常量名称设置为 1（除非另有说明）

  
这里提供的选项可能没有文档记录，因为它们不稳定且不受支持（请记住它们是实验性或开发选项）。列表的基本格式如何编写在下面的示例中进行了分解：

UNSTABLE_OR_DEV_OPTION ► _配置描述和目标_ ► _(特定版本信息)或值_

## 全局选项

- **ADD_UNSPLASH_LOGIN_BACKGROUND** ► 每次刷新登录页面时，背景图片将被刷新。背景图片从流行的开源图片网站 Unsplash 获取。如果已存在静态背景图片，则此代码将覆盖它（但不会删除保存的图片）。警告：使用此功能可能会允许该外部网站窃取您的登录凭证（要填入的是服务的 URL，例如  ：[https://source.unsplash.com/random](https://source.unsplash.com/random)) ► (v10.0)
- **MAIN_HIDE_POWERED_BY** ► 在公共页面上隐藏"由 Dolibarr 提供"图标
- **MAIN_APPLICATION_TITLE** ► 这将更改软件的标题（默认出现在登录页面上）。警告：更改此设置可能会导致智能手机应用程序（如 [Android 应用 - DoliDroid](https://wiki.dolibarr.org/index.php/Application_Android_-_DoliDroid "Application Android - DoliDroid")）无法检测到 Dolibarr 版本，从而在使用这些应用程序访问 Dolibarr 时导致某些功能失效。如果文本以"+"开头，文本将添加到标准的"Dolibarr"标签中，而不是替换它。

- **MAIN_AUTOFILL_DATE** ► 如果这个常量被定义（不是 `0`），发票、报价单、订单或付款的日期将自动填充为当前日期。强烈建议不要启用此功能。这会导致大量输入错误，因为数据未经用户验证。这会导致数据库中保存错误值，当您需要制作会计报告时会造成混乱！
- **MAIN_AUTOFILL_DATE_PROPOSAL►** 如果这个常量被定义（不是 0），报价单的日期将自动填充为当前日期。

- **MAIN_AUTO_TIMESTAMP_IN_PUBLIC_NOTES** ► 编辑_公共_笔记时自动添加时间戳和用户。

- **MAIN_AUTO_TIMESTAMP_IN_PRIVATE_NOTES** ► 编辑_私人_笔记时自动添加时间戳和用户。

- **MAIN_DEFAULT_PAYMENT_TERM_ID** ► 使用支付期限的 ID，每次创建新的提案、订单、发票（客户和供应商）时，将使用此作为默认支付期限。已弃用。已被默认设置功能替代（见维基法语页面的一些示例  : [Paramétrage Valeurs par défaut](https://wiki.dolibarr.org/index.php/Param%C3%A9trage_Valeurs_par_d%C3%A9faut "Paramétrage Valeurs par défaut")）
- **MAIN_DEFAULT_PAYMENT_TYPE_ID** ► 使用支付类型的 ID，每次创建新的提案、订单、发票（客户和供应商）时，将使用此作为默认支付类型。已弃用。已被默认设置功能替代（见维基法语页面的一些示例  : [Paramétrage Valeurs par défaut](https://wiki.dolibarr.org/index.php/Param%C3%A9trage_Valeurs_par_d%C3%A9faut "Paramétrage Valeurs par défaut"))

- **MAIN_DEFAULT_LANGUAGE_FILTER** ► 如果您不想在组合框中显示 `en_US` 语言选项，则很有用（其他语言可以轻松地从 `langs` 目录中删除，但 `en_US` 不可以）► (v10.0)

- **MAIN_LANGUAGES_ALLOWED** ► 是一个不带空格的语言列表，例如  : `fr_FR,en_US,de_DE,it_IT` 如果定义，则只有这些语言会出现在组合框中。► (v11.0)

- **MAIN_DISABLE_NOTES_TAB** ► 在卡片页面中显示或隐藏笔记选项卡

- **MAIN_DISABLE_CONTACTS_TAB** ► 在卡片页面中显示或隐藏联系人标签页

- **MAIN_DISABLE_FULL_SCANLIST** ► 禁用完整表格扫描，以允许分页显示总页数。在数据量非常大的系统（超过 200 万条记录的表）中启用可能有用。

- **MAIN_DISABLE_JQUERY_JNOTIFY** ► 禁用使用 `JNotify` 显示确认或错误消息

- **MAIN_DISABLE_AJAX_COMBOX** ► 如果您有大量的第三方或产品，可以通过将此常量设置为 `1` 来禁用第三方列表的自动完成功能 ► (v3.6.0+)
- **MAIN_DISABLE_MULTIPLE_FILEUPLOAD** ► 禁止用户一次性上传多个文件。
- **MAIN_DISABLE_TRUNC** ► 禁用选择列表中的所有截断。► (v7.0+)

- **MAIN_DISABLEDRAFTSTATUS** ► 禁用某些对象（项目、捐赠、...）的“草稿”状态，以便对象直接以“已验证”状态创建

- **MAIN_DOC_USE_OBJECT_THIRDPARTY_NAME** ► 在生成的文档开头添加第三方名称。

- **MAIN_DOC_USE_TIMING** ► 在生成的文档末尾添加时间戳。值必须是时间戳的格式。例如：`%Y%m%d%H%M`（仅适用于 ODT 文件）

- **MAIN_DOC_UPLOAD_NOT_RENAME_BY_DEFAULT** ► 禁用上传文件时的自动重命名► (v10.0)

- **MAIN_DOL_SCRIPTS_ROOT** ► 定义包含'scripts'目录的目录（例如 `/var/www/dolibarr`）。此变量的值可能被某些外部脚本或工具请求。

- **MAIN_ENABLE_LOG_TO_HTML** ► 如果定义了这个常量，可以通过在 URL 中添加参数 `&logtohtml=1` 来在页面中显示日志。

- **MAIN_ENABLE_IMPORT_LINKED_OBJECT_LINES** ► 允许从"关联"兼容文档中导入行到当前文档中► (v8.0+)

- **MAIN_FIRST_TO_UPPER** ► 如果没有大写字母，Dolibarr 会为第三方、联系人或成员名称添加大写字母。警告：对于某些语言（其大写字母的单词与原单词不同，或页面代码不总是大写，如西里尔语言），此功能可能会更改您的数据。

- **MAIN_ALL_TO_UPPER** ► 如果未设置，Dolibarr 会将第三方、联系人或成员的名称转换为大写。警告，对于某些语言（其大写字母的单词与原单词不同，或页面代码不总是大写，如西里尔语系），此功能可能会更改您的数据。► (v11.0)

- **MAIN_ALL_TOWN_TO_UPPER** ► 如果未执行，Dolibarr 会将城镇名称转换为大写。► (v13.0)

- **MAIN_FILESYSTEM_ENCODING** ► 在某些 PHP 版本中，PHP 无法检测服务器操作系统文件系统的页面编码。为解决此问题，如果是在 Linux 或 OSX 系统上，Dolibarr 会假设您的操作系统文件系统为 `UTF-8`；如果是在 Windows 上，则为 `ISO-8859-1`。如果不是，例如在具有 NTFS `UTF-8` 页面编码的 Windows 服务器上，您可以设置变量 `MAIN_FILESYSTEM_ENCODING` 为"`utf-8`"。

- **MAIN_FORCELANGDIR** ► 自定义 `langs` 文件夹的相对路径。
- **MAIN_HTML_TITLE** ► 可用于控制 HTML 页面标题的格式。如果值包含键"`noapp`"，则不会输出应用程序名称。如果值包含"`thirdpartynameonly`"，在第三方选项卡中，仅输出第三方名称。值可以是标签列表："`noapp;thirdpartynameonly`"。

- **MAIN_HELPCENTER_LINKTOUSE** ► 定义用作登录页面"我需要帮助"链接的目标页面的 URL 链接

- **MAIN_LOGOUT_GOTO_URL** ► 用户登出后将重定向到的 URL

- **MAIN_MAXTABS_IN_CARD** ► 可见标签的最大数量。其余标签将分组到组合列表中。

- **MAIN_MAXLIST_OVERLOAD** ► 空间域中行的最大数量。

- **MAIN_MIN_NB_ENABLED_MODULE_FOR_WARNING** ► 如果启用的模块数量低于或等于此值（如果未定义则为 `1`），则会显示一条关于模块设置未完成的警告

- **MAIN_NO_CONCAT_DESCRIPTION** ► 允许在线条（建议、订单、发票）中仅使用输入的自定义描述► (v10.0) < v20.0. [ 自从 20.0 起已弃用 | 请查看产品模块管理配置以设置产品和服务的描述行为 ]. 此值被 PRODUCT_AUTOFILL_DESC 覆盖，由产品模块管理配置中的选项控制，不再使用。保留在代码中以允许自定义模块使用它。在 v22 中完全移除。

- **MAIN_OPTIMIZE_SPEED** ► 使用一些速度增强功能。有关更多信息，请参阅页面 [FAQ Increase Performance](https://wiki.dolibarr.org/index.php/FAQ_Increase_Performance "FAQ Increase Performance")。
- **MAIN_PASSWORD_FORGOTLINK ►** 修改登录页面的忘记密码链接。► (v9.0)

- **MAIN_PROPAGATE_CONTACTS_FROM_ORIGIN** ► 在从其他对象创建订单、合同、发票时，如果可能，将对象的特定联系人设置为新建对象的特定联系人。► (v4.0+)

- **MAIN_PUBLIC_NOTE_IN_ADDRESS** ► 在地址块中显示公共笔记 ► (v4.0+)

- **MAIN_REMOVE_INSTALL_WARNING** ► 移除所有向管理员用户显示的安全警告，如果 URL `/install` 是公开的。如果出现警告，你应该解决问题，而不是移除警告！为此，在 Dolibarr 根目录中创建一个名为 `install.lock` 的文件。这将停止警告，但也会使页面 `/install` 无法使用，以保护你的安装。

- **MAIN_REPEATCONTACTONEACHTAB** ► 如果添加并设置为 `1`，这将添加所有选项卡上的联系人，而不仅限于主选项卡。

- **MAIN_REPLACE_TRANS_xx_XX** ► 其中 `xx_XX` 是语言代码。如果值为 `string1:newstring1;string2:newstring2` ，则将 `string1` 替换为 `newstring1`，在为语言 `xx_XX` 所做的所有翻译中。

- **MAIN_ROUNDOFTOTAL_NOT_TOTALOFROUND** ► 改变计算含税行总计的方式，先舍入还是后舍入。

- **MAIN_ROUNDOFTOTAL_NOT_TOTALOFROUND_SUPPLIER**► 改变包含税的行总计的舍入方式，先舍入还是后舍入。

- **MAIN_SERVER_TZ** ► 如果无法设置您的 PHP 安装的时区，请设置此常量。最好是设置为 UTC。未来，此常量将被强制设置为'`UTC`'，因此 PHP 服务器时区将不再起作用。示例：`Europe/Paris`，`auto`。

- **MAIN_SEARCH_FORM_ON_HOME_AREAS** ► 在主页区域显示核心模块的搜索表单（v5 版本后已移除，因全局搜索组合框取代）► (v6.0+)

- **MAIN_SEARCHFORM_SUPPLIER_INVOICE_DISABLED** ► 在搜索表单中禁用供应商发票

- **MAIN_SEARCH_DIRECT_OPEN_IF_ONLY_ONE** ► 如果只找到一个结果，将此值设置为 `1` 将直接跳转到该项（默认方法）。将值设置为 `0` 将在列表中以单个结果形式显示。► (v5.0+)

- **MAIN_SERVICES_ARE_ECOMMERCE_200238EC** ► 如果卖方和买方在欧洲且买方不是公司，则使用购买国家的增值税。它可以有值 '1' 或 '2'。如果值为 2，可选择的增值税仅限于购买国家的。如果为'1'，可选择的增值税包括销售国家和购买国家的。► (v18.0+)

- **MAIN_SHOW_TUNING_INFO** ► 向 JavaScript 控制台添加调优信息。启用 xdebug 时效果更好。

- **MAIN_SHOW_TECHNICAL_ID** ► 在元素卡片或某些列表中也显示技术 ID（并非所有地方都支持）。

- **MAIN_SHOWDATABASENAMEINHELPPAGESLINK** ► 在顶部帮助菜单中显示数据库名称► (v8.0+)

- **MAIN_USE_ALTERNATE_TRANSLATION_FOR** ► 每个对象需要替代翻译的字段列表。示例： `MAIN_USE_ALTERNATE_TRANSLATION_FOR=societe:name,town;contact:firstname,lastname`

- **MAIN_USE_HOURMIN_IN_DATE_RANGE** ► 在所有实体行（发票、订单、合同等）上，可以在“开始日期”和“结束日期”字段中添加小时和分钟。

- **MAIN_USE_JQUERY_JEDITABLE** ► 允许通过屏幕直接更新元素（发票、报价单等）的一些属性到数据库中，使用 Ajax。这可以加快响应时间，但应避免使用此功能，因为它绕过了一些业务操作（需要在一致性地更新其他数据），并忽略了您保存数据时的业务控制。因此，此功能会破坏数据的一致性，并可能影响软件的稳定性。

- **MAIN_USE_JQUERY_MULTISELECT** ► 允许在使用需要多选的选项时使用 Ajax（目前只有外部模块使用带多选值的选框）。将其设置为要使用的 jQuery 插件名称（multiselect、multiple-select、select2 等）。设置为其他值会导致不期望的副作用和/或错误。

- **MAIN_USE_OLD_SEARCH_FORM** ► 在左侧菜单中显示旧搜索表单。

- **MAIN_VAT_DEFAULT_IF_AUTODETECT_FAILS** ► 允许强制将增值税率设置为给定值（而不是国家较高的增值税率），如果产品的增值税率未定义。

- **MAIN_UNKNOWN_CUSTOMERS_ARE_COMPANIES** ► 如果我们无法判断第三方是公司还是个人（未填写增值税 ID、未填写专业 ID、未填写第三方类型），那么如果设置为 1，我们假设它是公司（B2B 业务）；如果设置为 0，我们假设它是个人（B2C 业务）。

- **MAIN_USE_VAT_COMPANIES_IN_EEC_WITH_INVALID_VAT_ID_ARE_INDIVIDUAL** ► 对于内部 CEE 销售，默认情况下，在提案、订单或发票创建时，我们会为被视为公司的客户使用 0 增值税（参见 MAIN_UNKNOWN_CUSTOMERS_ARE_COMPANIES 以更改行为，判断第三方是公司还是个人）。但如果设置了选项 MAIN_USE_VAT_COMPANIES_IN_EEC_WITH_INVALID_VAT_ID_ARE_INDIVIDUAL，我们只有在为客户定义了增值税 ID 时才会使用 0 增值税。

- **MAIN_USE_VAT_OF_PRODUCT_FOR_INDIVIDUAL_CUSTOMER_OUT_OF_EEC** ► 用于为位于欧洲经济共同体（E.E.C.）以外的个人客户使用产品的默认增值税（v7.0+）。 _没有理由使用此功能。_

- **MAIN_VIEW_LINE_NUMBER** ► 在报价单/订单/发票等文档中为每条产品/服务显示行号。仅在屏幕上显示，不显示在 PDF 中。

- **MAIN_VIEW_LINE_NUMBER_IN_LIST** ► 在列表中显示行号►（v12.0）

- **MAIN_VOLUME_DEFAULT_ROUND** ► 容量的精度（小数位数）

- **MAIN_VOLUME_DEFAULT_UNIT** ► 体积的默认单位（`0=kg`, `-3=g`, ...）

- **MAIN_WEIGHT_DEFAULT_ROUND** ► 重量精度（小数位数）

- **MAIN_WEIGHT_DEFAULT_UNIT** ► 体积的默认单位（`0=kg`, `-3=g`, ...）

- **USER_HIDE_INACTIVE_IN_COMBOBOX** ► 禁止在组合框中显示非活动用户。

- **MAIN_ALLOW_WYSIWYG_LOCAL_MEDIAS_ON_PRIVATE_NETWORK** ► 默认情况下，您可以将媒体链接（img src 或其他）添加到富文本内容编辑器中，但您不能添加使用本地主机链接（如 [https://localhost/file](https://localhost/file)）的链接。如果将此选项设置为 1，您就可以添加。
- **MAIN_ALLOW_WYSIWYG_EVEN_ON_UNSECURED_EXTERNAL_HTTP_URL** ► 默认情况下，您可以将媒体链接（img src 或其他）添加到富文本内容编辑器中，但如果链接是未加密的"http"链接（非 https）且您的 Dolibarr 是 http，则不能。如果您将此选项设置为 1，您就可以。

## 适用于 SaaS / 云托管集成商

以下选项对于 Dolibarr 的普通使用是无用的。但如果您计划将 Dolibarr 实例作为软件即服务（SAAS）提供给客户，它们将很有用。

- **CRON_DISABLE_KEY_CHANGE** ► 当您向客户提供一个实例时，您可能还会在这个用户的 cron 中添加一个条目，以便 Dolibarr 批处理和调度器能够正常工作。出于安全目的，它可能有一个安全密钥，该密钥位于 cron 条目中的命令行内，并且该条目必须与 Dolibarr 设置中定义的值匹配（模块"计划任务"的设置）。因为 SaaS 平台的客户可能无法访问编辑 cron 文件，因此也很重要确保他们无法编辑 Dolibarr 设置中的密钥，这样 cron 命令行中的密钥将始终与 Dolibarr 设置中的密钥匹配，并且 Dolibarr 批处理将不会出现安全错误。为了确保客户不会更改该值，您可以将此常量设置为 1 到表 [Table_llx_const](https://wiki.dolibarr.org/index.php/Table_llx_const "Table llx const") 中。

- **CRON_DISABLE_TUTORIAL_CRON** ► 禁用关于如何安装 cron 脚本的教程（在 SaaS 主机上，这应该由网络主机提供商完成）

- **CRON_WARNING_DELAY_HOURS** ► 将此值设置为 cron 脚本的频率（以便在用户收到其计划任务的最高频率警告时显示警告）

- **MAILING_NO_USING_PHPMAIL** ► 为了避免错误使用电子邮件模块，建议将此选项设置为 1（此选项在前面已描述）。您还可以通过使用常量 MAILING_SMTP_SETUP_EMAILS_FOR_QUESTIONS 来完善客户在尝试设置其 Dolibarr SMTP 凭证时可见的消息（此选项在前面已描述）。例如，您可以指向您网站上的常见问题解答。

- **MAIL_MAX_NB_OF_RECIPIENTS_IN_SAME_EMAIL** ► 如果您在系统中设置了接收者数量的系统限制，您也可以设置此选项以匹配相同值，这样用户就会收到通知：因此 **MAIL_MAX_NB_OF_RECIPIENTS_IN_SAME_EMAIL** 限制将同一封电子邮件消息发送给 `x` 个接收者（x 为收件人 + 抄送 + 密送）。如果未定义，则值为 `10`。这是为了对抗在一条消息中包含大量接收者的垃圾邮件行为。请注意，**MAIL_MAX_NB_OF_RECIPIENTS_TO_IN_SAME_EMAIL**、**MAIL_MAX_NB_OF_RECIPIENTS_CC_IN_SAME_EMAIL** 和 **MAIL_MAX_NB_OF_RECIPIENTS_BCC_IN_SAME_EMAIL** 也都可用。请注意，这不是一个硬限制；它只是屏幕警告中显示的数量。对于实际限制，必须将其实现到系统中。

- **MAILING_LIMIT_SENDBYDAY** ► 这是单个实例可以发送的电子邮件数量限制。请注意，这不是一个硬限制；它只是屏幕警告中显示的数量。对于实际限制，必须将其实现到系统中。

- **MAILING_LIMIT_WARNING_PHPMAIL** ► 将此值设置为翻译键。然后在实例中添加翻译键，以便用户在进入邮件设置页面时看到消息。例如，您可以设置一条消息，提示： _警告：为避免滥用，在使用默认设置时，您对所有应用程序的限制为每天 500 封邮件（违反此规则可能导致账户被暂停。您可以将应用程序设置为使用自己的 SMTP 服务器发送邮件，这样您将没有任何限制（请参阅菜单 Home-Setup-Emails）_

- **MAIN_ALWAYS_CREATE_LOCK_AFTER_LAST_UPGRADE** ► 如果设置，当您启动客户实例的升级时，您可以确信升级过程会自动重新创建 install.lock 文件并删除 upgrade.unlock 文件，因此管理工具如 install.php、upgrade.php 和 repair.php 无法在您的客户实例上使用（直到 install.lock 文件被删除或 upgrade.unlock 文件被创建）。

- **MAIN_EXTERNAL_SMTP_CLIENT_IP_ADDRESS** ► (这个选项更好的名称应该是 MAIN_EXTERNAL_MAIL_CLIENT_IP_ADDRESS)。在这里设置您的 Dolibarr 实例所部署的 IP 地址列表，用逗号分隔。因此，当您的客户进入邮件设置区域时：
    - 如果他选择了邮件方法，系统会向他解释如何为其电子邮件域名设置 SPF 记录（显示 IP 地址列表）。这是为了避免其从 Dolibarr 实例发送的邮件因某些电子邮件服务器的严格反垃圾邮件规则而失败。
    - 如果他选择了 SMTP 方法，系统会向他说明如果 SMTP 代理对 IP 地址有限制，可以使用哪些 IP 地址。如果您还需要添加一条帮助设置 SPF 的消息，请查看选项 **MAIN_EXTERNAL_SMTP_SPF_STRING_TO_ADD**。

你也可以提供一个返回 IP 地址列表而不是硬编码 IP 地址的 URL 列表。例如，你可以设置一个 URL 调用 whoami 服务返回服务器的公网 IP 地址，再设置另一个 URL 用于 IPv6 地址，这样在设置页面，服务器的公网 IP 地址将始终是最新的（示例：[https://ipv4.server.com/_service_showmyip.php,https://ipv6.server.com/_service_showmyip.php](https://ipv4.server.com/_service_showmyip.php,https://ipv6.server.com/_service_showmyip.php)）

- **MAIN_EXTERNAL_SMTP_SPF_STRING_TO_ADD** ► 在这里设置 SPF 记录中要添加的字符串。当用户在电子邮件设置页面选择使用外部 SMTP 服务器时，这个字符串会显示在帮助信息中。

- **MAIN_FIRST_PING_OK_ID** ► 将此值设置为"disabled"以在完全设置后完全移除任何 ping。

- **MAIN_FILECHECK_LOCAL_SUFFIX** 和 **MAIN_FILECHECK_LOCAL_EXT** ► 如果你提供的是定制的或补丁版本的 Dolibarr，当用户使用工具检查文件完整性时，用于签名检查的默认 xml 文件名将是 Dolibarr 团队提供的官方文件，因此不包含你自己的修改。为了使建议的签名文件成为你自己的文件，你可以将常量 MAIN_FILECHECK_LOCAL_SUFFIX 设置为后缀。例如，将其设置为 "**-mysaassolution**"。这样，当用户使用文件完整性工具时，用于检查签名的默认文件将是 "**/install/filelist-10.0.2-mysaassolution.xml**" 而不是 "**/install/filelist-10.0.2.xml**"。你只需要使用工具 **build/generate_filelist_xml.php** 生成签名文件 **mysaassolution**，并将该文件放入客户实例的安装目录中。这样做后，你的客户和你自己将能够检查文件是否被修改，而不会被由于你的定制文件或补丁产生的错误警报所干扰（它们将被包含在用于检查的签名中）。 此外，如果你想把自定义的签名文件压缩到"**/install/filelist-10.0.2-mysaassolution.xml.zip**"，可以设置常量 MAIN_FILECHECK_LOCAL_EXT 为'.zip'。

- **MAIN_HIDE_WARNING_TO_ENCOURAGE_SMTP_SETUP** ► 默认设置为 1（因此隐藏警告）。您可以将其设置为 0 以向管理员显示警告，鼓励其设置自己的 SMTP 服务。

- **MAIN_MAIL_SENDMODE_password** ► 强制在"忘记密码"页面上发送邮件。这样你可以决定使用 php 邮件或 SMTP 方法来处理这种情况。

- **MAIN_MIN_NB_ENABLED_MODULE_FOR_WARNING** ► 如果设置为 N，当已激活模块的数量小于 N 时，将显示模块未激活的警告（未定义此变量与将其设置为 1 效果相同）。如果预先安装的应用程序中已默认加载某些模块，并且您希望保持警告以确保用户启用其需要的其他模块，即使某些模块已经启用，这可能会很有用。
- **MAIN_SETUP_MODULES_DESC** ► 如果您的安装已经完成且模块已激活，则帮助信息会隐藏，该信息用于解释如何在设置页面启用模块。您可以通过将此选项添加为 1 来保持其可见。

- **MAIN_NO_UPGRADE_REDIRECT_ON_LEVEL_3_CHANGE** ► 当您在数据库版本为 X.Y.Z 的安装上部署 X.Y.Z+delta 版本的文件时，迁移页面不会自动显示。只有当版本中的 X 或 Y 的值发生变化时，升级页面才会自动显示。

- **SYSLOG_DISABLE_LOGHANDLER_SYSLOG** ► 将此设置为 1 以禁用 syslog 的使用（所有客户实例记录在同一系统文件中并不是一个好主意）。

- **WEBSITE_REPLACE_INFO_ABOUT_USAGE_WITH_WEBSERVER** ► 在这里输入文本或文本的翻译键，当用户使用“部署”功能部署使用 Dolibarr CMS 制作的网站时显示。这样，例如，您可以向他显示一条消息，说明此功能不在其订阅范围内，并且将网站上线可能需要额外的订阅。
