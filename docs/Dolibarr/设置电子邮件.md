邮件设置

这是所有设置参数的解释：

### 全局禁用所有邮件发送（测试模式或演示）

设置为否。如果你设置为是（例如，对于演示系统），将不再发送邮件。

### 将所有邮件发送到（而不是真实收件人，用于测试目的）

输入一个电子邮件地址。所有外发邮件都将发送到该地址。用于测试。

### 建议员工邮箱

建议将员工邮箱（如果已定义）添加到新邮件的预定义收件人列表中

### 发送邮件的方法

- 默认方法是 **PHP 邮件函数** 。这意味着 Dolibarr 将使用您的 PHP 来发送邮件。这需要您的 PHP 设置完整。如果您不知道如何为邮件发送设置 PHP，请选择下一个方法。
- 如果您的邮件发送服务器需要认证，或者您没有权限或知识来设置 PHP，请选择第二种方法：**SMTP/SMTPS 套接字库** （如果您无法使前一种方法与您的邮件提供者配合使用，则选择 **Swift Mailer 套接字库** ）。

 [![Warning.png](https://wiki.dolibarr.org/images/c/cb/Warning.png)](https://wiki.dolibarr.org/index.php/File:Warning.png)警告

某些电子邮件服务商（如 Yahoo）不允许您从 Yahoo 服务器以外的服务器发送电子邮件，如果用作发件人的电子邮件地址是 Yahoo 邮箱（例如 myemail@yahoo.com、myemail@yahoo.fr 等）。如果您使用 PHPmail 方法，这意味着您将使用应用程序的服务器发送电子邮件，因此一些收件人（兼容 DMARC 协议的收件人）会询问 Yahoo 是否可以接收您的电子邮件，而 Yahoo 会回复“不”，因为该服务器不是 Yahoo 服务器，您的一些电子邮件可能无法被接收。  
如果您像 Yahoo 一样，其电子邮件服务商有此限制，您必须设置此选项以选择其他方法“SMTP/SMTPS 套接字库”，并在此处输入由您的电子邮件服务商提供的 SMTP 服务器和凭据。

### SMTP/SMTPS 发送服务器的主机名或 IP 地址

发送邮件的服务器的名称或 IP 地址。这通常是一个由您的互联网服务提供商提供的名称，如 smtp.xxx.zzz。

例如：

- smtp.aol.com
- smtp.free.fr
- @1001#
- smtp.gmail.com (使用 gmail 或工作账户的登录名/密码)
- smtp-relay.gmail.com (使用 gmail 的工作模式中继)

### SMTP/SMTPS 发送服务器的端口号

如果邮件发送服务器使用标准端口（25），您可以留空该字段。

其他示例：

- 25 (SMTP 标准)
- 465 (SMTPS，免费 Gmail 或 Gmail 套件)
- 25、465 或 587 (SMTP，Gmail 套件中可用中继模式，取决于设置)

### SMTP 身份验证 ID

如果选择 **SMTP/SMTPS socket library** 作为发送方式，则可见。在此处输入您的登录名。

### SMTP 身份验证密码

如果选择 **SMTP/SMTPS socket library** 作为发送方式，则可见。在此处输入您的密码。

### 使用 TLS (SSL)

有些邮件服务器需要加密通信（例如 Google 的 SMTP 服务器 smtp.gmail.com，它使用 SMTPS）。

支持此协议的唯一方法是 **SMTP/SMTPS 套接字库** 。如果您需要这种加密，必须通过设置此方法来启用加密。

注意：您的 PHP 中必须提供 SSL 功能。如果没有，您可能忘记安装 PHP 的 **openssl** 模块。

注意：有 2 种不同的 SMTP 安全编码类型：

- 在加密流（**SSL** 或 **非标准 TLS**）中发送 SMTP 协议。服务器通常运行在端口 **465**。
- 在 SMTP 中发送加密数据（ **使用 STARTTLS 的 TLS**）。服务器通常运行在 **587** 端口。

有关 TLS 和 STARTTLS 之间差异的更多信息，请参阅：[https://www.fastmail.com/help/technical/ssltlsstarttls.html](https://www.fastmail.com/help/technical/ssltlsstarttls.html)

### 用作自动邮件的发送者邮箱

在此处设置默认情况下 Dolibarr 将用作自动邮件发送者邮箱的邮箱，如果未明确定义发送者。

### 手动发送的默认发送者邮箱

您可以使用用户邮箱或公司邮箱

### 用于错误返回邮件的邮箱

设置错误返回邮件地址（发送邮件中的“Errors-To”字段）。所有未正确接收的邮件将被发送回此地址

### 将所有发送的邮件抄送至

如果您希望将所有 Dolibarr 发出的邮件抄送至一个通用邮箱地址

### 常见邮件服务器设置示例

以下是一些用于通过 SMTP 方法设置邮件并使用您邮件提供商的 SMTP 服务器的值示例（适用于常见邮件服务商）。如果您的邮件服务商不在列表中（或如果您不确定使用哪个值），请联系您的邮件服务商以获取凭证（SMTP 服务器、端口、是否使用 TLS）。

#### Gmail（使用登录密码和应用密码）

- SMTP 服务器：smtp.gmail.com
- 端口：465
- 认证方式：使用密码（AUTH LOGIN）
- SMTP 用户名：您的 Gmail 登录名（xxx@gmail.com 或 xxx@yourdomain.com）
- SMTP 密码：一个生成的应用密码，不含空格（不是你的 GMail 密码，见下文）
- 使用 TLS（SSL）加密：是
- 使用 TLS（STARTTLS）加密：否

您必须在您的 Google 账户上启用两步验证。完成后，您必须为您的账户创建一个专用的备用密码。这可以在以下位置完成：[https://myaccount.google.com/security](https://myaccount.google.com/security)，菜单“应用密码”。创建备用密码。然后您必须使用它而不是标准的 Gmail 密码进行设置（主电子邮件的登录不会改变）。

这个案例的法语视频可以在以下链接找到：[https://youtu.be/oz04CPJ6NWE?feature=shared](https://youtu.be/oz04CPJ6NWE?feature=shared)

 [![Warning.png](https://wiki.dolibarr.org/images/c/cb/Warning.png)](https://wiki.dolibarr.org/index.php/File:Warning.png)如果您的账户上有电子邮件别名，请确保将主用户名/电子邮件设置为登录，而不是别名。

 [![Warning.png](https://wiki.dolibarr.org/images/c/cb/Warning.png)](https://wiki.dolibarr.org/index.php/File:Warning.png)请注意，当使用谷歌 SMTPS 发送电子邮件时，如果发件人的电子邮件不是谷歌电子邮件，也不是已声明的别名，谷歌将用您的默认电子邮件别名替换收件人可见的"发件人"（但回复仍然会发送到发件人电子邮件，即使未声明）。

注意：在这种模式下，所有发送的电子邮件将自动添加到**主账户**的“已发送”文件夹中。如果您是 Gsuite 用户，拥有多个用户/邮箱，请优先使用下一步的方法。

#### Gmail（使用 OAuth2）

启用 OAuth2 模块。在 OAUTH2 模块设置中，为 Google 提供程序创建一个具有 3 个范围的 OAuth2 条目：

- gmail_full (=[https://mail.google.com/](https://mail.google.com/)) 或 [https://www.googleapis.com/auth/gmail.readonly](https://www.googleapis.com/auth/gmail.readonly) 或 [https://www.googleapis.com/auth/gmail.modify](https://www.googleapis.com/auth/gmail.modify))

进入令牌管理标签页，为这个 OAuth2 服务生成一个令牌。

现在，进入主页 - 设置 - 邮件必须

- 邮件发送方式：SMTPs
- 服务器：smtp.gmail.com
- 认证方式：OAUTH2
- 用户名：您的 Gmail 登录名（xxx@gmail.com 或 xxx@yourdomain.com）
- OAUTH2 认证服务：选择在 OAUth2 设置中创建的条目
- 端口：587
- 使用 TLS（SSL）加密：否
- 使用 TLS（STARTTLS）加密：是

#### Gmail（使用 Google Workspace - GSuite 的 Gmail 中继模式）

如果您是 Google Workspace 用户，并且有多个用户/邮箱，如果您希望每个用户的发送邮件自动存储到其自己的 Gmail“已发送”文件夹中，则必须使用此模式。

- SMTP 服务器：smtp-relay.gmail.com
- 端口：587 _(来自 Google 文档的说明：如果使用 TLS：587，如果不使用 TLS：25、465 或 587)_
- 认证方式：使用密码（AUTH LOGIN）
- 使用 TLS：取决于中继设置
- 登录/密码：保持登录/密码为空（选择 A）。在这种情况下，在你的电子邮件 Google 控制台中，你必须设置"仅允许某些 IP 地址"，并输入你的 Dolibarr 服务器的公网 IP 地址（见下文）。或者（选择 B）输入你的 GSuite 电子邮件账户和一个"应用"密码，这个密码不是你的账户密码，而是从 [https://myaccount.google.com/security](https://myaccount.google.com/security) 生成的第二个密码。

注意 1：您必须首先设置您的 Google 账户以转发外发邮件，并设置您的 SMTP 客户端的 IP 列表（[https://admin.google.com](https://admin.google.com/)，应用程序/应用程序 - GMail - 路由 - SMTP 中继服务）。然后选择“接受我域名的所有邮件”或“接受所有”，选择“启用 TLS”，并选择“SMTP 身份验证必需”为否（选项 A）或为是（选项 B）。

- 如果你选择了 A，你必须在"仅允许某些 IP 地址"中输入你的 Dolibarr 服务器的公网 IP 地址。
- 如果你选择了 B，你必须从 [https://myaccount.google.com/security](https://myaccount.google.com/security) 创建一个"应用密码"并使用这个密码。（需要启用双因素认证才能创建"应用密码"）

无论选择 A 还是 B，在使用 GMail 中继解决方案时，你都不需要在 Dolibarr 设置中输入你的 Google 账户的真实密码。

注意 2：在这种模式（A 或 B）下，如果开启选项"保存所有发送邮件的副本..."，发送的邮件也可以保存到"已发送"文件夹中。

#### iCloud

iCloud 不支持 SSL/TLS，仅支持 STARTTLS 的 TLS。

设置如下：

- 服务器：smtp.mail.me.com
- 端口：587
- 认证方法：使用密码（AUTH LOGIN）
- 用户名：您的 iCloud Mail 邮箱地址（请包含域名——即 iCloud Mail 地址中"@"后面的部分；例如，如果您的 iCloud Mail 邮箱地址是"me@icloud.com"，请使用"me@icloud.com"作为用户名。）
- 密码：iCloud Mail SMTP 密码：您的 iCloud Mail 密码或应用专用密码（已启用双重认证）
- 使用 TLS（SSL）加密：否
- 使用 TLS（STARTTLS）加密：是

#### Gandi

设置如下：

- 服务器：mail.gandi.net
- 端口：587
- 认证方式：使用密码（AUTH LOGIN）
- 用户名：您的 Gandi 账户的电子邮件地址
- 密码：您的 Gandi 账户的密码
- 使用 TLS（SSL）加密：否
- 使用 TLS（STARTTLS）加密：是

#### 橙色

设置将会是：

- 服务器：smtp.orange.fr
- 端口：25（或465）
- 认证方式：使用密码（AUTH LOGIN）
- 用户名：您的 Orange 账户邮箱地址（例如：myname@wanadoo.fr）
- 密码：您的 Orange 账户密码
- 使用 TLS（SSL）加密：否（如果您将端口设置为 465 则为是）
- 使用 TLS（STARTTLS）加密：否

有用户报告在使用 Orange SMTP 服务器时，需要在“主页 - 设置 - 其他”中设置变量 MAIN_FIX_FOR_BUGGED_MTA 的值为 0

#### Outlook / Office365 / Exchange 服务器（使用登录名/密码）

它也被称为 SMTP AUTH 方法或此 [Microsoft 教程](https://docs.microsoft.com/en-us/exchange/mail-flow-best-practices/how-to-set-up-a-multifunction-device-or-application-to-send-email-using-microsoft-365-or-office-365#option-3-configure-a-connector-to-send-mail-using-microsoft-365-or-office-365-smtp-relay)中的选项 1。警告，根据 Microsoft 文档，此方法有限制：它只支持一个可能的发件人。任何其他用于发送邮件的邮箱都会显示为同一个主要发件人。

设置可能为：

- 服务器：smtp.office365.com (Microsoft Office 365, Exchange Server) 或 smtp-mail.outlook.com
- 端口：587
- 认证方式：使用密码 (AUTH LOGIN)
- 用户名：主要邮箱账户
- 密码：您的账户密码（如果您启用了双重认证方法，您必须在菜单 [https://account.microsoft.com/security/](https://account.microsoft.com/security/)->"更多安全选项"中创建一个"应用密码"，并使用它而不是您的常用密码）
- 使用 TLS（SSL）加密：否
- 使用 TLS（STARTTLS）加密：是

- 您还必须在微软管理控制台中操作，并为每个电子邮件允许从外部平台发送。为此，在 [https://admin.microsoft.com](https://admin.microsoft.com/) 上进入**用户文件 - 邮件 - 允许作为...**。添加权限，并添加主要通用电子邮件账户。
- 您还必须允许应用程序"SMTP"访问您的账户。为此，在 [https://admin.microsoft.com](https://admin.microsoft.com/) 上，进入**用户文件 - 邮件 - 管理邮件应用程序** ，并勾选允许"SMTP 认证"。

注意：Outlook 和 Office365 是我们所知的最糟糕的电子邮件管理平台。它不符合大多数网页和电子邮件标准，因此在此平台上设置通常很困难。关于 SMTP 凭证的文档也很差。这取决于您 Outlook 平台中保存的大量参数。向您的 Outlook/Office365 平台提供者询问用于 Outlook/Office365 平台 SMTP 服务器的参数。只有您的 Outlook/Office365 提供者才能为您提供这些参数。如果您无法联系它（大多数客户从未收到任何答复），恐怕尝试任何参数组合是找到此电子邮件平台正确参数的唯一解决方案，但本维基中建议的参数在 90%的情况下应该有效（注意平台可能还期望一些特定于 Office365 的其他参数，请询问您的 Microsoft 集成商）。

### 创建邮件模板

要创建电子邮件模板，您需要填写几个字段：

- 模板代码：代码可以自由定义
- 语言：模板的语言
- 模板类型：电子邮件模板可以专门用于模块或全局可见
- 模板的所有者
- 私密：如果设置为私密，只有所有者才能看到模板
- 位置：模板在列表中的位置（1为最顶端位置）
- 邮件主题： [变量替换系统](https://wiki.dolibarr.org/index.php/Variable_substitution_system "Variable substitution system") 可被使用
- 附件： 如果邮件从有文档的界面发送，输入 "1" 将立即将文档添加到邮件中。
- 邮件内容： [变量替换系统](https://wiki.dolibarr.org/index.php/Variable_substitution_system "Variable substitution system") 可被使用

### 修改现有的邮件模板

在邮件模板列表中，您可以：

- 查看模板的摘要
- 通过点击状态列来激活或停用模板
- 通过点击铅笔图标修改模板
- 通过点击垃圾图标删除模板

## 邮件跟踪

像大多数现代 ERP 和电子邮件客户端一样，Dolibarr 发送的所有电子邮件都包含一个标头行"参考"，其中包含跟踪信息，以便知道电子邮件是从哪个源元素发送的。这些跟踪信息也将在电子邮件回复中出现，但前提是阅读者使用了其电子邮件客户端的"回复/回答"功能来发送回复，而不是从头开始创建一封新邮件，当然。这个跟踪 ID 可以被[模块电子邮件收集器](https://wiki.dolibarr.org/index.php/Module_EMail_Collector "Module EMail Collector")使用，该模块扫描您的邮箱，并可以自动将回复或发送的电子邮件存储为事件、潜在客户、工单或候选人，存储在正确的位置（因此它自动链接到相关的客户和/或报价等）。
