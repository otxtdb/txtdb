PDF 设置

PDF 生成的全局选项定义。

### 纸张格式

设置纸张格式和文档页边距

- 纸张格式：您可以选择可用的格式之一 [![PDF Paper format.png](https://wiki.dolibarr.org/images/6/69/PDF_Paper_format.png)](https://wiki.dolibarr.org/index.php/File:PDF_Paper_format.png) 
- PDF 左页边距，单位毫米（默认：10 毫米）
- PDF 右页边距，单位毫米（默认：10 毫米）
- PDF 的顶部边距，单位为毫米（默认：10 毫米）
- PDF 的底部边距，单位为毫米（默认：10 毫米）

### 地址框的规则

设置地址框中显示的字段

- 隐藏社区内部增值税号与地址
- 显示专业 ID 与地址 - 专业 ID 1（标签取决于您的国家）
- 显示专业 ID 与地址 - 专业 ID 2（标签取决于您的国家）
- 显示专业 ID 与地址 - 专业 ID 3（标签取决于您的国家）
- 显示带地址的专业 ID - Prof ID 4（标签取决于您的国家）
- 显示带地址的专业 ID - Prof ID 5（标签取决于您的国家）
- 显示带地址的专业 ID - Prof ID 6（标签取决于您的国家）

### 显示销售税/VAT 的规则

设置与税相关的显示字段

- 隐藏所有与主要销售税（大多数国家通常称为增值税，但名称可能因国家而异）相关的信息
- 隐藏 Tax Sale 列中的第二个税率（此税率的名称将取决于您的国家。例如印度的 CGST）
- 隐藏 Tax Sale 列中的第三个税率（此税率的名称将取决于您的国家。例如印度的 SGST）

### 其他

PDF 生成的附加参数

- 隐藏产品描述
- 隐藏产品编号
- 隐藏产品线详情
- 在 PDF 文档中交换发件人和收件人地址的位置
- 将客户地址位置使用法国标准位置（La Poste）
- 在页脚中添加更多详细信息，例如公司地址或经理姓名（除了专业 ID、公司资本和增值税号之外）
