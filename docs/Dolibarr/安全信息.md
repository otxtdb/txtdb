##  [![Art.png](https://wiki.dolibarr.org/images/6/66/Art.png)](https://wiki.dolibarr.org/index.php/File:Art.png)安全特性

Dolibarr 实现了多种安全特性，以符合与安全相关的最佳实践规则。

以下是你能够找到的主要安全特性列表  ：

  
**加密**

- 密码或安全密钥数据在数据库中加密 [*7][*8]。
- 数据库技术密码可以被混淆到 [Dolibarr 配置文件](https://wiki.dolibarr.org/index.php/Configuration_file "Configuration file") （conf.php）[*8]。
- 强制使用 HTTPS 的可能性 [*9]。

//conf/conf.php file
//example of $dolibarr_main_force_https  configuration
$dolibarr_main_force_https = '1';//to force https

|值|描述|
|---|---|
|0|不强制重定向|
|1|强制重定向到 https，直到 SCRIPT_URI 在响应中开始以 https 开头|
|2|强制重定向到 https，直到 SERVER["HTTPS"] 在响应中为 'on'|
|[https://mydomain](https://mydomain/)|强制重定向到 https 域名 mydomain（推荐方法）|

  
**具有防破解功能**

- 支持 PHP register_globals 开启或关闭（推荐关闭）[*2]。
- 支持 PHP safe_mode 开启或关闭（推荐开启）[*3]。
- 生产模式禁用任何技术信息泄露，如调试信息、错误堆栈跟踪、版本信息（参见[配置文件](https://wiki.dolibarr.org/index.php/Configuration_file "Configuration file") ）[*6]。
- WAF：防止 SQL 注入。由内部 WAF 和单元测试保护，以检查数据库良好实践中的转义操作。[*2]。
- WAF：防止 XSS 注入（跨站脚本）。由内部 WAF 和网页头部保护。[*1]。
- 防止 SSRF。所有 URL 访问都使用 core/lib/geturl.lib.php 中的 getURLContent()方法，该方法提供此保护。
- 防范 CSRF（跨站请求伪造）。通过内部 WAF 和令牌系统进行保护（具有多级更新策略，可按会话或按页面）。[*5]。

请注意，还建议通过禁用 Apache 选项来保护您的 Web 服务器。

AcceptPathInfo Off

  
**页面和文件访问**

- 页面和内容受集中式入口代码保护，用于检查权限（每个功能模块对组或用户的授权）[*4][*10]。
- Dolibarr 保存的文件存储在与 Web 应用程序不同的根目录中（因此它们不能在不通过 Dolibarr 包装器的情况下下载）[*3][*10]。注意：您必须检查您没有将"**document**"目录（用于上传文件）选择为与"**htdocs**"目录相同，也不是其子目录。您的 Web 虚拟主机必须仅指向 htdocs 目录（并且这个目录应该是只读模式）。因此，任何上传的文件（存储在文档目录中）不能在不使用包装器页面的情况下下载。
- 目录和文件名的清理（内部函数 dol_sanitizeFilename()和 dol_sanitizePathname()）。

  
**登录保护**

- 登录页面延迟反暴力破解 [*7]。目前该延迟是固定的（在未来的版本中可能会随着尝试次数呈指数增长）。
- 登录页面对机器人启用图形验证码（CAPTCHA）选项 [*7]。
- 仅对某些 IP 地址限制访问后台管理 [*7]。
- 日志中不记录密码，即使在技术日志中也不记录 [*7]。
- 内部日志记录器用于永久保存所有与用户管理相关的 Dolibarr 事件，包括成功或失败的登录尝试以及管理事件（如用户、组或权限变更）。
- 在成功或失败的登录尝试后，可以将日志记录输出到日志文件（在生产服务器上，必须启用 Debug Log 模块，并设置至少为 5-LOG_NOTICE 级别，开发服务器上级别应更高），以便您添加 fail2ban 规则来锁定暴力破解行为。您可以使用以下语法检查记录：

"YYYY-MM-DD HH:MM:SS (ERROR|NOTICE|INFO|DEBUG)    IP functions_dolibarr::check_user_password_.* Authentication KO"

要在您的服务器上添加的 fail2ban 规则列表，将在后面的章节 **DOS 和暴力破解速率缓解**中提供。

  
**病毒**

- 每上传的文件运行外部杀毒软件的可能性 [*3]。

  
**安全信息中心**

- 从版本14开始，你将在菜单“首页 - 管理工具 - 安全”中找到一个安全信息中心，它会向你报告与你安装相关的所有已完成和待办的建议。

  
**一个用于安全的 CTI**

一个持续集成平台在每次代码修改时运行安全单元测试和静态代码分析。

  
**每个版本的足迹**

我们的发布流程为每个版本附带一个足迹文件（也在线提供），用于验证本地安装的所有文件并检测任何文件变化，可通过菜单中的"主页 - 管理 - 安全"中的集成工具进行检测。

  
**DOS 和暴力破解率缓解**

- 内置 AntiDOS 功能，限制每个 IP 的公共操作配额。

- 该项目还提供了一些 fail2ban 规则的示例，用于阻止暴力破解尝试或滥用登录页面、忘记密码页面以及任何公共页面的访问。参见 [https://github.com/Dolibarr/dolibarr/tree/develop/dev/setup/fail2ban](https://github.com/Dolibarr/dolibarr/tree/develop/dev/setup/fail2ban)

  
**OpenSourceSSF**

Dolibarr 符合 OpenSourceSSF 定义的最佳实践：[https://bestpractices.coreinfrastructure.org/projects/5521](https://bestpractices.coreinfrastructure.org/projects/5521)
