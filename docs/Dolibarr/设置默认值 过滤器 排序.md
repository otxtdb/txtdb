## 识别字段

- **相对 URL** ：您必须输入页面 URL 的相对路径。如果 URL 中包含参数，当所有参数都设置为相同值时，将生效默认值。  
    示例：  
    创建新第三方的表单是 **societe/card.php**。  
    对于安装在自定义目录的外部模块的 URL，不要包含"custom/"，应使用类似 **mymodule/mypage.php** 的路径，而不是 custom/mymodule/mypage.php。  
    如果你只想在 URL 包含某些参数时使用默认值，可以使用 societe/card.php?abc=val1&def=val2。  
    还请注意，覆盖表单创建的默认值只适用于正确设计的页面（即带有参数 action=create 或 presend...的页面）。
- **字段** ：这是 HTML 字段的名称。需要技术知识来读取 HTML 页面的内容以获取字段的键名：找到 id="xxxxxxx"。
- **值** : 您可以使用任何固定值或使用[变量替换系统](https://wiki.dolibarr.org/index.php/Variable_substitution_system "Variable substitution system")

## 表单默认值

所有表单（卡片等）使用的默认值：需要填写三个字段：

- **相对 URL** : 应为 card.php
- **字段**
- **值**

## 默认搜索过滤器

需要填写三个字段：

- **相对 URL** : 应为 list.php
- **字段**
- **值**

## 默认排序顺序

需要填写三个字段：

- **相对 URL** ：应为 list.php
- **字段**
- **排序顺序**  ；：升序请填写 ASC，降序请填写 DESC

## 默认焦点字段

需要填写两个字段：

- **相对 URL** : 应该是 list.php
- **字段**
