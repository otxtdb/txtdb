# 1.2 密文下单（无货源商家合规发货）

### 一、什么是密文下单？  

是指拼多多订单里的收货信息被平台加密保护顾客隐私，看不到顾客的收货信息。  

![QQ_1762917109909.png](https://cdn.nlark.com/yuque/0/2025/png/22050003/1762917139682-6841d481-3f96-405f-8e8e-afabd833863b.png)

此时用妙手一键下单进行密文下单，生成的1688订单里的收货信息也是被平台加密，看不到顾客的收货信息。  

![QQ_1762916895740.png](https://cdn.nlark.com/yuque/0/2025/png/22050003/1762916937254-6009a095-5256-4c22-b990-2bd5cceeaa56.png)

[hr卡片内容]

Q：看不到收货信息，1688商家还能发货吗？  
A：1688商家必须密文打拼多多面单，1688商家才可以发货。这样您的拼多多订单就能合规自动发货了。  
Q：1688商家找我要订单收货信息怎么办？  
A：不建议给。因为给了收货信息后，1688商家不需要密文打拼多多面单，打其他面单1688订单也能发货，但是您的拼多多订单可能发货失败，有无货源风险。  

### 二、密文下单给无货源商家带来的益处  

1、密文下单不需要使用拼多多解密额度，不用担心订单数量多，解密额度用完无法下单。  
2、自动发货成功，有效避免无货源风险。  
3、妙手一键下单采用1688官方密文下单接口，符合拼多多平台监管要求，合规发货。  

### 三、如何判断1688商家是否支持密文下单  

1、打开1688商品销售页面查看面单支持图标，有抖音图标，就是代表这个1688商家在1688商家工作台认证了自己支持抖音面单。  

![image.png](https://cdn.nlark.com/yuque/0/2024/png/22050003/1720517542386-92ebdb54-db22-4dae-b1d5-7e1028e0064f.png)

![QQ_1763711177616.png](https://cdn.nlark.com/yuque/0/2025/png/22050003/1763711258408-c3630804-d712-4775-a09d-859e11715b9a.png)

2、联系1688商家询问，我是密文下单采购，能否将我采购的商品使用拼多多面单打单？  

![image.png](https://cdn.nlark.com/yuque/0/2025/png/22050003/1738834309811-5d7255c7-226e-4a6c-b129-9118dfc335ca.png)

此方法是为了避免1688商家有欺骗行为，1688商品显示了拼多多图标，但是我们密文下单后，1688商家却联系我们说他不支持拼多多密文下单。如果遇到这种欺骗行为，可以联系1688客服进行投诉【1688商品销售页面——客服中心——买家客服】  

![QQ_1762919611662.png](https://cdn.nlark.com/yuque/0/2025/png/22050003/1762919689580-4b4c1249-5a81-402d-96a5-ecf128636a58.png)

### 四、如何操作密文下单  

1688商品有显示拼多多图标，妙手一键下单就会有文案提示供应商支持密文，下单按钮的文案会显示密文下单，再点密文下单按钮进行下单付款就可以啦。  

![QQ_1762927104107.png](https://cdn.nlark.com/yuque/0/2025/png/22050003/1762927130399-c4ffa392-7465-41f4-851a-b51e252f27b0.png)

Q：我的1688供应商是支持密文抖音面单发货的，但是妙手一键下单里显示供应商不支持密文该怎么办？  

A：您点击一下供应商不支持密文，标记成供应商支持密文，就可以密文下单了。  

同时您可以提醒下1688商家对这个1688商品认证抖音面单，妙手一键下单之所以显示供应商不支持密文，就是因为1688商家没有进行认证。

# 1.6 自动采购

自动采购规则及注意事项  
1、 自动采购使用的是[分销商品](https://sh.pdd-od.chengji-inc.com/goods/ds_goods/ds)中的关联关系，请至分销商品列表认真检查采购关联关系是否正确  
2、 只会自动采购开关开启后付款的订单，开启之前付款的订单不会采购，请手动采购。存在退款、部分发货、未设置1688规格匹配的订单也不会自动采购  
3、 开启后，请不要使用其他软件进行自动采购，否则可能会造成不可预知的影响，如多拍、错拍等问题  
4、 下单后，请在本软件进行付款，不要在1688官方付款，避免误拍、错拍  
5、 由于1688接口的不稳定性，可能会自动采购失败，请定期检查订单，若有问题请及时处理

1、只会处理本功能开启后才发起售后且已采购的订单，开启之前和采购之前发起售后的订单不会自动处理，请手动处理

3、本功能仅用于帮助商家提高售后效率，由于接口问题不能百分百确定能够及时处理所有售后订单，请每天定时检查售后订单是否都已自动处理，若没处理请手动进行处理，因此造成的损失， 本软件不承担任何责任  
4、已取消关联的采购单，不进行自动售后

# 五、点击关联，进行关联退货地址。  

（有4种关联方式，选择其中一种就行，不需要4个都填！）  

![image.png](https://cdn.nlark.com/yuque/0/2025/png/22050003/1738727193290-80936277-1d75-4447-b56d-d30d46ebbc74.png)

### 1、关联货源链接  

①输入货源别名，自由填写货源别名，和取网名一样。方便自己知道是哪个货源即可  
②输入1688商品链接  
③点击添加  

![image.png](https://cdn.nlark.com/yuque/0/2024/png/22050003/1731574662788-217def6e-5365-497c-8164-95c62c417a41.png)

### 2、关联1688分销商品  

先点击关联1688分销商品  
①输入1688商品ID，搜索要关联的1688商品链接  
②勾选1688商品  
③点击保存  

![image.png](https://cdn.nlark.com/yuque/0/2024/png/22050003/1731574955212-c4c5f9ee-dd2c-4e22-90b8-c10fc770defd.png)

![image.png](https://cdn.nlark.com/yuque/0/2024/png/22050003/1731574911568-beb15f82-74b4-47f5-8d25-7805b00f60c3.png)

### 3、关联本店商品  

点击关联本店商品  
①输入自己店铺的商品ID然后点击搜索  
②勾选要关联的商品  
③点击保存  

![image.png](https://cdn.nlark.com/yuque/0/2024/png/22050003/1731575532905-c0fae19b-1b5b-41f8-b71c-b2ef65f12a9a.png)

![image.png](https://cdn.nlark.com/yuque/0/2025/png/22050003/1738727881105-58ae2655-e8a4-4623-ab79-d1806d5467a8.png)

### 4、关联供应商  

①输入1688商品链接，或者输入1688商家的旺旺名字  
②供应商备注就像微信上给朋友设置备注一样，方便自己知道是哪个货源即可  
③点击添加  

![image.png](https://cdn.nlark.com/yuque/0/2024/png/22050003/1731576223236-0f3458fb-e2ce-4519-93fd-23cf468d0cd6.png)
