### 这个插件有什么用途？[#](https://www.aakashweb.com/docs/git-it-write/faq/#what-is-the-use-of-this-plugin)

  
使用此插件，您可以管理 GitHub 仓库中的文章内容，并在其中进行编辑。每当仓库更新时，文件将被自动拉取并发布到 WordPress 中。通过这个概念，如果您需要维护一个文档网站，那么您可以创建一个 GitHub 仓库，用 Markdown 格式编写文档，并使用此插件将它们发布为网站上的文章。现在您可以邀请用户为文档仓库做出贡献，接受社区的建议等。
