1. **一个账号一个环境**: 每个账号使用独立的浏览器环境
2. **指纹完全独立**: 确保不同环境的指纹参数完全不同
3. **代理不重复**: 避免多个账号使用相同的代理 IP
4. **存储隔离**: 每个环境的数据完全独立存储

#### 环境命名规范 [​](https://virtualbrowser.cc/zh/guide/#%E7%8E%AF%E5%A2%83%E5%91%BD%E5%90%8D%E8%A7%84%E8%8C%83)

```
[平台]-[账号类型]-[用途]-[序号]

- Facebook-Ads-001
- TikTok-Creator-001
- Shopify-Store-001
```
