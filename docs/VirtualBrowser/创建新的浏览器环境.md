1. 打开 VirtualBrowser 并选择“创建浏览器”。 ![Image text](https://virtualbrowser.cc/static/img/vb/welcome_zh-cn.png)
2. 修改弹出对话框中的配置信息或使用默认设置。 ![Image text](https://virtualbrowser.cc/static/img/vb/create_zh-cn.png)![Image text](https://virtualbrowser.cc/static/img/vb/create_success_zh-cn.png)
3. 浏览器环境创建成功后，会显示在浏览器列表中。 ![Image text](https://virtualbrowser.cc/static/img/vb/browser-list.png)
4. 点击启动，即可打开该浏览器环境。 ![Image text](https://virtualbrowser.cc/static/img/vb/browser-list.png)
5. 浏览器环境创建成功后，会显示在浏览器列表中。 ![Image text](https://virtualbrowser.cc/static/img/vb/browser-list.png)
6. 在官网申请 apiLink，或者[立即申请](https://vbhub.net/ip.html)。
7. 点击设置，即可配置查询 ip 的 apilink。 ![Image text](https://virtualbrowser.cc/static/img/vb/browser_set.png)
