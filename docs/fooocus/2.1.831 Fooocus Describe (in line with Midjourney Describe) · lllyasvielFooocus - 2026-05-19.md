**我们不同！** Fooocus 旨在提供最高质量的功能，Fooocus 中的几乎所有工具都具有高度独特性。

您可能会对 CLIP Interrogator（在其他开源软件中）和 Fooocus Describe 之间的差异感兴趣：

1. 与 CLIP Interrogator 相比，Fooocus Describe 较少产生重复的失败案例，例如“在帽子里，在帽子里，在帽子里，在帽子里，在帽子里，在帽子里”。
2. Fooocus Describe 不会随机将艺术家名称和网站名称添加到您的提示中。（大多数 CLIP Interrogator 实现会几乎随机地添加艺术家名称和嘈杂的网站名称）
3. Fooocus Describe 与 Midjourney Describe 类似，可以为您提供多个可能的描述。使用它时，只需多次点击“将此图像描述为提示”即可。（大多数 CLIP Interrogator 实现只给出单一结果。）
4. 只有“照片”Describe 支持提供多个可能的描述。
5. 除了上述 1234，Fooocus Describe 也基于 BLIP 类似于 CLIP Interrogator，但模型选择基于大多数设备的计算能力。
6. Anime/Art Describe 基于 WD-Tagger-V2 最佳模型。请注意，如果您之前使用的是 DeepDanboru 或 WD-Tagger-V1 的较小或较旧模型，可以预期此实现将为您提供更好的结果。如果您之前在其他 UI 中使用 WD-Tagger-V2，则结果应该相同。（但是，您确定之前使用的是 v2 模型吗？如果您使用 Fooocus，您总是能获得最佳模型，无需研究。）
